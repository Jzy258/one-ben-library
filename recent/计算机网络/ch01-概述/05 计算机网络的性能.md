* 速率（Rate）：
	* 单位时间内可以传输的数据量
	* 单位：bit/s
	* 一般指额定速率而非实际运行速率
* 带宽（Bandwidth）：
	* 频域：
	    * 信号具有的频带宽度
	    * 单位：Hz
	    * **如**：
		    * 传统通信线路上传送的电话信号标准带宽为 3.1 kHz
	* 时域：
		* 网络中某通道传送数据的能力
		* 单位时间内网络的最高发送速率
	    * 单位：bit/s
	* 两者本质相同
* 吞吐量（Throughput）：
	* 单位时间内通过网络的实际数据量
	* 单位：bit/s
* 时延（Delay，延迟，迟延）：
	* 数据从网络的一端传送到另一端所需的时间
	* 发送时延（Transmission Delay，传输时延）：
	    * 主机或路由器发送数据帧所需的时间
		* $发送时延 = \frac{数据帧长度}{发送速率}$
	    * 与发送帧长成正比，与发送速率成反比
	* 传播时延（Propagation Delay）：
	    * 电磁波在信道中传播的时间
	    * $传播时延 = \frac{信道长度}{电磁波在信道上的传播速率}$
	    * 与传输距离成正比
	* 处理时延：
	    * 主机或路由器处理分组花费的时间
	    * 包括：
		    * 分析首部、提取数据、差错校验、查找路由
	* 排队时延：
	    * 分组在路由器的输入输出队列中排队等待的时间
	    * 取决于网络通信量
	    * 网络通信量很大时会发生队列溢出，使分组丢失，此时排队时延为无穷大
	* 总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延
	* 一般小时延的网络优于大时延的网络
	* **举例**：
		* 高速链路：
			* **发送**速率更高的链路
		* 光纤信道的发送速率优于铜线，传播速率略低于铜线
* 时延带宽积：
	* $时延带宽积 = 传播时延 \times 带宽$
	* 以比特为单位的链路长度
* 往返时间（RTT，Round-Trip Time）：
	* 从发送方发送完数据到发送方收到来自接收方确认需要的时间
	* $往返时间 = 2 \times 传播时延 + 接收方处理时延 + 接收方排队时延 + 接收方发送时延$
	* $有效数据率 = \frac{发送数据量}{发送时延 + 往返时间}$
* 信道利用率：
	* 传输数据的时间占总时间的比例、
	* 信道利用率并非越高越好
		* 当信道利用率增大时，时延迅速增加
	* $D = \frac{D _0}{1 - U}$
		* $D$：网络当前时延
		* $D _0$：网络空闲时的时延
		* $U$：信道利用率
	* 通常不应超过 50%，否则应考虑增大线路带宽
* 非性能指标：
	* 费用、质量、标准化、可扩展性、易维护性
