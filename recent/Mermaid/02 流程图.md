* 流程图：
	* `flowchart`
* 节点形状：
	* `A[文本]`：
		* 矩形
		* 普通步骤
	* `A(文本)`：
		* 圆角矩形
		* 开始 / 结束
	* `A{文本}`：
		* 菱形
		* 判断
		* 必须连接带标签的分支
	* `A((文本))`：
		* 圆形
		* 起止 / 接口
	* `A[/文本/]`：
		* 平行四边形
		* 输入 / 输出
	* `A[(文本)]`：
		* 圆柱
		* 数据库
* ID 为英文，显示文本为括号内的中文
* 箭头类型：
	* `A --> B`：
		* 实线箭头
		* 默认流程
	* `A --- B`：
		* 实线无箭头
		* 连接
	* `A -.-> B`：
		* 虚线箭头
		* 可选 / 非主线
	* `A ==> B`：
		* 粗线箭头
		* 强调 / 关键路径
	* `A --文字--> B`：
		* 带标签实现
		* 判断分支
	* `A ==文字==> B`：
		* 带标签粗线
		* 关键分支
	* 也可以写成 `-->|文字|`
* 方向：
	* `flowchart TD` / `TB`：
		* 从上到下
	* `flowchart BT`：
		* 从下到上
	* `flowchart LR`：
		* 从左到右
	* `flowchart RL`：
		* 从右到左
	* 方向声明只能写一个
* 子图：
	* `subgraph 标题`
	* `end` 结束
	* 节点属于首次提及它的子图，
* 样式：
	* `classDef 类名 样式...`：
		* 定义样式类
	* `class ID 类名`：
		* 为节点赋予类
	* 格式类似 CSS：
		* 样式名与样式值使用 `:` 分隔
		* 样式与样式之间使用 `,` 分隔
	* `fill`：
		* 填充颜色
	* `stroke`：
		* 边框
	* `stroke-width`：
		* 边框宽度
* 文本内含有特殊符号要使用 `""` 包裹
