* 后端优化：
	* 输入低层 IR，在特定硬件上特化优化代码
	* 施加路径：
		* 将低层 IR 降级到 LLVM IR，使用 LLVM 优化器
		* 使用 DL 领域知识定制优化 pass
* 硬件内建映射（Hardware Intrinsic Mapping）：
	* **定义**：
		* 将低层 IR 指令匹配 / 变换为硬件上已经高度优化的内核
		* 内建（Intrinsic）：
			* 硬件的原生高效操作
	* TVM：可扩展张量化（Extensible Tensorization）
		* 声明硬件内建的行为、内建映射的降级规则
		* 后端将硬件实现、手工优化的微内核套用到特定操作模式上
	* Glow：量化内建映射
		* 估计网络每阶段的数值范围
		* 使用 profile 引导的优化自动量化，映射为硬件的量化指令
	* Halide/TVM：
		* 将特定 IR 模式映射到各个架构的 SIMD 操作码
* 内存分配与取数（Memory Allocation and Fetching）：
	* GPU/ 加速器的内存是分层的：
		* 共享内存：
			* 低延迟、容量小
		* 本地 / 全局内存：
			* 高延迟、容量大
	* TVM：内存作用域（Memory Scope）调度
		* 用调度原语将某个计算阶段标记为：
			* `shared`：
				* 放在共享内存中
				* 编译器生成带共享内存分配 + 协同取数的代码
				* 在恰当位置插内存屏障保证正确性
			* `thread-local`：
				* 线程私有
	* TC：
		* 通过扩展 PPCG 编译器提供类似能力，只支持有限预定义规则
	* 原则：
		* 将最常被反复读的数据放进共享内存
* 内存延迟隐藏（Memory Latency Hiding）：
	* 在访问内存时执行其他任务
	* CPU/GPU 大多不需要编译器管理：
		* GPU 使用 warp 实现上下文切换，等待内存时会切换到另一个 warp 执行任务
	* TPU 的访存与执行分离（DAE），需要后端调度 + 细粒度同步
	* TVM：虚拟线程（Virtual Threading）调度原语
		* 用户声明数据并行
		* 插入必要内存屏障
		* 将虚拟并行线程降级
		* 将各线程操作交错（Interleave）为单一指令流
		* 形成每线程更优的执行流水线
* 面向循环的优化（Loop Oriented Optimizations）：
	* 嵌套循环是低层 IR 的核心
	* 循环融合（Loop Fusion）：
		* 合并边界相同的循环
		* 改善数据复用
	* 滑动窗口（Sliding Windows）：
		* 按需计算、边算边存，复用前值
		* 两个循环交错 + 串行化
	* 平铺（Tiling）：
		* 将循环切块成外层遍历块 + 内层块内迭代
		* 让分块适配硬件缓存，改善局部性
		* 分块尺寸使用自动调优
	* 循环重排（Reordering）：
		* 改变嵌套循环迭代顺序
		* 优化内存访问，提升空间局部性
		* 有依赖时重排不安全
	* 循环展开（Unrolling）：
		* 循环体复制成固定份数
		* 给编译器激进指令集并行空间
		* 常与分块配合
* 并行化（Parallelization）：
	* 现代处理器 = 多线程 + SIMD
	* Halide：
		* `parallel` 调度原语指定哪一维做线程级并行，映射为 block/thread 注解支持 GPU
		* 将循环变为向量语句
		* 经硬件内建映射到 SIMD
	* Stripe：
		* 嵌套多面体模型，引入并行多面体块作为基本执行单元
		* 可以检测出跨平铺 / 跨步各级的层次化并行
	* 实现路径：
		* 编译器自研：
			* 能施加更多 DL 领域知识
			* 工程投入大
		* 使用依赖库：
			* 省事
			* 黑盒不可控

补充：
* 基于 Profile 的量化（Profile-Guided Quantization）：
	* 先通过运行代表性数据测试模型，收集运行时特征，然后知道量化决策
* SIMD（Single Instruction, Multiple Data，单指令多数据流）：
	* CPU/GPU 中的一条指令在一个时钟周期内对多个独立的数据元素同时执行相同的算数或逻辑操作
* 内存屏障（Memory Barrier）：
	* **本质**：
		* 特殊的同步指令
	* **作用**：
		* 告诉硬件和编译器，在屏障之前的所有内存访问必须在屏障之后的内存访问开始之前完成
* 硬件的并行层级：
	* Grid -> Block -> Warp -> Thread -> SIMD Lane
