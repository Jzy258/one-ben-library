* 前端优化：
	* **目标**：
		* 减少冗余，使图更省更快
		* 不必关心硬件
	* 载体：
		* pass
	* 优化方法：
		* 捕获特征：
			* 分析图的内容
		* 重写图：
			* 将图改写成更优形态
	* **前提**：
		* 每个算子的输入 / 输出形状基本已知
		* 优化能基于形状信息完成
* 节点级优化：
	* 优化方法：
		* 节点消除：
			* 直接删除无用节点
		* 节点替换：
			* 用等效的代价更低的节点替换代价高的节点
	* Nop 消除（Nop Elimination）：
		* 删除缺乏足够输入的空转操作
		* 操作没有实际意义
	* 零维张量消除（Zero-dim-tensor Elimination）：
		* 若零维张量参与的运算没有实际意义，则可以删除
* 块级优化：
	* 将一系列相邻节点做整体处理
	* 代数化简（Algebraic Simplification）：
		* 利用交换律、结合律、分配律优化计算
		* 代数恒等识别：
			* 使用恒等式替换计算
		* 强度削减（Strength Reduction）：
			* 用等效的性能更高的算子替换性能低的算子
		* 常量折叠（Constant Folding）：
			* 常量的计算直接在编译时期计算完毕，并替换
		* 对于 DL 特定算子的化简：
			* 计算顺序优化：
				* 转置后相乘 -> 相乘后转置（减少一次转置）
			* 节点合并：
				* 连续多个转置合并成一个或删除
				* 不移动数据的转置改成重塑
			* Glow：ReduceMean 替换
				* 使用 AvgPool 替代四维输入规约最后两维的 ReduceMean
	* 算子融合（Operator Fusion）：
		* **定义**：
			* 将多个相邻算子合并成一个内核（Kernel）执行
		* **优点**：
			* 计算共享：
				* 中间结果可能被多个算子复用
			* 消除中间分配：
				* 节省两个算子之间中间结果在内存和 GPU 之间的交换
			* 合并循环嵌套：
				* 循环可以整体优化
			* 降低启动与同步开销
		* 典型融合：
			* 卷积 + 偏置 + ReLU
		* TVM：算子四分类 + 跨算子融合规则
			* injective（单射）：
				* 输出每个元素只由输入对应位置决定
				* 最易融合
			* reduction（规约）：
				* 输出聚合一片输入
				* 可融合
			* complex-out-fusible（复杂输出可融合）：
				* 输出较复杂但仍可视规则融合
			* opaque（不透明）：
				* 内部不可控的算子
				* 不能融合
		* TC：
			* 使用多面体自动变换以不同方式融合
		* **问题**：
			* 如何自动识别并融合更复杂的图模式
	* 算子下沉（Operator Sinking）：
		* 将移动数据的操作（**如**：转置）下沉到 ReLU/sigmoid/BN/channel shuffle 等逐元素操作下
		* **原理**：
			* 逐元素操作对每个元素独立，转置下沉不影响结果
			* 下沉后多个转置可合并
		* **本质**：
			* 聚合相似操作，便于化简 / 融合
* 数据流级优化：
	* 对整张计算图的优化
	* CSE（公共子表达式消除）：
		* 同一表达式的结果若值不变，则后续重复使用，不重复计算
		* 通常排在其他图优化之后，起到清扫作用
	* DCE（死代码消除）：
		* 删除结果或副作用无用的代码
			* 常为其他优化制造
		* 通常排在其他图优化之后，起到清扫作用
	* DSE（死存储消除）：
		* 删除永不被读的张量
	* 静态内存规划（Static Memory Planning）：
		* **目标**：
			* 尽可能复用内存缓冲区
		* 就地共享（in-place）：
			* 某操作的输入输出使用同一块内存
		* 标准共享（standard）：
			* 在不重叠的前提下复用先前操作的内存
		* 可以在编译时完成，使用复杂的规划算法
		* 近期进展：
			* 内存感知调度最小化边缘设备峰值激活内存
	* 布局变换（Layout Transformation）：
		* 插入布局变换节点，优化张量数据在内存中的排列
			* 实际的数据移动在后端处理
		* 变换操作本身也会消耗内存与计算，需要谨慎
		* 跨硬件布局变换：
			* 实现在不同硬件上使用各自的优化布局
		* TVM：
			* 将卷积布局统一改为 `NCHW[x]c`，使用自动调优搜索 `x` 参数，最终优化布局

补充：
* 偏置：
	* **本质**：
		* 可训练的参数张量
	* **作用**：
		* 提供移动原点的能力，使决策边界可以灵活地平移
* ReLU（Rectified Linear Unit，修正线性单元）：
	* **本质**：
		* 一种激活函数
	* 只保留非负值
* 现场可编程门阵列（FPGA）：
    * 可重新编程的集成电路
    * 低功耗、高性能
