# 小样 · 曲风名

> 配套卡片：[[01-曲风卡片/曲风名]] ｜ 状态：（构思 / 制作中 / 完成 / 搁置）
> ⭕ **加分项**：不做也不欠债；做一半放着也行。
> 🎯 **模式 = 复刻**（2026-09-28 主人定）：挑该曲风**最经典的一首**，**复刻其中一段** —— 有参照物才能 AB 对比、才可验。
> ⚠️ **边界**：复刻仅作私人练习，**不发布、不外传**。

## 1 · 复刻目标

| 项 | 值 |
|----|----|
| **复刻曲目** | （填：该曲风最经典的一首） |
| **版本** | （专辑版 / 12″ 版 / 单曲版 —— ★ 老歌版本不同，音色与长度都不同） |
| **复刻范围** | **主段 8–16 小节 + 一个变化段**（推荐）｜整首 = 超纲 ｜只做 4 小节循环 = 入门 |
| **要像的 3 件事** | ①　②　③ |
| **允许不像的事** | （如：真弦乐 / 现场鼓 / 磁带饱和 —— 现有插件无法 1:1） |

> 只盯 3 件事，不要贪多。**能听出「这是那首」就算过关。**
