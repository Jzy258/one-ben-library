## 6 · 硬件条件与工作方式

**已有** ✅ MIDI 键盘 · ✅ 耳机（监听）· ✅ 声卡（音频接口）　｜　**没有** ❌ 硬音源（硬件合成器 / 音源模块 / 鼓机 / 硬件效果器）

| 环节 | 条件 | 工作方式 | FL 对应能力 |
|------|:----:|---------|------------|
| **弹奏输入** | ✅ MIDI 键盘 | **可直接弹奏录制**（不必全靠鼠标画） | Piano Roll 实时录制 + 量化/半量化；**Disco / Deep House / Chicago House 的真乐手感与和弦即兴都靠它** |
| **鼓组编程** | ✅（键盘映射） | 键盘上弹鼓 or 鼠标画（EDM 鼓反而**画更准**） | FPC（可映射到键盘分区）+ Piano Roll |
| **旋钮自动化** | 视键盘是否有旋钮/推子 | 边听边扭 → **实时录自动化**；或鼠标画曲线 | **Automation Clip**（可录 MIDI CC）+ Peak Controller |
| **音频输入输出** | ✅ 声卡 + **FL Studio ASIO（FLSASIO）** | 见下方专表 |
| **监听** | ✅ 耳机 | 耳机低频易过量，需交叉验证 | 用 **SPAN / Wave Candy** 看频谱，别只靠耳朵 |
| **音色来源** | ❌ 硬音源 | **软件音源完全替代** | FL 51 生成器 + **Serum** + **Omnisphere 3** + Kontakt |
| **效果处理** | ❌ 硬件效果 | 软件通道条 | Slate VMR + SSL Native + MAAG EQ4（✅ 已在用） |
| **侧链 / 泵感** | — | 软件侧链 | **Fruity Limiter 侧链** 或 **Peak Controller** |

### MIDI 键盘带来的具体变化（相比纯鼠标）

| 好处 | 说明 |
|------|------|
| **弹进去 ≠ 画进去** | 旋律/和弦更有人味 —— 对 **Disco / Deep House / Chicago House** 关键 |
| **实时录自动化** | 边听边拧旋钮 → 直接生成 Automation Clip，比画曲线自然 |
| **学和声更快** | 即弹即听，不用画 16 小节再听结果 |
| **试音色更快** | 左手弹右手调，找音色效率翻倍 |

> ⚠️ **但要克制**：EDM 的**鼓组与 Bass 反而画更精确**（网格对齐 + 相位一致），别硬弹。
> 判断法：**要「人味」的弹（和弦、Pad、真贝斯、旋律）；要「机器感」的画（Kick、Sub、Hat、Acid line）**。

### MIDI 键盘规格 → 使用对策（32 键 · 2D 摇杆 ×1 · 无延音踏板 · 无打击垫）

| 规格 | 限制 | 对策 |
|------|------|------|
| **32 键**（≈2.5 八度） | 跨八度声部**不能同时弹**（低音 + 高音和弦） | ① **分轨录**（先录 Bass，再录和弦）② 用 FL 的 **Keyboard Octave** 快捷键快速换八度 ③ 和弦进行用 Piano Roll 的 **Chord / Stamp 工具**批量铺 |
| | 打鼓**键数够**（一套 808/909 约 16–20 键） | 把 **FPC** 分区映射到键盘即可手打；但 EDM 仍建议**画** |
| **2D 摇杆 ×1** | 一般是 Pitch Bend（左右）+ Mod Wheel（上下）；**只有 1 个 → 不能同录两个参数** | ① 优先映射到「**滤波器 Cutoff**」或「**扫频/Love Philter**」→ 实时录 Build-up ② **摇杆带弹簧回中**，不适合定值参数（定值用 Automation Clip）③ 可用 MIDI Link 映射到任意参数当"通用表演控制器" |
| **无延音踏板** | 钢琴类长音只能手按住 | EDM 影响 ≈ 0（Pad 靠长音符 + 混响）；Disco / Deep House 钢琴用 **Piano Roll 拉长音符**代替；想补的话踏板很便宜（非必需） |
| **无打击垫** | 不能指打鼓 | ① 键盘分区映射 FPC ② **Piano Roll 画**（EDM 推荐做法） |

### 音频驱动专表：FL Studio ASIO（FLSASIO）

| 项 | 说明 |
|----|------|
| ✅ 优点① **多客户端** | Windows 共享模式下**其他程序仍能发声**（浏览器 / Spotify / 参考曲目 A/B 对比不受影响）—— 对「研究曲风」这件事**特别有用**：FL 里做小样，浏览器里放参考曲，来回切不用重新起驱动 |
| ✅ 优点② 免驱 | 不需要声卡原生 ASIO，任何声卡都能用 |
| ✅ 优点③ 省心 | FL 官方维护，比 ASIO4ALL 少踩坑（ASIO4ALL 常与 Windows 音频打架） |
| ⚠️ 局限① **延迟略高** | 比声卡原生 ASIO 高（原生走独占 + 直通，FLSASIO 走共享）。**MIDI 键盘演奏延迟约 10–20 ms** → 弹和弦/Pad/贝斯/旋律**够用**，但**打鼓会"肉"**（手感不跟手） |
| ⚠️ 局限② 输入受限 | 音频**输入**跟随 Windows 默认录音设备（对 MIDI 键盘**无影响** —— MIDI 不走音频驱动） |
| ⚠️ 局限③ 独占冲突 | 别的程序占用独占模式音频设备时可能爆音/无声 → 切共享或重启 FL |
| ⚠️ 局限④ 采样率 | 换采样率后建议重启 FL；**固定 48 kHz** 最省事 |

**FL 音频设置建议**

| 项 | 建议值 | 说明 |
|----|--------|------|
| Device | **FL Studio ASIO** | ✅ 现状 |
| Buffer length | **256 samples** 起步 ｜ 爆音 → 512 ｜ 嫌延迟 → 128 | 沙盒式试 |
| 采样率 | **48000 Hz** | 固定，别频繁切 |
| Priority | **Highest** | FL → Options → Audio settings |
| 多线程 | 开 **Multithreaded generator / mixer processing** | 现代多核 CPU 必开 |
| Windows 电源计划 | 高性能 | 防 CPU 降频导致爆音 |

**延迟换算（单程）**

$$\text{延迟 (ms)} = \frac{\text{buffer (samples)}}{\text{采样率 (Hz)}} \times 1000$$

- 256 samples @ 48 kHz ≈ **5.3 ms** 单程
- 加上驱动往返缓冲，实际体感一般 **10–20 ms**

> **对"弹 / 画"分工的再校准**：FLSASIO 的 10–20 ms 延迟 → **适合弹和弦 / Pad / 真贝斯 / 旋律**，**不适合打鼓**（不跟手）→ 正好印证前面的分工：**鼓一律用画**。

> 💡 **附带能力**：你已装 **VB-CABLE / Voicemeeter**，配合 FLSASIO 的共享模式，可以用 Edison 把**参考曲目内录进 FL**（浏览器放歌 → 录成音频 → 用 SPAN 看频谱、对比自己小样）—— 这是后期做"曲风拆解"的利器。

**32 键「弹 / 画」分工定稿**

| 弹（键盘 + 摇杆） | 画（Piano Roll） |
|------------------|-----------------|
| 和弦（Pad / stab）· 旋律 / Lead · 真贝斯（Disco / Deep House 跳跃贝斯）· **摇杆实时录滤波扫频** | Kick / Sub / Hat / 整组鼓 · Acid line · 跨八度的复杂编排 |

> 结论：**制作链完整无缺**。唯一没有的是硬音源，而软件音源（FL 原生 + Serum + Omnisphere）在电子舞曲领域**没有音色类型缺口**；32 键的跨度限制有成熟对策，不影响曲风复现。

## 9 · 资源使用原则（避免"插件地狱"）

1. **先 FL 原生，后第三方**：能用 3x Osc / Sytrus / Transistor Bass / FPC 复现的，先不用 Serum —— **理解原理优先于音色好听**
2. **每个曲风最多用 5 个插件**：小样只做 3 个特征，不要堆工具
3. **Transistor Bass = Acid 的钥匙**、**Slicex = Jungle/DnB 的钥匙**、**Gross Beat/Pitcher = Build-up 的钥匙**、**Peak Controller = 泵感的钥匙** —— 这 4 个是本研究的关键节点
4. **FabFilter / SSL / Slate / MAAG 只用在"混音"环节**，不要一开始就上
5. **VCV Rack 2 当教具**：想搞懂"减法合成/FM/加法"到底怎么回事时，用 VCV 搭一遍比看教程更快
6. **钢琴卷帘与 MIDI 键盘分工**：要「人味」→ 弹（和弦/Pad/真贝斯/旋律）；要「机器感」→ 画（Kick/Sub/Hat/Acid line）
