## 结构类

### Break

* **定义**：**节奏组单独露出来的段落** —— 其他乐器撤走，只剩鼓/贝斯（或鼓整个消失只留器乐），本质是"**把空间让给节奏**"
* **为什么存在**：DJ 拿它做 **loop / 接歌**；舞者有 solo 窗口
* **首次成型**：**Disco**（Tom Moulton 在 12″ 里专门做出的 break 段落）
* **血统**：Hip-Hop 的 **breakbeat** 就是从 Disco/Funk 唱片里的 break 采样来的
* ⚠️ **易混**：`Break` ≠ `Breakdown`（见下条）

### Breakdown

* **定义**：**能量大幅下降**的段落 —— 乐器减少、鼓消失或变简，通常用来铺情绪，然后"冲回来"
* **与 Break 的区别**：Break 强调**节奏露出来**；Breakdown 强调**能量掉下去**（可能有鼓，但很薄）
* **首次成型**：**Disco** → **Trance** 把它发扬成核心武器（大段 Pad + 无人声 + 大混响）
* ★ **血统**：**Break / Breakdown 都是 Drop 的祖先** —— 共同逻辑是"**拿掉什么，再放回来**"，Drop 只是把量级推到极端

### Build-up（Build）

* **定义**：能量**持续上升**的一段 —— 手段：滚奏加密、音高上行、滤波器打开、噪声渐强、去掉底鼓只留上升
* **首次成型**：**Disco**（镲滚奏 + 弦乐上行 → 引副歌）
* **血统**：Disco 镲滚奏 → **House** 的 Snare Roll → **Trance** 的 Riser → **EDM** 的整套 build-up

### Drop

* **定义**：Build 之后**能量爆发的那一点**（"drop the beat"）
* **首次成型**：语源来自 **Drum and Bass / Dubstep**（90s 末–00s "the drop"），2010s 被 EDM 变成全球通用词
* ⚠️ 很多人说"drop 是 EDM 发明的"—— 错，它的**逻辑祖先在 Disco 的 Break**

### Intro / Outro（DJ 版）

* **定义**：为 DJ 接歌而设计的**器乐头尾** —— 纯节奏、无人声、结构规整，方便和前一首叠着混
* **首次成型**：**Disco**（12″ 长 Intro 是标配，常 30–60 秒）

## 节奏类

### 四踩（Four-on-the-floor）

* **定义**：**每一拍都踩一下底鼓**（4/4 里 = 咚 咚 咚 咚），像节拍器
* **首次成型**：**Disco**（把 Funk 的碎律动压成规则脉冲，才能长时间跳舞）
* **血统**：House / Techno / Trance / Hardstyle **全部继承**

### 碎拍（Breakbeat）

* **定义**：**不踩四踩**，鼓组用切分、打散、错位的节奏
* **首次成型**：**Breakbeat Hardcore**（UK Rave）→ Jungle / Drum and Bass
* **来源**：直接采样 Disco / Funk 唱片里的 **Break** 段落（最能采的就是 Amen Break）

### Roll（滚奏）

* **定义**：鼓的**密度加倍**（8 分 → 16 分 → 32 分），制造"时间被压缩"的紧迫感
* **首次成型**：**Disco**（镲滚奏引副歌）→ House 的 **Snare Roll** 定型
* ⚠️ Roll 是 Build-up 最古老的手段，早于 Riser

### Half-time（半拍）

* **定义**：鼓组实际速率**减半**，听感变慢变重（BPM 不变，但重心变）
* **首次成型**：**Drum and Bass / Dubstep**

## 手法类

### 转调升 key（Modulation）

* **定义**：整曲在某个点**整体升半音或全音** → 听感"突然变亮、能量升级"
* **首次成型**：**Disco**（★**不用 drop 也能造高潮**的核心手法）
* **血统**：Hi-NRG / Italo / 90s 流行舞曲的标配；现代 EDM 改用 Drop，转调变少

### Call & Response（一唱一答）

* **定义**：人声唱一句 → 铜管/弦乐"回一句"
* **首次成型**：Gospel / Soul → **Disco** 定型为编排手法

### 人声切片（Vocal Chop）

* **定义**：把**人声切碎当乐器**用（切音、重排、变调）
* **首次成型**：Disco（DJ 用 acapella 现场拼）→ **House** 定型为制作手法

### Dub / Instrumental Mix

* **定义**：**去掉人声**（或大幅削减）的版本，12″ 常放 B 面
* **来源**：Reggae **Dub** → Disco 12″ → House 的 Dub 传统（把 Mixdown 当创作）

### 12″ 单曲

* **定义**：**更长、低频更强、给 DJ 专用**的唱片格式（区别于 7″ 单曲）
* **首次成型**：**Disco 1976**（首张商用：Double Exposure《Ten Percent》，Walter Gibbons 混音）
* ⚠️ **版本陷阱**：同一首老歌常有 **7″ 单曲版 / 专辑版 / 12″ 混音版**，**长度与速度都可能不同**
  → 例①：The Trammps《Disco Inferno》专辑版 **10:51 / 129 BPM**，而常见的编辑版只有 6 分钟左右
  → 例②：Double Exposure《Ten Percent》—— **7″ 版 3:05 ｜ 专辑版 6:51 ｜ 12″ 版 9:42**（同一首歌差 3 倍时长）
  → 所以**记录 BPM / 时长时必须注明版本**，否则数据无法对比

## 声音设计类

### 303 / Acid line

* **定义**：Roland **TB-303**（1981，原本是失败的贝斯伴奏机）做出的**滑音 + 共振 + 失真**的循环贝斯线
* **首次成型**：**Acid House**（1987 Phuture《Acid Tracks》）
* **FL 对应**：**Transistor Bass**

### Riser

* **定义**：纯粹的**上升音效**（白噪声扫频 / 音高上行 / 反向混响），只为制造"要来了"
* **首次成型**：**Trance**（+ EDM 全面化）

### Supersaw

* **定义**：**多个锯齿波失谐叠加**成一把"巨型"Lead/Pad
* **首次成型**：**Trance**（源自 Roland **JP-8000**，1997 的 Supersaw 振荡器）
* **FL/插件对应**：Serum Unison / Hyper；Harmor Unison

### Reese Bass

* **定义**：**两个失谐锯齿波**互相拍频产生的"厚重、带内部晃动"的贝斯
* **首次成型**：Techno（1988，Kevin Saunderson 的 Reese 项目）→ 在 **Drum and Bass** 定型为主力 Bass
* **FL/插件对应**：Serum（两个 Saw + Detune）

### 侧链（Sidechain）

* **定义**：用 **Kick 触发压缩**去压低 Bass/Pad 音量 → 每次 Kick 落下时其他声部"躲一下" = **泵感（pumping）**
* **首次成型**：**House**（后来 Techno/Trance 全面采用，是"现代舞曲听感"的底层之一）
* **FL 对应**：**Fruity Limiter 的侧链输入** 或 **Fruity Peak Controller**（不需要买插件）

## 结构逻辑类

### 加法编排（Additive Arrangement）

* **定义**：靠**"加层"**增长能量 —— 加一层打击乐、加一条吉他、叠一轨弦乐、加一条 bass riff；**不是靠"改变"**
* **首次成型**：**Disco**（《Love Hangover》在段落内叠 conga + 加 bass riff）
* **血统 / 对照**：Disco **累积** → House 累积 + 循环 → Trance 叠到极致（层层叠加）→ **EDM 改成"开关式"**（build → drop，靠"拿掉 / 放回"）
* ★ 一句话记法：**Disco 是加法 · Techno 是循环 · EDM 是开关**

### Fill（加花 / 过门）

* **定义**：段落**交接处**的短促鼓 / 镲变化 —— 功能是**报信"要换段了"**，不是装饰
* **Disco 标准化形态**：**Crash + 快速加花** = 换段开关（→《Love Hangover》从 Ballad 切进 Disco 的那一刀）
* **血统**：→ House / Techno 的 **Drum Fill** → EDM 的"全停 → Crash → 白噪上升"
* ⚠️ **易混**：`Fill`（换段信号，短）≠ `Break` / `Breakdown`（成段的结构）
