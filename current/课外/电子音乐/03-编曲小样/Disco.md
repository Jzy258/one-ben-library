# 小样 · Disco

> 配套卡片：[[01-曲风卡片/Disco]] ｜ 状态：**构思**（⭕ 加分项 · 不做也不欠债 · 做一半放着也行）
> **验收标准只有一条**：闭眼听，**能听出这是 Disco 而不是 House / Techno / Funk** → 就算成功

---

## 0 · 先定策略：做 **MVP**，不做完整曲

| 阶段 | 内容 | 预计 |
|:--:|------|:--:|
| **MVP（本轮目标）** | **8 小节循环**：四踩鼓组 + 八度跳跃贝斯 + 电钢和弦 + 弦乐切分 | **40–60 min** |
| 加长版（有余力） | 扩到 32 小节：加入 Intro / Break / 转调 Chorus / Outro | +60 min |
| 加分项（随意） | brass fall、铜管呼应、拉丁打击乐层 | +30 min |

> ⚠️ **只做 8 小节就够了。** 卡在 Step 2 就停也完全 OK —— **中断不补欠债**。

---

## 1 · 目标：复现哪 3 个特征

1. **持续脉冲** —— 四踩底鼓 + **反拍开镲** + 16 分打击乐（"永不疲倦"的来源）
2. **八度跳跃贝斯 riff** —— 贝斯从伴奏变成 **riff 的载体**（Disco 留给后世的最大遗产）
3. **弦乐切分 + Fill 分段** —— 弦乐当**打击乐**切进去（不是长音铺底）；换段靠 **Crash + 加花**报信

> ❌ **明确不做**：侧链泵感、Drop、Riser、OTT —— 这些是**后面曲风**的语言，套上来立刻"不像 Disco"

## 2 · 参数表

| 项 | 值 | 说明 |
|----|----|------|
| BPM | **120** | 取中位（实测档：慢 111–117 / 快 128–132）；想更"灵魂"→ 114，想更"推进"→ 128 |
| 调性 / 音阶 | **D 大调** | 实测《Good Times》用的就是这个；大调 + 爵士和弦 = Disco 的标准色彩 |
| 长度 | **8 小节**（MVP）→ 32 小节（加长版） | 4 小节一组，8 小节一个完整循环 |
| 结构 | `Intro 4 → Verse 4 → Chorus 4 → Break 4 → Chorus 4 → Outro 4` | Break = 只留鼓 + 贝斯 |

## 3 · 音色拆解（用你已有的插件）

| 声部 | 工具 | 关键参数 | 参照曲目 |
|------|------|---------|---------|
| **底鼓** | **FPC**（Disco / 909 鼓组） | **短、干、无长拖尾**；每拍一下；单声道 | 《Disco Inferno》 |
| **拍手 / 军鼓** | FPC **clap**（+ 轻叠 snare） | 落 **2、4 拍**；clap 要"群体感 + 干净" | 《Mighty Real》 |
| **开镲** | FPC **OH** | ★ 落在 **8 分的反拍（"and"）** → 产生 "tss tss" | 全部 |
| **打击乐层** | FPC conga / shaker | shaker 走 **16 分**；conga 做点缀（**拉丁系**，别标"非洲鼓"） | 《Love Hangover》 |
| **贝斯** | **SWAM Double Bass 3**（最有人味）或 **BooBass**（草稿快） | ★ **八度跳跃 + 切分**；每音**短**、留空隙 | 《Good Times》 |
| **电钢 / 和弦** | **FLEX** → 找 `Electric Piano / Rhodes` 类音色 | ★ 用 **Maj7 / 9 / 11 / m7**，**别用普通三和弦** | 《Love Is the Message》 |
| **弦乐** | **Omnisphere** 弦乐 patch（或 FLEX strings） | ★ **切分重音**，像打击乐"切"进去；上行 riff 用 **4–5–6** | 《Love Is the Message》 |
| **铜管**（加分） | Omnisphere brass（或 FLEX） | **brass fall**：长音 + **Pitch Envelope** 快速下滑，落每小节第 1 拍 | 《Good Times》 |
| **吉他切分**（加分） | **Ample Sound AGML2**（木吉他） | 16 分**闷音切分**（当打击乐弹） | 《Good Times》 |
| **空间** | **Fruity Chorus** + **Fruity Reeverb 2** | 弦乐/电钢加一点；**别用大混响**（Disco 是干爽的） | — |

> ❌ **不要用**：OTT、Fruity Limiter 侧链输入、Gross Beat、Pitcher 上升 —— 全是现代手法

## 4 · 步骤记录（按顺序做，做完打勾）

### Step 0 · 准备（2 min）
* [x] 新建工程：**120 BPM**、4/4、48 kHz
* [x] 主输出挂 **Fruity Limiter**（只当"防爆保险"，阈值拉到底，不要压）
* [x] ⚠️ 用 MIDI 键盘前先确认 FLSASIO buffer = 256（弹奏延迟够用）

### Step 1 · 鼓组（10 min）
* [x] FPC 选一套 Disco / 909 鼓
* [x] 底鼓：**每拍一下**（四踩，4 拍全踩）
* [x] clap / snare：只落 **2、4 拍**
* [x] 开镲：★ **8 分的反拍**（`1 and 2 and 3 and 4 and` 里只放 "and"）
* [x] shaker：补 **16 分**（音量压低，只做"空气层"）
* ⚠️ **坑**：开镲放**正拍**会立刻变成"广场舞" —— 反拍才是那个"推"

### Step 2 · 贝斯（15 min，★ 用 MIDI 键盘弹）
* [x] D 大调；先用 **D–D'（八度跳跃）** 做骨架，再加经过音
* [x] 节奏：★ **不要和底鼓完全同步** —— 切分、抢拍，每音**短**、留空隙（律动来自**空隙**）
* [x] 音色：SWAM Double Bass 或 BooBass；**低切 30 Hz 以下**，低频转单声道（`Fruity Stereo Shaper`）
* ⚠️ **坑**：32 键跨度不够同时弹高低八度 → **分两轨录**，或用钢琴卷帘 **Stamp** 批量铺
* ⚠️ **坑**：别做成"电子 sub bass"（那是 Techno/E DM 的）—— Disco 要**有音头、可辨认音高**的贝斯

### Step 3 · 电钢 / 和弦（10 min）
* [ ] FLEX 加载 Rhodes 类电钢
* [ ] 和弦：**Dmaj7 / Em7 / F#m7 / A9** 之类，每 1–2 小节一个
* [ ] 弹法：**短促切分**（stab），或"长音 + 偶尔切分点缀"
* ⚠️ **坑**：用普通大三和弦会显得"土"；**Maj7 / 9 的"爵士味"就是 Disco 的洋气来源**

### Step 4 · 弦乐 + 铜管（15 min）
* [ ] 弦乐：★ **不是长音铺底**，而是**切分重音**（和开镲/吉他错位"切"进去）
* [ ] 上行 riff：用 **4–5–6**（你在 MFSB 听出的那个）往上推
* [ ] （加分）brass fall：用一个长音 + **Pitch Envelope** 画快速下滑，落在每小节第 1 拍
* ⚠️ **坑**：弦乐铺满全曲 → 立刻变"电影配乐"；Disco 弦乐是**间歇性的推进器**

### Step 5 · 结构 + Fill（10 min）
* [ ] 4 小节一组 → 每 4 小节换一次"层数"（**加法编排**：加 conga / 加弦乐 / 加吉他）
* [ ] 换段处放 **Crash + 快速加花**（= 报信"要换段了"）
* [ ] **Break**：拿掉弦乐 + 电钢，**只留鼓 + 贝斯** 4 小节
* [ ] （加分）**转调**：最后一段整体升半音（D → E♭），= 不用 drop 的高潮

### Step 6 · 粗糙混音（10 min）
* [ ] 各轨峰值 -6 dB 左右，别贴 0
* [ ] 贝斯低频单声道；开镲**明亮**；弦乐**靠前**
* [ ] 音量优先：底鼓 ≥ 贝斯 > 弦乐 > 电钢 > 打击乐
* ⚠️ **坑**：**不要侧链、不要 OTT、不要猛压 limiter** —— 会把"人味"和年代感一起压掉

### Step 7 · 导出 + 对照（5 min）
* [ ] 导出 wav/mp3（8 小节循环即可）
* [ ] **AB 对比**：和《Good Times》《Love Is the Message》轮流播 → 填 §5
