# 小样 · Disco（**复刻模式**）

> 配套卡片：[[01-曲风卡片/Disco]] ｜ 状态：**构思**（2026-09-28 由"风格原创"改为**复刻**）
> ⭕ **加分项**：不做也不欠债；做一半放着也行。
> 🎯 **模式 = 复刻**：挑该曲风**最经典的一首**，复刻其中一段 —— 有参照物才能 AB 对比、才可验。
> ⚠️ **边界**：复刻仅作私人练习，**不发布、不外传**。
> 📌 **旧稿可复用**：2026-09-22 那版已完成 Step 0–2（工程 + 鼓组 + 贝斯），**改 BPM 后接着对齐**即可。

## 1 · 复刻目标

| 项            | 值                                                        |
| ------------ | -------------------------------------------------------- |
| **复刻曲目**     | **《Good Times》— Chic (1979)**                   |
| **版本**       | 1979 专辑《Risqué》版（约 8:15）；★ 别用后来的 remix / 再版（老歌各版长度差很多）                       |
| **复刻范围**     | **主段 8 小节 + 变化段 8 小节**（riff 与切分吉他最清晰的那段）                     |
| **要像的 3 件事** | ① **八度跳跃贝斯 riff**（这首歌的灵魂） ② **16 分闷音切分吉他** ③ **弦乐 + 铜管的 Fall（正拍冲击）** |
| **允许不像**     | 女声主唱与和声（**无人声采样 → 跳过**） · 真弦乐 / 铜管的乐手呼吸 · 1979 的磁带饱和与混音胶合感                 |

### 为什么选它（判据 + 落选对照）

判据 3 条：**历史地位** / **传播度** / **可复刻性**（本项目硬约束：无人声采样 · 32 键 · 全软件音源）

| 曲目                        | 地位  | 传播  | 可复刻 |          合计          |
| ------------------------- | :-: | :-: | :-: | :------------------: |
| **《Love Is the Message》** | ★★★ | ★★  | ★★★ |      8（Ginna 原选）      |
| 《Good Times》              | ★★★ | ★★  | ★★★ | **8 ← 选它（主人 2026-09-28 拍板）**  |
| 《Stayin' Alive》           | ★★★ | ★★★ |  ★  | 7（三声部假声 + 弦乐，人声不可复刻） |
| 《I Will Survive》          | ★★★ | ★★★ |  ★  |      7（Diva 主导）      |
| 《Disco Inferno》           | ★★  | ★★  | ★★  |  6（层多；专辑版 10:51 太长）  |

**决定性两条**：

1. **它是"被借走最多"的那首** —— 那条八度跳跃贝斯 riff 直接被 Sugarhill Gang《Rapper's Delight》(1979) 采样 → **Hip-Hop 的起点之一**；Queen《Another One Bites the Dust》同骨架
2. **主人已经听过并扒过** —— 听感记录里写着「bass 成为 riff 的载体」「brass fall 产生冲击感」，起点比其他曲子高
3. **旧稿调性正好对得上** —— 旧稿是 **D 大调**，《Good Times》**也是 D 大调** → **旧贝斯不用移调**

> 📌 **2026-09-28 主人拍板**：Ginna 原提《Love Is the Message》，主人改选 **《Good Times》** —— 判据表同为 8 分，riff 更直接、且**调性与旧稿一致**（省一道移调）。

## 2 · 参数表

| 项 | 值 | 说明 |
|----|----|------|
| BPM | **111** | SongBPM 实测值（**Disco 慢档**，真乐队/灵魂派）；旧稿工程是 120，**要改** |
| 调性 / 音阶 | **D 大调** | SongBPM 值；★ **与旧稿同调** → 旧贝斯可直接用 |
| 长度 | **主段 8 小节 → + 变化段 8 小节** | 先对齐 **riff + 切分吉他**，再加弦乐/铜管层 |
| 结构 | riff + 切分吉他最清晰的 8 小节 → **副歌后的器乐段**（弦乐/铜管进）8 小节 | ⚠️ 具体小节号以主人扒带为准（Ginna 未逐小节核过） |

## 3 · 音色拆解（复刻版 · 全用现有插件）

> 复刻模式下，**每一层都对着同一首参考曲**（《Good Times》）。

| 层 | 工具 | 关键参数 | 对齐目标（参考曲里这一层的样子） |
|----|------|---------|------------------------------|
| **底鼓** | **FPC**（真鼓 / Disco 组） | 短、每拍一下、单声道 | **慢档**的四踩（111 BPM，不赶） |
| **开镲** | FPC **OH** | ★ **8 分反拍（"and"）** | Disco 的"推" |
| **拍手 / 军鼓** | FPC clap + 轻叠 snare | 落 **2、4 拍** | 骨架 |
| **打击乐** | FPC conga / shaker | 16 分 shaker + conga 点缀（**拉丁系**） | 空气层 / 摇摆 |
| **贝斯** | **SWAM Double Bass 3** 或 BooBass | ★★ **八度跳跃 riff**（根音 ↔ 高八度）；每音短、留空隙 | **这首歌的灵魂** —— 这层对了就赢一半 |
| **吉他** | **Omnisphere** 电吉他（clean）或 **FLEX** | ★ **16 分闷音切分**（当打击乐弹，不是扫弦） | Nile Rodgers 的招牌 |
| **弦乐** | **Omnisphere** 弦乐 | 上行 + 切分（**不是长音铺底**） | 推上去 |
| **铜管**（加分） | Omnisphere brass | **Fall**：长音 + Pitch Envelope 快速下滑 | 正拍冲击（依据：主人听感记录） |
| **主唱 / 和声** | ❌ **跳过** | 无人声采样 → 用吉他/键盘补中频 | 已写入 §1「允许不像」 |
| **空间** | **Fruity Chorus** + **Fruity Reeverb 2** | 干爽、小混响 | 1979 的"听得见房间" |

> ❌ **不要用**：OTT · 侧链 · Gross Beat · Pitcher 上升 —— 现代手法会让年份对不上
