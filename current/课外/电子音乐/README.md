## 1 · 目标

1. **了解每种电子音乐曲风** —— 按**历史演进顺序**走（不是字母表顺序），理解「谁从谁那里来 / 为什么此刻出现 / 为什么后来退场」
2. **每种曲风有产出**（四件套）：

| # | 产出 | 内容 | 目录 | 必做? |
|:-:|------|------|------|:----:|
| 🃏 | **曲风卡片** | 结构化知识卡：起源 / 特征 / 谱系辨析 / 听感锐评 | `01-曲风卡片/` | ✅ |
| 🎧 | **例曲歌单** | 3–5 首必听 + 「听什么」提示 + 听后记录 | `02-例曲歌单/` | ✅ |
| 🗺️ | **谱系图 / 时间线** | Mermaid 关系图（全局，非每曲风） | `00-总纲/` | ✅ |
| 🎛️ | **编曲小样** | 复现该曲风核心特征（DAW / LilyPond） | `03-编曲小样/` | ⭕ 加分项 |

> 前 3 项 = 「了解」的主干；**编曲小样是加分项，不做也不欠债**。

## 3 · 七期时间线（速览）

| 期 | 年代 | 一句话 | 本期曲风 |
|:--:|------|--------|---------|
| **0** | 1967–1979 | 合成器落地 + Disco 建立「舞曲」这套操作系统 | Disco |
| **1** | 1980–1988 | 三源并起：芝加哥 House · 底特律 Techno · Acid | Chicago House · Detroit Techno · Acid House |
| **2** | 1988–1994 | Rave 大爆炸后分裂：把拍子拆成碎拍 | Breakbeat Hardcore · Jungle · Gabber · Trance · Progressive House · Deep House |
| **3** | 1994–2001 | 黄金年代：超级 DJ · 大型俱乐部 · 旋律登顶 | Drum and Bass · Progressive Trance · Uplifting Trance · Psytrance · Minimal Techno |
| **4** | 2001–2009 | 回摆：Trance 退潮 · Electro/Minimal 上位 · Dubstep 出土 | Electro House · Minimal · Dubstep |
| **5** | 2009–2015 | EDM 大爆炸：Big Room 与音乐节产业化 | Big Room · Deep House 回潮 · Future Bass/Trap |
| **6** | 2015–今 | 再地下与本地化：Techno 回潮 · 全球南声音 | Melodic Techno · Afro House/Amapiano · Hard Techno · Phonk |

→ 详版（每期背景 / 技术 / 关键事件 / 代表作）见 [00-总纲/演进时间线.md](00-总纲/演进时间线.md)
→ 关系图（谁生谁）见 [00-总纲/谱系图.md](00-总纲/谱系图.md)

* 卡片 `01-曲风卡片/Disco.md`
* 歌单 `02-例曲歌单/Disco.md`

* ⚠️ 三处**同名** → 双链**必须带路径**，否则 Obsidian 分不清：
  * 卡片 ↔ 歌单：`[[01-曲风卡片/Disco]]` ｜ `[[02-例曲歌单/Disco]]`
  * 卡片 ↔ 小样：`[[03-编曲小样/Disco]]`
* 引用参考底本（跨 vault）：用**相对 Markdown 链接**（`../MusicResearch/Genres/Disco.md`），不用 `[[]]`

**字段约定**
* **`L` = Like · 个人喜好程度（0–10 分）** —— **不是**重要性 / 质量 / 历史地位
  * 记在**曲目级**（歌单 §2 曲目表的 `L` 列）
  * **曲风级 L = 该歌单所有曲目 L 的中位数**（数据驱动，别凭印象给整个曲风打一个分）

* 曲风名互链时：**本项目 16 种曲风内**才用 `[[]]`；`Funk` / `Soul` 等外部曲风写**纯文本**（参考底本是另一个 vault，双链连不上）

## 5 · 推进方式（每曲风一个循环）

```
① AI 系统讲解该曲风（起源 → 特征 → 谱系 → 代表作，对齐历史分期）
        ↓
② 自己听：按歌单听 3–5 首 → 写「听后记录」（不查资料，先写直觉）
        ↓
③ 自己产出卡片：套模板，重点填「辨析」与「听感锐评」
        ↓            （AI 只批改/补充，不代写）
④ 更新 曲风索引 进度：☐ → ◐ → ☑
        ↓
⑤ 可选：编曲小样复现特征
```

> **弹性原则**：随时可停；卡片不追求填满，缺的字段留空即可；**中断不补欠债**。
