# Disco

> **“舞曲”模式的发明者** —— 四踩底鼓、DJ 混音、12″ 加长版、Remix 全部从它开始；听感是“华丽、持续推进、不给你喘息”。

**上位**：Soul · Funk · R&B ＋ 合成器前史
**下位**：[[Chicago House]] · [[Detroit Techno]] · [[Deep House]] · Hi-NRG / Italo Disco · Nu-Disco
**易混**：Funk · Soul · Eurodisco

## 1 · 起源

| 项目        | 内容                                                                                                                           |
| --------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 诞生时间      | 1960s 术语用于纽约地下派对；1972–1974 成形；1975–1978 商业爆发                                                                                 |
| 发源地 / 场景  | **场景**：纽约地下派对（The Loft · The Sanctuary · The Gallery）＋ 费城录音室（Sigma Sound · Philadelphia International）；**社群**：黑人 · 拉丁裔 · 同性恋 |
| 关键技术 / 设备 | Moog 合成器 · 多轨录音 · 12″ 单曲（1976 首张商用）· Tom Moulton 的 Re-edit / Break 段落 · 两台唱盘 + DJ 混音台                                        |
| 命名来源      | 法语 discothèque（唱片图书馆）→ 指播放唱片的舞厅，后指其音乐                                                                                        |
| 出现原因      | Soul / Funk 的乐队编制 + DJ 而非乐队的地下派对；DJ 需要更长、低频更强、能无缝接歌的版本 → 12″、Remix、长 Intro                                                   |

**关键人物**：David Mancuso（The Loft）· Francis Grasso（最早用双唱盘无缝 beatmatch）· Tom Moulton（Re-edit 之父）· Larry Levan（Paradise Garage，后成 House 教父）· Nile Rodgers & Bernard Edwards（Chic）· Giorgio Moroder + Pete Bellotte · Gamble & Huff / Thom Bell（费城之声）

**关键唱片**：MFSB《Love Is the Message》(1973) · Double Exposure《Ten Percent》(1976, 12″ mix) · Donna Summer《I Feel Love》(1977)

## 2 · 音乐特征

| 维度       | 内容                                                                                                                                                                                                                     |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 速度       | 110–130 BPM（典型 120）<br>**慢档**（111–117，真乐队 / 灵魂派）：Good Times（111）· MFSB（114）· I Will Survive（117）<br>**快档**（128–132，机器 / 欧陆派）：I Feel Love（128）· Disco Inferno（129）· Mighty Real（132）<br>Hi-NRG 前身：“更快更机械”在 Disco 内部已经成形 |
| 拍号 / 节奏型 | 4/4，四踩底鼓（four-on-the-floor）：每拍一下；军鼓落 2、4 拍；开镲走 8 分，shaker / 打击乐填 16 分                                                                                                                                                  |
| 鼓组       | 真鼓（或真鼓 + 合成叠加）；底鼓干燥有力、军鼓明亮、开镲明显靠前                                                                                                                                                                                      |
| 低音       | **电贝斯（真贝斯）**：八度跳跃 + 切分，低音负责律动；**标杆**：Bernard Edwards（Chic）                                                                                                                                                             |
| 和声 / 旋律  | Maj7 / 9 / 11 + m7（爵士味大和弦）；弦乐上行 riff 推进；借降号级数（♭VII / ♭VI）制造“暗 / 前卫”（I Feel Love）；转调升 key 是常用高潮手法之一                                                                                                                     |
| 标志音色     | 电钢 Rhodes · Clavinet · 弦乐组 · 铜管 · 节奏吉他（16 分闷音切分，Nile Rodgers 式）；1977 后加入合成器（Moog Bass / Arpeggio）                                                                                                                      |
| 结构       | 长 Intro（给 DJ 接歌）→ Verse → Chorus → 器乐 Breakdown / Solo → 转调 Chorus → Outro；12″ 版常 7–10 分钟                                                                                                                              |
| 混音 / 空间感 | 弦乐高位铺宽、人声靠前、中频拥挤但通透；低频紧凑不轰（因为要经俱乐部大系统播放）                                                                                                                                                                               |

> **术语**：[[术语表#四踩（Four-on-the-floor）|四踩]] · [[术语表#反拍（Off-beat）|反拍]] · [[术语表#八度跳跃贝斯（Octave Bass）|八度跳跃贝斯]] · [[术语表#转调升 key（Modulation）|转调升 key]] · [[术语表#降号级数借用（Modal Mixture）|降号级数]] · [[术语表#Break|Break]] · [[术语表#Breakdown|Breakdown]] · [[术语表#Fill（加花 / 过门）|Fill]] · [[术语表#12″ 单曲|12″ 单曲]] · [[术语表#Roll（滚奏）|Roll]]

## 3 · 演进史

| 阶段     | 年代        | 发生了什么                                                                                                                                                              |
| ------ | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **诞生** | 1970–1974 | 纽约地下派对（Loft / Sanctuary）＋ 费城之声奠定乐手编制；MFSB《Love Is the Message》(1973) 定义节奏基底                                                                                        |
| **爆发** | 1975–1978 | 1975《The Hustle》带动舞蹈热 → 1977《Saturday Night Fever》全球现象 ＋ 《I Feel Love》技术跳跃 → 1978 全盛                                                                               |
| **转折** | **1979**  | Disco Demolition Night（1979-07-12，芝加哥 Comiskey Park 当众砸唱片，带种族 / 恐同色彩）→ 电台转向，主流反冲，Disco 退回地下                                                                        |
| **现状** | 1980s →   | 化名延续：Boogie / Post-disco · Hi-NRG · Italo Disco · Garage（Paradise Garage / Larry Levan）→ 1984 Chicago House 直接继承；今天以 Nu-Disco / Disco House / 采样（Daft Punk 一代）持续回流 |

## 4 · 谱系与辨析

* **继承了什么**：Soul / Funk / R&B 的**乐队编制**、**爵士和弦语汇**、人声传统；＋ 1970s 合成器前史的技术条件
* **又加了什么**：★**四踩底鼓**（把 Funk 的碎律动压成**规则脉冲**，才能长时间跳舞）· ★**DJ 工具化**（12″ / Remix / 长 Intro / Break 段落）· ★**舞池反馈创作循环**（先给 DJ，看舞池反应再定推不推）
* **生出了谁**：[[Chicago House]]（乐手全换成机器）· [[Detroit Techno]]（节奏骨架 + 未来主义）· [[Deep House]]（继承温暖音色与爵士和弦）· Hi-NRG / Italo Disco（合成器化一支，《Mighty Real》是起点）· Nu-Disco（现代回流）

**易混对比**

|     | **Disco**                 | Funk                            | Soul                 |
| :-- | ------------------------- | ------------------------------- | -------------------- |
| 速度  | 110–130 BPM               | 95–115 BPM                      | 60–100 BPM（偏中速 / 叙事） |
| 节奏  | **四踩底鼓**（规则脉冲，"推着走"）      | **碎、切分重**，律动由贝斯主导（强调 "The One"） | 摇摆、后拍，节奏服从人声         |
| 音色  | 弦乐 + 电钢 + 开镲明亮；1977 后加合成器 | 铜管 + 电吉他 + Clavinet，**脏**、有攻击性  | 管风琴 + 人声为主           |
| 听感  | 持续跳舞的**推进感**、华丽、不知疲倦      | 律动**咬合**、"放克劲儿"，会让人点头而非持续跳      | 情感表达为主，适合**听**       |
| 用途  | 舞池持续运动                    | 律动 / 炫技                         | 聆听                   |

> 另辨：**Eurodisco / Moroder 派** = Disco 的**合成器化分支**，鼓与 Bass 由机器执行、人声更冷 → 这就是通往 [[Detroit Techno]] 的那条路。

## 7 · 听感锐评

舞池性、律动感很强；可以复古，也可以融合现代元素；能量不会太高，但是能很好地调动情绪；速度适中

## 8 · 编曲复现（可选）→ [[03-编曲小样/Disco]]

* **要复现的 3 个特征**：
  1. **持续脉冲**：四踩底鼓 + 开镲 8 分 + 打击乐 16 分（"永不疲倦"的来源）
  2. **八度跳跃真贝斯 riff**（Bernard Edwards 式，律动的发动机）
  3. **弦乐上行 + Fill 分段**（不用 drop：靠"累积 + 加层 + Fill 报信"造高潮；升 key 是可选加强）
* **BPM / 调性**：**120 上下**（实测分两档：慢档 111–117 / 快档 128–132）；调性用**大调** —— 实测 **C / D / B♭ 大调**，建议 **D 大调**（弦乐明亮好写）
* **FL 工具链**（据 `00-总纲/资源清单.md`）：FPC / Toontrack 鼓 · **Ample Sound / SWAM 真贝斯** · Omnisphere 弦乐 · FL Keys 电钢 · Fruity Chorus + Fruity Reeverb 2；★**和弦与贝斯用 MIDI 键盘弹**（这类曲风的灵魂就是"像人在弹"）
* **结构**：Intro 16 → Verse 16 → Chorus 16 → Break 8 → 转调 Chorus 16 → Outro 8
