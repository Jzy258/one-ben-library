* 时序图：
	* `sequenceDiagram`
	* 展示多个角色之间按时间顺序的消息往来
* `participant ID as 显示名`：
	* 参与者
* `actor ID as 显示名`：
	* 参与者，显示成人形
* 消息箭头：
	* 用 `:` 分隔箭头声明和标签，一行内的后续毛猴都会被视为普通文本
	* `A ->> B`：
		* 实线箭头
		* 同步调用 / 请求
	* `A -->> B`：
		* 虚线箭头
		* 异步返回 / 响应
	* `A -) B`：
		* 实线实心箭头
		* 同步返回
	* `A --x B`：
		* 虚线叉箭头
		* 失败 / 中断
* 激活框：
	* 指示当前正在处理的参与者
	* `activate ID`：
		* 参与者开始处理
	* `deactivate ID`：
		* 参与者处理结束
	* `activate` 和 `deactivate` 必须配对
* 分支：
	* `alt 分支1` ... `else 分支2` ... `end`：
		* 二选一
	* `opt 标签` ... `end`：
		* 可选
	* `loop 标签` ... `end`：
		* 循环
* 注释：
	* 悬浮注释：
		* `Note over IDs 注释`
		* 可以横跨多个参与者
	* 单侧注释：
		* `Note left of ID`
		* `Note right of ID`
