* 类图 `classDiagram`：
	* **作用**：描述类、属性、方法、类之间的关系
* 定义类成员：
	* **包括**：
		* 定义类：`class 类名 { ... }`
			* `class` 可省略
		* 属性：`可见性 类型 属性名`
		* 方法：`可见性 方法名(参数) 返回类型`
	* 可见性：
		* `+` = `public`
		* `-` = `private`
		* `#` = `protected`
		* `~` = `package`
	* 后缀标记：
		* `*`：抽象
		* `$`：静态
	* `<<interface>>`：接口
	* `<<abstract>>`：抽象类
	* `<<service>>`：业务层
* 关系：
	* 继承 / 泛化：`--|>`
	* 实现：`..|>`
	* 组合：`--*`
	* 聚合：`--o`
	* 关联：`-->`
	* 依赖：`..>`
* 基数：
	* **例**：`A "1" --> "0..*" B`
* 注释：
	* **例**：`note for A "注释"`
