* 数据通信系统模型：
	* 源系统（发送端、发送方）
	* 传输系统（传输网络）
	* 目的系统（接收端、接收方）
* 源系统组成：
	* 源点（Source，源站，信源）：
		* 产生需要传输的数据
	* 发送器：
		* **作用**：编码源点产生的数字比特流
		* **如**：调制器
			* 很多计算机使用内置的调制解调器（包括调制器和解调器）
* 目的系统组成：
	* 接收器：
		* **作用**：
			* 从传输系统接收信号，转换为能被目的设备处理的信息
		* **如**：解调器
	* 终点（Destination，目的站，信宿）：
		* 从接收器获取数字比特流并输出
* 消息（Message）：
	* 文字、音频、图像、视频等
* 数据（Data）：
	* 运送消息的实体
	* 使用特定方式表示的消息
	* 有意义的符号序列
* 信号（Signal）：
	* 数据的电气或电磁表示
* 模拟信号（连续信号）：
	* 消息的参数取值是连续的
* 数字信号（离散信号）
	* 消息的参数取值是离散的
* 码元：
	* 代表不同离散数值的基本波形
	* 一个码元携带的信息量由调制方式和编码方式决定
* 信道（Channel）：
	* 向某一个方向传送信息的媒体
* 信息交互方式：
	* 单向通信（单工通信）：
		* **定义**：只存在一个方向的通信
		* **如**：无线电广播、有线电广播、电视广播
		* **特点**：需要一条信道
	* 双向交替通信（半双工通信）：
		* **定义**：通信双方都可以发送消息，但不能同时
		* **特点**：需要两条信道
	* 双向同时通信（全双工通信）：
		* **定义**：通信双方可以同时发送和接收消息
		* **特点**：需要两条信道；传输效率最高
* 基带信号（基本频带信号）：
	* **定义**：来自信源的信号
	* **特点**：包含较多低频分量（甚至直流分量）
* 调制（Modulation）：
	* 基带调制（编码，Coding）：
		* **定义**：
			* 仅变换基带信号的波形，使之适应于信道特性
		* 变换结果：基带信号
	* 带通调制：
		* **定义**：
			* 使用载波（Carrier）将基带信号的频率范围搬移到较高频段，并转换为模拟信号
		* **适用于**：模拟信道传输
		* 带通信号：经过带通调制后的信号
* 常用编码方式：
	* 不归零制：
		* `1` = 正电平
		* `0` = 负电平
	* 归零制：
		* `1` = 正脉冲
		* `0` = 负脉冲
	* 曼彻斯特（Manchester）编码：
		* `1` = 位周期中心的向下跳变
		* `0` = 位周期中心的向上跳变
		* 可以反过来定义
		* **特点**：
			* 信号频率比不归零制高
			* 具有自同步能力（能从信号波形中提取时钟周期）
	* 差分曼彻斯特编码：
		* 位周期中心始终有跳变
		* `1` = 改变位中心跳变方向 / 位开始没有跳变
		* `0` = 保持位中心跳变方向 / 位开始有跳变
* 基本带通调制方法：
	* 调幅（AM）：
		* 载波的振幅随基带数字信号变化
	* 调频（FM）：
		* 载波的频率随基带数字信号变化
	* 调相（PM）：
		* 载波的初始相位随基带数字信号变化
* 正交振幅调制（QAM，Quadrature Amplitude Modulation）
* 信道的极限容量：
	* 码间串扰：
		* 接收端收到的信号波形受信道频率范围限制的影响，失去码元之间的清晰界限
	* 奈氏准则：
		* 在带宽为 $W$ 的低通信道中，若不考虑噪声影响，则码元传输的最高速率为 $2W$，超出此上限就会出现严重的码间串扰
	* 信噪比：
		* 信号的平均功率和噪声平均功率之比
		* 单位：
			* dB
		* $ 信噪比 = 10 \log _{10} \frac{S}{N} $
	* 香农公式：
		* **定义**：$C = W \log _2 (1 + \frac{S}{N})$
			* $C$：信道的极限信息传输速率
			* $W$：信道的带宽
			* $S$：信道内所传信号的平均功率
			* $N$：信道内部的高斯噪声功率
		* 信道的带宽或信道中的信噪比越大，信息的极限传输速率越高
		* 只要信息传输速率低于信道的极限传输速率，就能通过某种方式实现无差错的传输
		* 实际信道中，信号会受到脉冲干扰、传输失真等损伤，导致实际传输速率低于极限传输速率
	* 提高信息传输速率的方法：
		* 拓宽频带宽度
		* 提高信噪比
		* 使每个码元携带更多信息量
