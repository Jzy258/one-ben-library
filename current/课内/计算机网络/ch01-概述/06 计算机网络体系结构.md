* 计算机网络通信的要求：
	* 有能够传送数据的通路
	* 发送方能激活（Activate）通路
	* 网络能识别接收方
	* 发送方能了解接收方是否准备好接收和存储文件
	* 文件格式兼容
	* 异常和差错处理，保证可靠性
* 系统网络体系结构（SNA，System Network Architecture）
* OSI / RM：
	* ISO 制订的标准框架
	* 抽象概念，没有实现
* TCP / IP
* 网络协议：
	* 为了进行网络中的数据交换建立的规则、标准和约定
	* 表示形式：
	    * 文字描述
	    * 程序代码
* 分层的优点：
    * 各层之间独立
    * 灵活性好
    * 易于实现和维护
    * 能促进标准化
* 各层完成的主要功能：
    * 差错控制
    * 流量控制
    * 分段和重装
    * 复用和分用
    * 连接建立和释放
* 网络接入模块：
    * 负责实现与网络接口细节有关的工作
* 网络的体系结构（Network Architecture）：
    * 计算机网络各层及其协议的集合
    * 包括其功能的精确定义
* 体系结构是抽象的，实现是具体的
* 五层协议：
    * 应用层（Application Layer）：
        * 任务：
            * 通过进程间的交互完成特定网络应用
        * 协议：
            * 定义应用进程之间通信和交互的规则
        * 包括：
            * DNS、HTTP、SMTP
        * 报文：
            * 应用层交互的数据单元
    * 运输层（Transport Layer）：
        * 任务：
            * 负责为进程通信提供通用的数据传输服务
        * TCP（Transmission Control Protocol，传输控制协议）：
            * 提供面向连接的、可靠的数据传输服务
            * 数据传输单位：
                * 报文段（Segment）
        * UDP（User Datagram Protocol）：
            * 提供无连接的尽最大努力的数据传输服务
            * 不保证数据传输的可靠性
            * 数据传输单位：
                * 用户数据报
    * 网络层（Network Layer）：
        * 任务：
            * 负责为分组交换网上的不同主机提供通信服务
            * 在路由器上生成转发表，并依据转发表中的路径将分组转发到下一个路由器
        * 数据传输单位：
            * 分组（包）
            * 使用 IP 协议则称为 IP 数据报
        * 互联网由大量的异构（Heterogeneous）网络通过路由器（Router）相互连接
        * 网络层协议：
	        * IP（网际协议，Internet Protocol）
    * 数据链路层（Data Link Layer）：
        * 任务：
            * 实现两个相邻节点之间的可靠通信
        * 数据传输单位：
            * 帧（Frame）
                * 包含控制信息（同步信息、地址信息、差错控制）
    * 物理层（Physical Layer）：
        * 任务：
            * 实现数字信号的传输
                * 确定 1 和 0 的表示电压
                * 确认引脚数量和连接方式
        * 传输数据单位：
            * 比特
* 协议数据单元（PDU，Protocol Data Unit）：
	* OSI 参考模型中对等层次（Peer Layer）之间传送的数据单位
* 实体（Entity）：
    * 可发送或接收信息的硬件或软件进程
* 协议：
    * 控制两个**对等实体**进行通信的规则的集合
    * 定义了发送者和接收者需要完成的操作
    * 需要下层提供的服务，下层的协议对上层的实体透明
* 服务访问点（Service Access Point，SAP）：
    * 同一系统中相邻两层的实体进行交互的地方
* 服务数据单元（Service Data Unit）：
    * 层与层之间交换数据的单位
    * 可以与 PDU 不同
        * 可以合并或划分
* TCP/IP 体系结构：
    * 不遵循严格的 OSI 分层
    * 某些应用程序可以直接使用 IP 层或直接使用链路层
    * IP 协议能适配多种运输层协议，也能适配多种数据链路层协议
        * 网络核心越简单越好

补充：
* 计算机网络的组成（三要素）：
    * 硬件：主机（端系统）、通信设备、通信链路
    * 软件：方便用户使用，实现资源共享
    * 协议：规定通信规则，由硬件、软件共同实现
* 网卡（网络适配器）：
    * 将主机数据发送到网络上
    * 接收来自网络的数据
