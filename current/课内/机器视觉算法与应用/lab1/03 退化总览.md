* 倾斜 / 透视 / 卷曲
	* 原因：
		* 拍摄姿态 + 镜头畸变
	* 修复方法：
		* 旋转 / 单应 / 去卷曲
* 光照不均 / 阴影 / 反光
	* 原因：
		* 场景照度 $L$ 分布不均
	* 修复方法：
		* 同态 / Retinex / CLAHE
* 模糊 / 低分辨率
	* 原因：
		* 失焦 / 手抖导致 PSF 变大
	* 修复方法：
		* 去卷积 / 超分
* 噪声 / 压缩伪影
	* 原因：
		* 光子随机 + 发热 + JPEG
	* 修复方法：
		* 空域 / BM3D / DnCNN
* 偏色 / 动态范围不足：
	* 原因：
		* 白平衡估计错 + 动态范围有限
	* 修复方法：
		* 色彩校正 / AWB / 对比度增强

---
补充：
* 单应性变换（Homography）：
	* 将一个平面上的点通过数学映射投影到另一个平面上的规则
* 同态滤波（Homomorphic Filtering）：
	* 调整频域，将光照和反射分开处理
	* 用于校正光照不均
* Retinex：
	* 模拟人眼视觉，去除光照影响
	* 用于暗光增强
