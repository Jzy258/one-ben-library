* 成像流水线：
	* 场景光照 -> 镜头（聚焦）-> 传感器（光 -> 电）-> ADC（电 -> 数字）-> ISP（加工）-> JPEG（压缩）-> 图片
	* 每一个步骤都会损失信息或掺入噪声
* 图像退化原因：
	* 辐射层、几何层、传感层、数字层
* 场景光照：
	* $I (x, y) = L (x, y) \cdot R (x, y)$
		* $L$：照度
		* $R$：反射率
	* 反射率提供物体本身的信息，照度提供环境光照信息
	* 光照不均的本质：
		* $R$ 不变，$L$ 不同
	* 光照增强：
		* 常用方法：
			* 同态滤波 / Retinex
		* **本质**：
			* 将 $L$ 和 $R$ 拆分
			* 压平 $L$、保留 $R$
	* 过曝 / 欠曝：
		* $L$ 超过相机能记录的范围
		* 导致 $R$ 信息丢失
		* 只能采取规避措施
* 镜头：
	* 理想镜头：
		* 纸上一点 = 传感器上一点
	* 真实镜头存在的问题：
		* 失焦：
			* 焦距错误 -> 点变成圆斑 -> 失焦模糊
		* 手抖：
			* 曝光时间内画面移动 -> 点被拉成线 -> 运动模糊
		* 镜头玻璃差：
			* 直线变弯 -> 桶形 / 枕形畸变
	* 模糊在数学上的应用：PSF（点扩散函数）
		* 使用 PSF 作为权重对全图做卷积 -> 全图模糊
		* 不同的卷积核产生的模糊形态不同
* 传感器：
	* 散粒噪声：
		* 传感器的每个像素都是光子计数器
		* 光线弱 -> 每个像素收集到的光子少 -> 计数更随机 -> 产生散粒噪声
		* 满足泊松分布
	* 读出噪声 / 热噪声
		* 由电路发热导致
		* 满足正态分布
	* 传感器表面贴一层 CFA（彩色滤光片阵列），每个像素只记录一种颜色，后期通过去马赛克插值合成 RGB
		* 会放大噪声，导致边缘出现彩色伪影
	* 动态范围：
		* 传感器的亮暗跨度有限
		* 逆光 / 强光场景会导致亮处白 / 暗处黑
* 白平衡：
	* 不同光源的色温不同，相机通过增益恢复三通道原色
	* 偏色本质：
		* RGB 三通道比例失衡
* JPEG 压缩：
	* 将图切分成 8 * 8 做 DCT（离散余弦变换），去除人眼不敏感的高频
	* 导致块和块之间出现**块效应** / **振铃**
* 图像形成过程的模型：
	* $g = f * h + n$
		* $h$：点扩散函数
		* $n$：噪声
	* 复原的本质：
		* 对 $h$ 和 $n$ 施加不同的先验假设反解 $f$

---
补充：
* 块效应（Blocking Artifact）：
	* 压缩图像中能用肉眼明显分辨出正方形网格边界
	* **原因**：
		* 压缩时将图像切分成 8 * 8 像素的方块，分别独立进行 DCT 和量化，导致方块与方块之间不连续
* 振铃效应（Ringing Artifact）：
	* 在图像中锐利边缘附近出现的明暗相间的震荡条纹
	* **原因**：
		* DCT 变换时削减了边缘区分所需要的高频分量
		* 频域系数反变换为图像时导致涟漪状过冲（Overshoot）和下冲（Undershoot）
