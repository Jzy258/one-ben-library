* 视觉：
	* 成像 - 感知 - 理解
	* 人类视觉：
		* 语义 + 几何 + 物理属性的联合推断
	* 机器视觉：
		* 拆分成分类、检测、分割、深度估计、3D 重建等子任务
		* 光线 -> 镜头聚焦 -> CMOS 光电二极管换能 -> ADC 量化 -> 处理器滤波 -> 特征提取 -> 神经网络推理
* 成像：
	* 透镜组 + 对焦马达
	* 光圈叶片控光
	* 鱼眼到超长焦镜头更换
	* 传感器为平面
* 感知：
	* CMOS 使用拜尔滤色阵列（Bayer Pattern）使各像素只接收一种基色
	* 通过去马赛克插值重建彩色
	* CMOS 忠实记录光强
	* ISP 流水线对图像预处理
* 理解：
	* 边缘检测算子
	* 局部特征（SIFT）
	* CNN（Convolutional Neural Network，卷积神经网络）
		* 各种朝向的边缘检测器
* 其他处理：
	* 立体匹配
	* 注意力机制
* 计算机视觉：
	* 使计算机从图像或视频中自动获取、处理、分析和理解信息
	* 完成识别、测量、重建、决策等任务
* 机器视觉系统参与的任务：
	* 目标识别、位置检测、完整性检测、形状和尺寸检测、表面检测
* 视觉是“病态问题”：
	* **问题**：
		* 成像将三维世界投影到二维，深度、光照、材质信息在投影中丢失
		* 从二维反推三维存在无穷多解
	* 核心方法：
		* 注入合理先验
		* 约束从二维反推三维的可能性
* 视错觉：
	* 人眼对先验的过拟合

补充：
* 机器视觉系统组成：
	* 光源
	* 镜头（焦距 / 光圈 / 接口）
	* 相机（传感器 + 接口）
	* 图像采集与处理器
	* 执行机构
* 机器视觉（MV）与计算机视觉（CV）：
	* MV：工业场景 · 目标明确 · 精度与节拍优先 · 软硬一体
	* CV：通用理论 · 任务开放 · 论文与基准驱动
	* 界限在模糊（深度学习把两边拉近）
