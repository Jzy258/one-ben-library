* `np.mgrid`：
	* **作用**：生成密集多维坐标网格
	* **返回值**：矩阵
	* **例**：
		```python
		Y, X = np.mgrid[0:5, 0:3]
		# Y = [[0 0 0]  
		#  [1 1 1]  
		#  [2 2 2]  
		#  [3 3 3]  
		#  [4 4 4]]  
  
		# X = [[0 1 2]  
		#  [0 1 2]  
		#  [0 1 2]  
		#  [0 1 2]  
		#  [0 1 2]]
		```

		* 中值滤波：
