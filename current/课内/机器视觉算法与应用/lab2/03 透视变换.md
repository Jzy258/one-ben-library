* `cv2.getPerspectiveTransform(src, dst)`：
	* **作用**：根据四对对应点计算透视变换矩阵
	* **参数**：
		* `src`：
			* 源图像的选取点
			* 通常取底图内缩 10% 的矩形四角
			* 形状：`(4, 1, 2)` 或 `(4, 2)`
			* 类型（`dtype`）：`np.float32`
		* `dst`：
			* 目标图像的选取点
			* **表现**：远端向内收
			* 偏移量通常取图宽 / 高的 5% ~ 15%
			* 形状、类型同上
* `cv2.perspectiveTransform(src, H)`：
	* **作用**：对一组点应用透视变换
	* **参数**：
		* `src`：输入点集，形状为 `(N, 1, 2)` 或 `(1, N, 2)`
		* `M`：透视矩阵 $H$
	* **返回值**：应用变换后的点集，形状与 `src` 一致
* `cv2.warpPerspective(src, M, dsize)`：
	* **作用**：对整张图像应用透视变换
	* **参数**：
		* `src`：输入图像
		* `M`：透视矩阵 $H$
		* `dsize`：输出图像尺寸 `(weight, height)`
* `np.save(file, arr)`：
	* **作用**：将数组保存为 `.npy` 二进制文件
	* **参数**：
		* `file`：文件名或文件对象
		* `arr`：要保存的数组
* `np.reshape(array, shape)`：
	* **作用**：改变数组形状
	* **参数**：
		* `shape`：新形状，`-1` 自动推断一个维度
* `ndarray#tolist()`：
	* **作用**：
		* 将 Numpy 数组递归转换为 Python 原生列表
		* 将 `ndarray` 转换为 `list`
		* 将 Numpy 标量转换为 Python 基本数据类型
* `json.dump(obj, fp, ensure_ascii=True, indent=None)`：
	* **作用**：
		* 将 Python 对象序列化为 JSON 格式并写入文本对象
	* **参数**：
		* `obj`：要序列化的 Python 对象
		* `fp`：文件对象，必须以文本写入模式打开
		* `ensure_ascii`：是否将非 ASCII 字符转义为 `\uXXXX`
		* `indent`：缩进，整数或字符串，默认紧凑输出
* `os.makedirs(name, exist_ok=False)`：
	* **作用**：递归创建目录
	* **参数**：
		* `name`：目录路径
		* `exist_ok`：若目录已存在则抛出 `FileExistsError`
* `path#as_posix()`：
	* **作用**：将路径转换为使用 `/` 的字符串
