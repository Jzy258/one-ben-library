* 机器语言：
	* 机器指令的集合
* 机器指令：
	* 机器可以正确执行的命令
* **缺点**：
	* 难以使用和排错
	* 开发效率低
* 汇编语言：
	* 由汇编指令、伪指令、其他符号组成
	* 执行流程：
		* 源程序 `.asm`
		* 汇编器 -> 目标程序 `.obj`
		* 链接器 -> 可执行文件 `.exe`
	* 汇编指令：
	    * 机器指令便于记忆的书写格式（助记符）
	* 伪指令：
	    * 计算机不执行，汇编器执行
	    * 不生成机器码
	    * 包括：
		    * `segment` / `ends`（定义段）
		    * `end`（程序结束标记）
		    * ...
	* 其他符号：
		* `+` / `-` / `*` / `/` 运算符
		* `db` / `dw`
		* ...
