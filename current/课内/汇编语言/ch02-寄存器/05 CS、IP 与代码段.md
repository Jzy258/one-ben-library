* `CS`：
	* 代码段寄存器
	* 程序执行时不变
	* 只在加载程序时改变
* `IP`：
	* 指令指针寄存器
* `CS:IP`：
	* 在任何时候，CPU 都会将 `CS:IP` 指向的内存单元作为指令执行
* `IP` 的工作原理
	* 指令长度在该指令第一个字节中指定
	* `IP + 1` 实际上是加上本条指令的长度
	* 精简指令集可能统一 IP 的步进
* 8086 CPU 的工作过程：
	* 从 `CS:IP` 指向的内存单元读取指令，存入指令缓冲器
	* `IP = IP + 当前指令长度`
	* 执行指令
* 8086 CPU 加电启动或复位后，`CS` 和 `IP` 被设为 `CS = FFFFH`，`IP = 0000H`
	* `CS:IP = FFFF0H` 单元中的指令是开机第一条指令
