# 09 网络安全技术

* ACL（Access Control List，访问控制列表，防火墙）：
	* 接口调用 ACL，检查收到、发出的数据包
		* 源、目的 IP 是否允许放行
	* **作用**：提高安全性
	* **反作用**：降低转发效率
	* 需要注意方向：in/out
	* ACL 规则的书写顺序：
		* 拒绝特定 IP 地址段，最后允许其他所有流量
	* 标准 ACL 和扩展 ACL：
		* 标准 ACL：
			* **编号**：0~99
			* **行为**：只检查源 IP 地址
			* **部署位置**：尽量靠近目标端
		* 扩展 ACL：
			* **编号**：100~199
			* **行为**：检查源 IP、目标 IP、协议、端口号
			* **部署位置**：尽量靠近源
* NAT（网络地址转换）：
	* **作用**：
		* 将私有 IP 转换为公网 IP
	* 公网 IP：
		* **性质**：
			* 全球唯一
			* 需要向 IPA 付费申请
	* 私有 IP：
		* **性质**：
			* 本地唯一
			* 只能在本地局域网内通信
		* 私有 IP 地址段：
			* A 类：`10.0.0.0` ~ `10.255.255.255`
				* 子网掩码：`255.0.0.0`
			* B 类：`172.16.0.0` ~ `172.31.255.255`
				* 子网掩码：`255.240.0.0`
			* C 类：`192.168.0.0` ~ `192.168.255.255`
				* 子网掩码：`255.255.0.0`
