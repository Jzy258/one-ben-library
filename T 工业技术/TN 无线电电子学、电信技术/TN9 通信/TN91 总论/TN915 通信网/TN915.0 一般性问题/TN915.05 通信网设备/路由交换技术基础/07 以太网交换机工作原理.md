* 集线器、交换机与路由器的区别：
	* 集线器（Hub）：
		* 工作在物理层
		* **工作流程**：
			* 识别电信号 / 光信号等
			* 将收到的数据从其他接口泛洪转发
	* 交换机（Switch）：
		* 工作在数据链路层
		* **工作流程**：
			* 从入口收到数据帧
			* 查看源 MAC 地址，添加到 MAC 表中，将 MAC 地址与接口号建立映射
			* 查看目的 MAC 地址，若不等于自己接口的 IP，则查表转发
				* 一对一转发：G1/0/1 进，G1/0/2 出
				* 不会转发的数据帧：泛洪转发，从其余所有接口转发
		* **工作依据**：MAC 表
		* **特点**：
			* 接口数量多、类型少
			* 设备功能少
		* **如**：校园网
	* 路由器：
		* 工作在网络层
		* **工作流程**：
			* 收到数据包，查看目的 IP 地址，若不等于自己接口的 IP，则查表转发
				* 一对一转发：G0/0 进，G0/1 出
				* 不会转发的数据包：丢弃
		* **特点**：
			* 接口数量少、类型多
			* 设备功能多
		* **如**：ISP 网络
* 广播域：
	* **定义**：一个广播帧能够传递的范围
	* 路由器能用于隔离广播域
* VLAN（Virtual Local Area Network，虚拟局域网）：
	* **作用**：将广播域划分成多个小广播域
	* 可以将交换机广播转发的范围缩小，只在指定 VLAN 中广播
	* **标签格式**：
		* 遵循 IEEE 802.1Q 协议
		* 总计 4B
* access 接口：
	* **适用于**：交换机连接终端
	* **工作机制**：
		* 若收到不携带 VLAN 标签的数据帧，则自动打上接口所属的 VLAN 标签
		* 若从 access 接口将数据帧发送到终端设备，则自动剥离 VLAN 标签
		* 若收到数据帧的 VLAN 标签与自己的 PVID 不同，则直接丢弃
* trunk 接口：
	* **适用于**：交换机连接另一台交换机
	* **工作机制**：
		* 发送数据帧时，检查帧属于哪个 VLAN，并插入 VLAN 标签
		* 若收到带标签的数据帧，则读取 VLAN ID，并转发给对应 VLAN 的接口
	* 本征 VLAN（Native VLAN）：
		* **定义**：交换机出厂时的默认的 VLAN，默认为 VLAN 1
		* 必须保证传输两端 trunk 接口的本征 VLAN 一致，否则会导致 VLAN 串扰（Leaking），即不同 VLAN 的数据合并到同一 VLAN 中
* 动态 VLAN：
	* **定义**：
		* 不依赖交换机固定接口，而根据接入设备的身份信息（如 MAC 地址、IP 地址、用户账号等）动态决定所属 VLAN 的技术
* hybrid 接口：
	* 结合了 access 接口和 trunk 接口的优点
	* **工作流程**：
		* 接收数据帧（与 trunk 接口相同）：
			* 若带标签，则检查该 VLAN 是否在接口配置的允许通过列表中
				* 若允许，则接收，否则丢弃
			* 若无标签，则接收打上接口缺省 VLAN 标签
		* 发送数据帧：
			* 可以发送接口指定 VLAN 标签的数据帧、PVID（缺省 VLAN ID）标签的数据帧、剥离 VLAN 标签的数据帧
			* 可以精细配置
	* **适用于**：
		* 动态 VLAN
* 汇聚层交换机：
	* **作用**：
		* 汇聚来自接入层交换机的流量，并进行初步处理，然后转发给上层核心层交换机
		* 实现负载均衡
* STP（Spanning Tree Protocol，生成树协议）：
	* **问题**：
		* 交换机泛洪转发容易造成广播风暴
		* 交换机的冗余线路容易形成环，导致广播帧将在物理环路上无限循环转发
		* 网络运行时间越长、广播帧越多，在线路带宽固定的情况下，带宽的利用率不断降低
	* **原理**：在通讯网络形成的图中寻找最小生成树
	* **工作流程**：实现负载均衡
		* 若网络正常，则 STP 通过计算，选出冗余线路并将其阻塞
		* 若网络故障，则 STP 再次计算，放行阻塞的接口，保证网络的连通性
	* 交换机默认开启 STP 协议，能自动消除环路
	* **作用**：消除环路，计算最短路径
	* 收敛：
		* **定义**：
			* 网络拓扑结构发生变化，交换机重新计算并达成一致的过程
	* **缺点**：
		* 计算冗余线路上的冗余接口，需要消耗 CPU 资源
		* 计算过程耗时长，故障恢复在秒级别，不符合当前网络需求
	* **改进**：
		* RSTP（Rapid Spanning Tree Protocol，快速生成树协议）：
			* STP 的优化版
			* **作用**：实现快速收敛
		* PVST（Per-VLAN Spanning Tree，每 VLAN 生成树）：
			* **核心思想**：为交换机上配置的每一个 VLAN 都运行一个生成树
		* MSTP（Multiple Spanning Tree Protocol，多生成树协议）：
			* **实现**：将多个 VLAN 映射到同一个生成树实例
* 链路聚合：
	* 将多条线路、多个接口当作一条线路、一个接口使用
	* STP 会将多条线路视为一条，不会阻塞多连的线路
	* **作用**：
		* 增加链路带宽
		* 提高链路可靠性
	* 个人 PC 通常有两个网口：有线 + 无线
	* 服务器通常有多个网口
	* **聚合方式**：
		* 强制、手动聚合：
			* 不经过协商，通过虚拟接口技术强制加入聚合组
		* 协商聚合：
			* 运行 LACP 协议
			* 运行 PAgP 协议
	* 参与聚合的物理接口必须性质相似（带宽相同、双工方式相同），没有特殊的配置
	* Cisco 中对聚合链路的实现：`Port-channel`
* IP 相关服务：
	* DNS 服务器
	* DHCP 服务器
* DHCP（Dynamic Host Configuration Protocol，动态主机配置协议）：
	* **作用**：主机开启后，网卡通过 DHCP 获取 IP 地址
	* **工作流程**：
		* Discover：新接入的设备广播（255.255.255.255）寻找 DHCP 的请求包
		* Offer：DHCP 收到请求，从地址池中挑选可用的 IP 地址
		* Request：客户端收到 IP 地址，广播确认收到的请求包
		* Acknowledge：DHCP 收到请求，正式分配 IP 地址，并发送确认包，附带子网掩码、默认网关、DNS 服务器地址等
* DNS（Domain Name System，域名系统）：
	* **作用**：通过域名获取 IP 地址
	* **域名优点**：便于记忆
	* DNS 服务器与城市、ISP 相关
* 直通线和交叉线：
	* 直通线（Straight-through）：
		* **特点**：两端线序相同，引脚一一对应
		* **主要用途**：连接不同的设备
	* 交叉线（Crossover）：
		* **特点**：两端线序不同，引脚交叉
		* **主要用途**：连接相同设备
	* **原理**：
		* 发送方的发送端必须接到接收方的接收端
		* 终端与交换机的发射 - 接收端天然相反，使用直通线即可
		* 交换机与交换机的接口相同，需要使用交叉线
	* 现今的线路可以通过**自动翻转**功能实现自适应
* 【实验三】实现 VLAN & 链路聚合 & DHCP 配置：
	* `(config-if)# channel-group <NO> mode active`：
		* 将当前物理端口加入端口通道组中
	* `(config-if)# switchport trunk encapsulation dot1q`：
		* 将交换机端口封装为 802.1Q 协议
	* `(config-if)# switchport trunk native vlan <NO>`：
		* 设置交换机端口的本征 VLAN
	* `switchport trunk allowed vlan <NO>`：
		* 设置交换机接口放行的 VLAN
	* `switchport mode trunk`：
		* 将交换机接口的模式设为 trunk
	* `ip dhcp excluded-address <IP>`：
		* 设置 DHCP 的排除 IP 地址
	* `ip dhcp pool <VLAN>`：
		* 进入 DHCP 地址池管理模式
	* `network <ADDRESS> <MASK>`：
		* 设置地址池所在子网
	* `default-router <ADDRESS>`：
		* 设置默认网关
	* `dns-server <ADDRESS>`：
		* 设置 DNS 服务器地址
