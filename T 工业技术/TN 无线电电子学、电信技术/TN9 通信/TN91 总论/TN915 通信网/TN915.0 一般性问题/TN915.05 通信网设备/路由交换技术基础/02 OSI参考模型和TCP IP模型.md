# 02 OSI参考模型和TCP IP模型

* 网络通信设备：
	* 无线 AP
	* 路由器
	* 交换机
	* 防火墙
* 代表厂商：华三、思科
* OSI（开放系统互联）参考模型：
	* **包括**：
		* 物理层：
			* **作用**：规定接口、线路使用什么标准
			* **包括**：
				* 有线：
					* 铜丝、光纤、同轴电缆、双绞线
				* 无线：
					* 蓝牙、红外、Wi-Fi
				* 设备：
					* 交换机
		* 数据链路层：
			* **作用**：标记数据转发过程中的**一段**链路
		* 网络层：
			* **作用**：
				* 负责数据转发过程中从起点到终点的所有转发管理
				* 使用 **IP 地址**标记接口，实现寻址、路由选择
			* IP 地址：
				* **包括**：
					* 网络地址、主机地址
				* **表示方式**：点分十进制
			* 可路由协议（Routed Protocol）
			* 路由协议（Routing Protocol）：
				* **作用**：在路由器之间传递信息，计算路由并形成路由表，为可路由协议选择路径
			* 路由器最多只需要解析到网络层
		* 传输层：
			* **作用**：
				* 负责数据转发过程中的传输服务
				* 使用**端口号**标记上层应用程序
				* 分段上层数据
			* **包括**：
				* TCP、UDP
			* 分段：
				* **定义**：将传输的内容拆分成若干份，并标记端口号、IP 地址等信息
			* 面向连接的服务：
				* **特征**：可靠传输，传丢了重传
				* **适用于**：文件下载
			* 无连接的服务：
				* **特征**：尽力而为
				* **适用于**：直播
		* 会话层：
			* **作用**：
				* 通过 OS 调度，保障多个应用程序同时使用网络
				* 建立、维护、管理 `应用 - 操作系统 - 网络` 会话
		* 表示层：
			* **作用**：负责数据的表示、压缩等
		* 应用层：
			* **作用**：提供应用程序接口
			* **包括**：HTTP 协议
	* **作用**：
		* 将网络通信从硬件到软件分为 7 步，规定各层协议
	* **分层**：
		* 主机层：上三层
			* 由软件开发人员管理
			* 涉及 APP、OS
		* 媒体层：下四层
			* 由网络工程师管理
			* 涉及硬件、传输
* TCP/IP：先有具体协议，后总结模型
	* **包括**：网络接口层、网络层、传输层、应用层
