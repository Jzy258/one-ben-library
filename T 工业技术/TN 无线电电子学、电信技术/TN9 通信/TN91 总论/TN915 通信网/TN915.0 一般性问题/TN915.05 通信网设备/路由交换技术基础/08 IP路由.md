* 路由：
	* **定义**：
		* 指导 IP 报文转发的路径信息
		* 转发 IP 报文
* 子网：
	* **作用**：
		* 将大网络划分成多个小网络，增加网络的数量
	* 子网掩码：
		* **组成**：前缀的若干 1
		* **作用**：标识网络的大小范围
		* 1 的个数与网络号长度一致
* 最长匹配转发：
	* **定义**：
		* 当一个数据包的 IP 地址属于多个路由表条目，则按照最长的子网掩码（最小、最精确子网）执行转发
* 路由表查找采用递归查找，找到一个本地出口为止
* 默认路由（缺省路由）0.0.0.0/0：
	* **作用**：作为数据包转发的最后出路
	* 若数据包不属于任何一个路由表条目，则查找是否存在默认路由
		* 若不存在默认路由，则丢弃
* 直连路由：
	* 若接口的物理层 up、数据链路层 up、网络层有 IP，则该接口所在子网成为直连路由加入路由表
* 静态路由：
	* 由工程师手动添加到路由表
* 路由协议：
	* 路由器之间建立邻居关系，分享网络信息并加入路由表
	* 主流路由协议：
		* OSPF（开放最短路径优先协议）：
			* **适用于**：绝大多数园区网
		* ISIS：
			* **适用于**：绝大多数 ISP 的省网、市网
		* BGP：
			* **适用于**：跨省、跨 ISP 路由
* 网络连通性一般步骤：
	* 添加设备、连线、配置 IP、配置路由协议
* 【实验四】静态路由实现网络互通
	* `(config)# interface loopback <INDEX>`：
		* 配置环回端口
	* 路由器的环回地址作为路由器的唯一标识，通常分配一个子网专门用于配置
	* `ip route <DST> <MASK> <NEXT>`：
		* 配置静态路由
		* `<DST>`：网络号，而非具体 IP 地址
		* `<NEXT>`：下一跳地址，数据包转发至该地址，继续负责转发
* 【实验五】OSPF 实现网络互通
	* `(config)# router ospf <PID>`：
		* 启动一个 OSPF 协议进程
	* `(config-if)# network <ADDRESS> <MASK> area <NO>`：
		* 将匹配的 IP 地址加入 OSPF 区域 0（骨干区域）
