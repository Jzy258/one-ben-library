* IP 协议：
	* **定位**：网络层协议
	* **作用**：
		* 标识节点和链路
		* 寻址和转发
		* 适应各种数据链路
	* 协议头部标志位：
		* `0`：功能未开启，数值无意义
		* `1`：功能已开启
* IP 地址：
	* **组成**：
		* 网络号、主机号
	* **分类**：
		* 单播（Unicast）：ABC 类
			* A 类：`1.x.x.x ~ 126.x.x.x`
			* B 类：`128.x.x.x ~ 191.x.x.x`
			* C 类：`192.x.x.x ~ 223.x.x.x`
		* 组播（Multicast）：D 类，`224.x.x.x ~ 239.x.x.x`
		* 保留：E 类
		* 环回地址：`127.0.0.1`
		* 网段广播（Broadcast）地址：每个网络的最后一个地址
			* A 类：`X.255.255.255`
			* B 类：`X.X.255.255`
			* C 类：`X.X.X.255`
		* `0.0.0.0`：当前网卡没有 IP 地址的默认值，需要向 DHCP 服务器请求获取 IP 地址
		* `255.255.255.255`：全网广播
	* **版本**：
		* IPv4、IPv6、IPv8
* ARP（Address Resolution Protocol，地址解析协议）：
	* 已知数据包的 IP 地址，求到达该地址下一跳的 MAC 地址
* RARP（Reverse Address Resolution Protocol，反向地址解析协议）：
	* 已知 MAC 地址，求 IP 地址
* 网关地址：
	* **定义**：该网络出口路由器的接口 IP 地址
	* 可以任意设置
* 路由器单播 IP 包转发流程：
	* 数据包入站
	* 目的是否为本机？
		* 是：提交本机上层协议处理
		* 否：目的是否直连？
			* 是：解析目的主机硬件地址
			* 否：解析下一跳路由器硬件地址
		* 封装成帧并由相应出接口发出
* 主机数据包接收：
	* 发给自己的：解封装查看
	* 不是发给自己的：丢弃
* 路由器数据包接收：
	* 发给自己的：解封装查看
	* 不是发给自己的：查表转发（G0/0 接口接收，G0/1 接口发出，一对一单播），若找不到出口则丢弃
* 广播风暴：
	* PC 发出广播包，目的 IP 为 255.255.255.255，目的 MAC 地址为 FF-FF-FF-FF-FF-FF
	* 交换机收到该数据，查询目的 MAC 地址，执行单播转发，无法转发则泛洪转发
	* 路由器收到该数据，查询目的 IP 地址，执行单播转发，无法转发则丢弃数据包，不会广播，否则会引起广播风暴
* 代理 ARP：
	* 路由器收到 MAC 寻址请求，将自己的 MAC 地址假装成目标 MAC 地址回复
* 代答 ARP：
	* 路由器收到 MAC 寻址请求，直接回复目标 MAC 地址
* ICMP：
	* **作用**：
		* 测试网络连通性：
			* 使用 `ping [IP]` 命令，OS 将经过网络层封装 IP 地址和数据链路层 MAC 地址，生成 ICMP 报文，通过物理层传输
		* 故障排查：
			* 网络出现故障，对方可能回复 ICMP 消息告知故障原因
