# 06 网络通信模拟基础

* 【实验一】实现直连网络互通：
	* 连接两个路由器的 G0/0 接口，配置 IP，通过 `ping` 通讯
	* CLI（Command Line Interface，命令行操作界面）：
		* 通常用于配置路由器、交换机初始配置
	* GUI（Graphic User Interface，图形化用户界面）：
		* 通常用于配置防火墙、无线设备
	* 带外管理：
		* 通过 console 接口输入命令，命令的输出通过 console 显示给管理员
		* 专门传输管理命令，不传输用户数据
		* 适用于：初始状态
	* 带内管理：
		* 主要用于传输用户数据，可以顺便传输管理命令
		* 适用于：已经配置了 IP 地址
	* 基础配置命令：
		* `> enable`：
			* 进入特权模式
		* `# configure terminal`：
			* 进入全局模式
		* `(config)# line <INTERFACE> <NO>`：
			* 进入线路线配置模式
		* `(config-line)# exec-timeout <MINUTE> <SECOND>`：
			* 设置会话超时时间
			* 设为 0 分 0 秒则永不超时
		* `* exit`：
			* 退出到上一级模式
			* 可以使用 `Ctrl + Z` 快捷键
		* `* ?`：
			* 显示可用命令
		* `(config)# hostname <NAME>`：
			* 修改设备名称
		* `(config)# interface <INTERFACE> <NO>`：
			* 进入接口配置模式
		* `(config-if)# ip address <ADDRESS> <MASK>`：
			* 设置端口 IP
		* `# write`：
			* 保存配置到 NVRAM（Non-Volatile Random Access Memory，非易失性随机存取存储器）
		* `(config)# no <CONFIG>`：
			* 删除配置
	* 基础查看命令：
		* `# dir nvram:`：
			* 查看 NVRAM 中的所有文件
		* `# show running-config`：
			* 查看当前 RAM 中的配置
		* `# show startup-config`：
			* 查看 NVRAM 中的启动配置
		* `# show history`：
			* 查看历史命令
		* `# show version`：
			* 查看设备版本信息
		* `# show interfaces`：
			* 查看接口信息
		* `# show clock`：
			* 查看系统时钟
		* `# reload`：
			* 重启系统
	* 高端设备配置需要经过确认（Commit）才能生效
* 【实验二】通过 Telnet 远程管理设备：
	* `(config-line)# logging synchronous`：
		* 将系统弹出的日志另起一行显示，避免直接插入输入
	* `show ip interfaces brief`：
		* 显示接口物理层、网络层状态
	* 接口物理层状态：
		* `administratively down`：
			* 【默认】手动关闭，指示灯为红色
		* `down`：
			* 没有手动关闭，未连线或未加电
		* `up`：
			* 没有手动关闭，已连线并加电
