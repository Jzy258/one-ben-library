# 03 局域网基本原理

## 局域网基础

* 局域网（LAN）
* 以太网（Ethernet  II）：
	* 目前最流行的有线局域网标准
	* **本质**：数据链路层通信协议
	* **特点**：开放、简单、易于实现、易于部署
	* **常见协议**：
		* 802.3、802.11（ac 为 WiFi 5 标准，ax 为 WiFi 6 标准）
	* **分类**：
		* 共享式以太网
		* 交换式以太网
* MAC（Media Access Control，介质访问控制）地址：
	* 网卡出厂默认就有，不可修改
	* **组成**：48位二进制，12位十六进制
	* 存储在网卡的 ROM 里
	* 代表一段链路的起点和终点
* IP 地址：
	* 存储在网卡的 RAM 里
	* 代表数据包的起点和终点
* 通信方式：
	* 单播：一对一
	* 广播：一对所有
		* MAC：FF-FF-FF-FF-FF-FF
		* IP：255.255.255.255
* 流量控制：
	* 背压式流控：接收方制造冲突，发送方检测到电压异常则停止发送
		* **适用于**：半双工线路，同一时间只能一方发送数据，但双方都有能力发送数据
	* PAUSE 流控：接收方通过发送 PAUSE 帧直接通知发送方
		* **适用于**：全双工线路，双方可以同时发送数据
* 铜质双绞线：
	* **分类**：
		* 直连线
		* 交叉线
	* **接口**：RJ-45接口（水晶头）
	* 线缆顺序支持自适应，顺序错误也能通信
	* **另一种分类**：
		* STP（屏蔽双绞线）：八根铜丝外侧有金属网
		* UTP（非屏蔽双绞线）【常用】：八根铜丝外侧使用橡胶皮包裹
* 光纤：
	* **分类**：
		* 单模光纤：单一波长激光，衰耗小，传输距离远
		* 多模光纤：多波长，衰耗大
	* **材质**：
		* 玻璃丝、高透塑料
	* **特点**：
		* 性能好、传输距离长、成本低、稳定性好、速度快

## WLAN 基础

* 常见无线通信：
	* WLAN（无线局域网）≈ WiFi：适用于中小范围的无线通信
	* 4G/5G：适合中远范围的无线通信
	* 卫星：适合远距离的无线通信
	* 蓝牙、红外等
* 常见无线通信频段：
	* 2.4GHz：
		* 宽度：83.5MHz
		* 非重叠信道：3 个
	* 5GHz：
		* 宽度：325MHz
		* 非重叠信道：13 个
* 信道：工作频段的范围
* 无线覆盖原则：蜂窝式覆盖
	* 任意相邻区域使用无频率交叉的频道
	* 适当调整发送功率以避免跨区域同频干扰
