# 15 Vue3的新组件

* `Teleport`：
	* **作用**：
		* 将包裹的元素传送到其他位置，解决定位相关的问题
		* 通常用于解决 `filter` 样式导致的定位错误问题
* `Suspense`：
	* **作用**：
		* 解决页面尚未渲染完毕，而异步请求已经完成的问题
	* 常规解决方式：
		* 使用 `onMounted()` 在页面挂载完毕后再发送异步请求
	* 使用 `Suspense` 组件：
		* 将实际内容加载到 `Suspense` 的 `default` 插槽
		* 在 `fallback` 插槽中挂载加载中的提示信息
