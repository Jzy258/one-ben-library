* Vue3 项目创建脚手架：
	* `vue-cli`
	* `create-vite`
* Vite：
	* 构建工具
	* **作用**：
		* 编译、打包、优化、生成浏览器能识别的文件
* 下载并执行 `create-vite` 脚手架：
	```bash
npm create vite@版本号
	```
* 下载所需依赖：
	```bash
npm install
	```
* 启动开发环境服务器：
	```bash
npm run dev
	```
	* 默认端口：5173
* 构建生产版本：
	```bash
npm run build
	```
	* 构建产生的文件会生成在 `dist` 目录中
* 项目结构：
	* `dist`：
		* 生产环境构建输出目录
	* `node_modules`：
		* 项目依赖的 npm 包
	* `public`：
		* 纯静态资源
		* 构建工具不会做任何编译，原封不动拷贝
	* `src`：
		* 源代码
		* `App.vue`：
			* Vue 根组件
		* `assets`：
			* 图片、字体等静态资源
			* 会被 webpack 解析、打包
		* `component`：
			* 可复用的 Vue 组件
		* `main.ts`：
			* 应用入口文件
			* 用于初始化 Vue 实例
		* `style.css`：
			* 全局样式文件
		* `vite-env.d.ts`：
			* Vite 环境变量类型声明
	* `.gitignore`：
		* 用于指定 Git 忽略的文件和目录
	* `index.html`：
		* 主 HTML 入口，引入了 `main.ts`
	* `package.json`：
		* 项目配置和依赖管理
	* `package-lock.json`：
		* 锁定依赖版本，确保安装一致性
	* `tsconfig.app.json`：
		* 应用相关的 TS 配置
		* 继承 `tsconfig.json`
		* 专门配置应用源码的编译规则
	* `tsconfig.json`：
		* 主 TS 配置文件
	* `tsconfig.node.json`：
		* 专为项目中的 Node.js 相关脚本提供的 TS 编译配置
	* `vite.config.ts`：
		* Vite 构建工具配置
