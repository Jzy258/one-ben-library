# 09 组件的生命周期

* **作用**：
	* 允许在特定的时间节点执行不同的代码（钩子函数）
* Vue2 的生命周期：4 阶段 8 钩子
	* 创建：执行一次
		* 创建前 `beforeCreate`
		* 创建完毕 `created`
	* 挂载：执行一次
		* 挂载前 `beforeMount`
		* 挂载完毕 `mounted`
	* 更新：每次更新都会执行
		* 更新前 `beforeUpdate`
		* 更新完毕 `updated`
	* 销毁：执行一次
		* 销毁前 `beforeDestroy`
		* 销毁完毕 `destroyed`
* Vue3 的生命周期：4 阶段 7 钩子
	* 创建：执行一次
		* `setup`
	* 挂载：执行一次
		* 挂载前 `onBeforeMount`
		* 挂载完毕 `onMounted`【常用】
	* 更新：每次更新都会执行
		* 更新前 `onBeforeUpdate`
		* 更新完毕 `onUpdated`【常用】
	* 卸载：执行一次
		* 卸载前 `onBeforeUnmount`【常用】
		* 卸载完毕 `onUnmounted`
* 所有钩子函数的绑定都在 `setup` 阶段执行，但各个钩子函数的实际执行在各个对应的阶段
* `v-show` 和 `v-if`：
	* `v-show` 的更改被视为更新操作
	* `v-if` 值的更改被视为卸载和挂载操作
