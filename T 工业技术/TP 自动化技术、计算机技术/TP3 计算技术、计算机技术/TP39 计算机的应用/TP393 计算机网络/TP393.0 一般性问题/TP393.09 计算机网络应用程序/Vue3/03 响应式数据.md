# 03 响应式数据

* 响应式数据：
	* `setup` 中的数据修改后，`template` 中渲染的数据自动修改
* ==component `User02.vue`==
* `ref`：
	* 实现原始数据类型的响应式
	* 也支持包装对象类型的数据，底层通过 `reactive` 的代理机制实现
* `reactive`：
	* 实现对象数据类型的响应式
	* 数组的响应式：
		* 支持 `push`、`pop`、`shift`、`unshift`、`splice`、`sort`、`reverse` 等函数的调用
* Vue 指令：
	* 在 `template` 中编写
	* 格式：`v-xxx`
* `v-on`：
	* 将 `setup` 暴露的回调函数绑定到某个事件上
	* `v-on:click` 可以简写为 `@click`
	* 内置对象：`$event`，表示当前事件对象
* `v-bind`：
	* 动态绑定 HTML 属性到 Vue 实例的数据上
	* 可以绑定字符串、布尔、数组类型的属性值
		* 对 `class` 的绑定数组有特殊的处理，使用 ` ` 分隔，其余属性使用 `,` 分隔
	* 可以简写为 `:属性名="表达式"`
	* 条件绑定：
		* 通过定义变量控制属性的绑定
	* 多属性绑定：
		* 使用对象同时绑定多个属性
* `v-model`：
	* 实现双向绑定，即页面和变量数据保持一致，一方改变则另一方同时改变
	* 数据类型默认为 `string`，可以使用 `v-model.number` 指定为 `number` 类型
* `v-for`：==component `User04.vue`==
	* 遍历可迭代对象（数组、对象、范围值）
* 修改 `ref` 或 `reactive` 的引用会导致响应式失效
* `toRefs`：==component `User05.vue`==
	*  将一个 `reactive` 响应式对象转换为新对象，新对象的每一个属性都是 `ref` 的，且仍然连接到原始响应式对象
	* 不会创建新的 `RefImpl` 对象
* `toRef`：
	* 将一个 `reactive` 响应式对象的某一属性提取为 `RefImpl` 对象，且仍然连接到原始响应式对象
