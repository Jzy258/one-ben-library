* 选项式 API：
	* 将各个成分按种类放
	* 所有 `data` 放在一起，所有 `method` 放在一起，所有 `computed` 放在一起
* 组合式 API：
	* 将各个成分按用途放
	* 将用于 A 业务的数据、函数打包，将用于 B 业务的数据、函数打包...
* 组合式函数 Hooks：
	* 封装了可复用逻辑的函数
	* 一般以 `use` 开头
	* 一般统一存放在 `src/hooks` 目录下
	* 在 Hooks 中编写业务逻辑并导出，在组件中导入，实现逻辑分离
		* 可以配合解构语法分别从不同的 Hooks 中导入数据和函数
	* Hooks 中支持生命周期的钩子函数
