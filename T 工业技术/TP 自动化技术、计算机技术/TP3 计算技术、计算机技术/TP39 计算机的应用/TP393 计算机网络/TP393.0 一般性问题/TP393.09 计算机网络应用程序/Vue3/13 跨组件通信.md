# 13 跨组件通信

* props 传递：
	* **适用于**：
		* 直接父子组件之间的数据传递
* 自定义事件：
	* 只支持子向父传
	* `defineEmits()`：
		* 定义事件
		* 支持泛型指定事件名和事件参数
	* `@事件名`：
		* 将事件绑定到需要调用的函数上
		* 调用函数时只需要指定函数的引用，不需要形参列表，也不需要 `()`
			* Vue 会自动包装一层匿名函数，将 `emit` 传入的参数原封不动地传入函数
	* `emit()`：
		* 触发事件并传递参数
* `mitt`（微型事件总线）：
	* 可以实现任意组件之间的通信
	* 通常在 `utils` 目录下编写 `mitt` 工具
		* 调用 `mitt()` 获取 `emitter`
		* 导出 `emitter`
	* 在数据的接收方通过 `emitter.on(事件名, 回调函数)` 绑定事件
	* 在数据的发送方通过 `emitter.emit(事件名, 参数)` 触发事件
	* `emitter.off(事件名)` 解绑事件
	* `emitter.all.clear()` 解绑所有事件
	* 组件销毁时应将所有相关事件解绑
		* 使用 `onBeforeUnmount`
* `$attrs`：
	* 通过 props 实现在多层（> 2 层）组件中传递数据，可以在中间层中通过 `$attrs` 指代从上一层获取到的属性
	* 中间层可以通过 `defineProps()` 消费从上一层获取到的部分属性
* `$refs` 和 `$parent`：
	* 使用 `defineExpose()` 暴露数据
	* `$refs` 可以获取当前组件中的所有被 `ref` 属性标记的组件实例
	* `$parent` 可以获取当前组件的父组件的实例
* `provide` 和 `inject`：
	* 在数据发送方使用 `provide(数据名, 实际数据)` 暴露数据
	* 在数据接收方使用 `变量 = inject(数据名, 默认值)` 接收数据
* 插槽：
	* **作用**：
		* 父组件向子组件动态注入自定义内容或解构（HTML 片段、组件等）
		* 实现 UI 复用，父组件只需要向子组件提供内容
	* 默认插槽：
		* 父组件中在子组件标签内部编写的内容会替换对应子组件的 `<slot>` 标签
	* 具名插槽：
		* 在父组件的子组件标签内添加 `v-slot:插槽名` 属性，指定内部内容替换子组件的哪一个插槽
		* 子组件内的 `<slot>` 提供对应的 `name` 属性
		* 若一个子组件内有多个插槽，可以在父组件的子组件标签中使用 `<template v-slot:插槽名>` 指定
		* `v-slot:` 可以简写为 `#`
	* 作用域插槽：
		* 父组件向子组件传结构，子组件向父组件传数据
		* 父组件的子组件标签中添加 `v-slot:插槽名="数据名"`，则父组件可以通过 `数据名` 获取来自子组件的数据
			* `数据名` 数组类型
		* 子组件中添加对应属性 `<slot 数据1="实际数据1" 数据2="实际数据2"></slot>`
			* 数据会被打包为数组
