# 05 Linux系统安全与服务搭建

* SSH 免密登录：
	* 公钥 - 私钥对机制：
		* 在客户端上生产一对公钥 - 私钥对
		* 私有由客户端自行保管，公钥提交给服务器
		* 验证时，服务器使用公钥加密数据，客户端需要使用私钥解密
	* `ssh-keygen`：
		* **作用**：
			* 生成密钥对
		* `ed25519`：
			* 一种加密算法
		* 较老的系统会使用 `rsa` 算法
		* 公钥 - 私钥对默认存储位置：
			* `/用户家目录/.ssh/id_加密算法.pub`
		* `passphrase`：
			* 私钥的使用口令
		* `-t`：
			* 指定加密算法
	* `ssh-copy-id`：
		* 推送公钥
		* **本质**：
			* 将公钥复制到服务器的 `~/.ssh/authorized_keys/` 中
	* 私钥泄露的处理措施：
		* 在服务端移除公钥
	* 大多数服务器或安全环境下，只允许基于密钥登录，禁止密码登录
* Firewalld 防火墙服务：
	* **原理**：
		* Linux 内核中存在 `Netfilter` 框架，可以过滤、修改和重定向网络数据包
		* `Netfilter` 提供的可以操作的位置（5 链）：
			* `pre-routing`：
				* 网络数据包刚进入网络栈，尚未进入路由
			* `local input`：
				* 检查到目的地址为本机的数据包
			* `forward`：
				* 需要进行转发的数据包
			* `local output`：
				* 本机发出的数据包
			* `post-routing`：
				* 即将离开网络栈的数据包
		* 每个链可以进行拦截、修改、记录等相关操作，从而衍生出 4 表
		* 早期 Linux 使用 `iptables` 实现对防火墙的管理（使用 5 链 4 表）
		* 当前主流 Linux 发行版使用 `nftables` 代替 `iptables`，以解决规则增加导致网络延迟、不同协议需要单独配置的问题
		* Rocky Linux 使用 `firewalld` 增强 `nftables`，简化大多数防火墙配置
	* `firewalld`：
		* 区域（zone）：
			* 一组预先定义好的信任规则
			* 每个网络接口会被分配到一个区域中
			* 常见区域：
				* `public`【默认】：
					* 默认允许所有出栈，对入站有严格限制
				* `trusted`：
					* 允许所有入站，完全可信网络
				* `drop`：
					* 丢弃所有入站数据包
		* 服务（service）：
			* 预定义的端口和协议的组合
			* **如**：
				* HTTP 使用 TCP 80
				* HTTPS 使用 TCP 443
				* SSH 使用 TCP 22
				* MySQL 使用 TCP 3306
				* DNS 使用 UDP 53
			* 可以开放特定的端口和协议
	* `firewall-cmd`：
		* 防火墙配置和管理
		* `--list-all`：
			* 列出当前使用的区域及其规则配置
		* `--add-service`：
			* 添加放行的服务
		* `--remove-service`：
			* 移除放行的服务
		* `--add-port`：
			* 添加放行端口，支持自定义
			* `--permanent`：
				* 将自定义的端口号写入 `firewalld` 的配置中
				* 当前不生效
		* `--remove-port`：
			* 移除放行端口
		* `--reload`：
			* 重新加载配置
* SELinux：
	* 强制访问控制（MAC）安全系统
	* NSA（美国国家安全局）主导开发
	* 在 Linux 的安全基础上添加了细化的、基于策略的安全防护
	* **对比**：
		* 传统 Linux 的一个进程获取到特定用户权限后，就可以访问该用户能访问到的所有资源
		* SELinux 为每个进程授予正常工作的最小权限
	* SELinux 中，每个进程和用户被视为主体，其他资源被视为客体，系统根据主体和客体之间的安全上下文判断是否允许主体访问客体
	* 安全上下文的组成：
		* `user`：
			* **作用**：
				* 标识用户身份
			* **如**：
				* `system_u` 表示系统进程
				* `unconfined_u` 表示普通用户进程
		* `role`：
			* 用户可以访问的域集合
		* `type`：
			* 类型控制，描述资源和进程等相关的类型标签
		* `level`：
			* 用于多层安全或多类别安全的高级设置
	* `ls -Z`：
		* 显示文件的安全上下文
	* `ps -Z`：
		* 显示进程的安全上下文
	* SELinux 会检查进程的安全上下文与该进程想要访问的资源的安全上下文是否属于同类型，决定是否放行
	* SELinux 的运行状态：
		* `Enforcing`：
			* 安全策略强制执行，拦截违规行为并记录日志
		* `Permissive`：
			* 对违规行为仅记录日志
		* `Disabled`：
			* 关闭全舰防御系统
	* `semanage`：
		* 管理 SELinux 策略
		* `fcontext`：
			* 管理文件上下文映射定义
			* `-a`：
				* 添加文件上下文对象类型的记录
			* `-t`：
				* 指定对象的 SELinux 类型
* 实操：搭建私有网盘：
	* LNMP：经典的开发环境组合
		* L：Linux
		* N：nginx
		* M：MySQL
		* P：PHP
	* MySQL：
		* `mysql_secure_installation`：
			* 官方提供的安全预配置工具，一键完成最基本的安全配置
			* 匿名用户：
				* MySQL 安装后默认创建的用户
				* 用户名为 `''`
				* 允许任何人无需用户名和密码即可登录
			* 测试数据库：
				* MySQL 安装后用于测试的数据库 `test`
	* `setenforce`：
		* 设置 SELinux 功能是否启用
	* `sed`：
		* 流编辑器
		* `-i`：
			* 直接修改原文件而非输出到标准输出
		* 替换命令：
			* `s`：
				* 开始替换操作
			* `g`：
				* 全局替换，
				* 每一行所有匹配的地方都替换
	* `unzip`：
		* 用于解压缩 `.zip` 格式的压缩包
* 手工编译项目：
	* **适用场景**：
		* 官方没有提供二进制编译版本或没有适配硬件
		* 需要特定版本
	* **一般流程**：
		* 获取源码
		* 通过源码内置的构建工具 `configure` 生成编译构建文件 `Makefile` 并编辑配置
		* 通过 `make` 构建
		* 通过 `make install` 安装
		* 补全一些缺失的配置
* `dnf group install "Development Tools"`：
	* 安装官方提供的用于编译运行的工具包
* `dnf group install "RPM Development Tools"`：
	* 安装用于编译 rpm 包的工具包
	* **包括**：
		* `rpmbuild`：
			* 通过编写 `SPEC` 文件定义构建流程

补充：
* 流编辑器：
	* **特点**：
		* 非交互式：
			* 通过预先编写的命令或脚本执行
		* 面向数据流：
			* 处理来自文件或管道的输入流
	* **使用场景**：
		* 批量处理超大文件
		* 执行复杂的文本提取与转换
* 逻辑与控制运算符：
	* **原理**：
		* Linux 每条指令执行后都会返回状态码
		* `0` 表示执行成功
		* 非 `0` 表示执行失败
	* `&&`（逻辑与）：
		* 命令成功则继续执行下一条
		* 常用于解压成功后删除压缩包以节省空间
	* `||`（逻辑或）：
		* 命令失败则继续执行下一条
	* `;`（命令分隔符）：
		* 不管命令是否成功，下一条命令都会执行
