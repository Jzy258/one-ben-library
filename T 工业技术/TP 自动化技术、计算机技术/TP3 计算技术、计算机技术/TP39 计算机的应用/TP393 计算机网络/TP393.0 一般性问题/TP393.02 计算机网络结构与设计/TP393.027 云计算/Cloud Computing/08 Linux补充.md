* `top`：
	* 实时进程监控
	* 常用于排障
	* `load average`：
		* CPU 1 / 5 / 15 分钟平均负载
	* `%Cpu(s): ##.# id`：
		* CPU 空闲率
	* `MiB Mem`：
		* 内存总量 / 空闲 / 已用 / 缓存
	* **快捷键**：
		* `P`：
			* 按 CPU 使用率排序
		* `M`：
			* 按内存使用率排序
		* `Q`：
			* 退出
* 排查网络问题的顺序：
	* 确认连通
	* 确认端口
	* 测试接口
* `ping`：
	* 连通性测试
	* `-c`：
		* 指定测试顺序
* `curl`：
	* API 调试
	* `-v`：
		* 查看完整请求 / 响应
* `ss`：
	* 端口占用排查
	* `-t`：
		* 检查 TCP 端口
	* `-l`：
		* 检查监听端口
	* `-n`：
		* 显示数字端口
	* `-p`：
		* 显示进程
* Shell 脚本：
	* `变量名=值`：
		* 定义变量
		* `=` 两边不能有空格
	* `$变量名`：
		* 访问变量
	* `if [ 条件 ]; then ... else ... fi`：
		* 条件
		* `[ 条件 ]` 条件两侧必须有 ` `
	* `for i in 1 2 3; do ... done`：
		* 循环
	* `函数名() { ... }`：
		* 定义函数
		* `$数字` 作为位置参数
	* `函数名 参数列表`：
		* 调用函数并传参
	* `$?`：
		* 退出码
	* 常用判断条件：
		* `[ -f 文件 ]`：
			* 是普通文件
		* `[ -d 目录 ]`：
			* 是目录
		* `[ -z "$变量名" ]`：
			* 变量为空
		* `[ $变量1 -eq $变量2 ]`：
			* `变量1` 和 `变量2` 数值相等
		* `[ "$变量1" = "$变量2" ]`：
			* 字符串相等
	* 脚本文件一般以 `.sh` 为扩展名
	* 执行方式：
		* 直接通过文件名执行：
			* 需要执行权限
		* 显式指定解释器：
			* 如 `bash`
			* 无需执行权限
