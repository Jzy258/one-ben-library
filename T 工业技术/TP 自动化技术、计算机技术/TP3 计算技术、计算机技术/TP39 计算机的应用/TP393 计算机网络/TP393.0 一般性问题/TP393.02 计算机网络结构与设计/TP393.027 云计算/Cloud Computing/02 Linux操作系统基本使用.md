# 02 Linux操作系统基本使用

* 虚拟机快照：
	* **作用**：
		* 完整保存虚拟机状态，便于恢复
* 重置 root 密码：
	* 在 GRUB 中按 `e` 编辑 rescue 模式
	* 在 `linux` 命令末尾添加 `init=/bin/bash` 参数
		* 指定挂载根目录后首先启动的进程（PID 1）是 `/bin/bash`，用于绕过大部分系统服务
	* 按 `Ctrl + X` 或 `F10` 启动系统
	* 执行 `mount -o remount,rw /`
		* `mount`：
			* 挂载文件系统的系统调用
		* `-o`：
			* 指定挂载选项
		* `remount`：
			* 更新现有的挂载标志位，不在物理上卸载和重新挂载
		* `rw`：
			* 设置读写权限为读-写，取代 `ro`（只读）
		* `/`：
			* 目标挂载点
	* `passwd root`
		* 修改 `/etc/shadow` 文件，用新输入的明文密码与盐混合，替换旧密文
	* `touch /.autorelabel`
		* 在根目录下创建名为 `.autorelabel` 的空标志文件
		* **作用**：
			* 提醒系统启动时强制重新扫描并修正 SELinux 安全上下文标签
		* SELinux 通过 `systemd` 启动时，会检查安全上下文标签，决定 `login` 是否有权限读取
		* 通过 `/bin/bash` 写入 `/etc/shadow` 绕过了 SELinux 策略域，可能会写入不正确的标签、创建临时文件残留
		* 通过该标志文件可以自动修正如上异常
	* `exec /sbin/init`
		* 直接用 `/sbin/init` 替换当前进程（PID 1），重新初始化用户态空间
* Shell：
	* **作用**：
		* 提供用户与操作系统的交互界面
	* **包括**：
		* `bash`、`sh`、`zsh`、`fish`
	* 一般基于 CLI（字符命令行接口），通过输入命令完成对系统的操作
	* **特性**：
		* 支持特定文件路径
		* 支持循环、判断、变量等类编程功能
		* 支持脚本编写
		* 启动快，节约资源
* Shell 命令：
	* `命令名称 [命令参数] [命令对象]`
		* 命令名称：
			* 系统中存在的某一个程序的名称
		* 命令参数：
			* 调节命令行为的配置参数，通常可选
			* **分类**：
				* 短格式：如 `-h`
				* 长格式：如 `--help`
		* 命令对象：
			* 命令作用的文件、目录等资源
	* Shell 提示符：
		* `用户名@主机名:当前目录#`
	* 命令对大小写敏感
* 常用命令：
	* `man <COMMAND>`：
		* 显示命令的帮助文档
		* 按 `q` 退出
	* `echo <INFO>`：
		* 控制台输出
		* 字符串通常使用 `''` 或 `""` 包裹
		* `$SHELL`：
			* 当前使用的 SHELL 程序
	* `date`：
		* 显示当前系统时间
		* 格式化：
			* `date +"%Y-%m-%d %H-%M-%S"
	* `wget <URL>`：
		* 通过 URL 下载文件
		* `-P`：
			* 指定文件保存的路径前缀
		* `-O`：
			* 指定保存的文件名
	* `ip address`：
		* 显示网卡、网络信息
	* `free`：
		* 查看内存相关信息
		* `-h`：
			* 以人类可读形式输出
	* `history`：
		* 查看历史命令
		* `!<NO>`：重复执行第 `NO` 条命令
	* `pwd`：
		* 显示当前工作目录
	* `cd`：
		* 改变当前所在目录
	* `ls [DIR]`：
		* 列出目录中所有文件
		* `-l`：
			* 以列表形式列出详细信息
		* `-A`：
			* 列出*几乎*所有文件
				* 包括以 `.` 开头的隐藏文件
		* `-a`：
			* 列出所有文件
				* 包括以 `.` 开头的隐藏文件、`.`（当前目录）、`..`（上级目录）
		* `-d`：
			* 查看目录本身而非目录的内容
		* `-1`：
			* 每行列出 1 个项目
	* `tree [DIR]`：
		* 以树状图形式查看目录和文件的结构
	* `find [PATH] [EXPRESSION]`：
		* 基于特定条件查找文件
		* `[EXPRESSION]`：
			* 查找条件
			* **包括**：
				* 文件名、文件类型、文件大小、修改时间、权限等
	* `cat <FILE>`：
		* 输出文本文件的内容
	* `head <FILE>`：
		* 查看文本文件的前特定行数内容
			* 默认 10 行
		* `-n`：
			* 指定查看行数
	* `tail <FILE>`：
		* 查看文本文件的后特定行数内容
			* 默认 10 行
		* `-n`：
			* 指定查看行数
	* `less <FILE>`：
		* 用于查看内容非常多的文件
		* 可以使用键盘进行上下翻页
		* 可以减少对终端的污染
	* `grep <FILE>`：
		* 按行对文件的内容进行匹配提取
		* `-e`：
			* 使用正则表达式匹配
		* `-v`：
			* 反向匹配
	* `diff`：
		* 比较两个文本文件之间的差异部分
	* `touch <FILE>`：
		* 修改文件或目录的时间信息
		* 若目标文件不存在，则创建空文件
	* `mkdir <PATH>`：
		* 新建目录
		* `-p`：
			* 若父目录不存在则一并创建
	* `file <FILE>`：
		* 基于文件头部的魔数识别文件的类型
	* `stat`：
		* 查看文件的详细元数据
	* `cp <SRC> <DST>`：
		* 复制文件
		* `-r`：
			* 递归复制整个目录及其内容
	* `mv`：
		* 移动文件
		* 可以用于实现重命名
		* 不存在递归移动
			* 本质是修改元信息
	* `rm`：
		* 删除文件
		* `-f`：
			* 强制删除，不进行确认
		* `-r`：
			* 递归删除整个目录及其内容
	* `tar`：
		* 归档文件相关操作
		* `-c`：
			* 创建新归档文件
			* 默认不压缩
		* `-f`：
			* 指定归档文件
		* `-t`：
			* 列出归档文件内容
		* `-x`：
			* 提取归档文件内容
		* `-a`：
			*  根据指定的后缀决定使用的压缩算法
			* 常用后缀：
				* `.tar`：无压缩
				* `.tar.gz`：使用 gzip 压缩
				* `.tar.bz2`：使用 bzip2 压缩
				* `.tar.xz`：使用 xz 压缩
	* `ps`：
		* 查看当前系统中运行的进程
		* `-a`：
			* 查看所有正在运行的 TTY 终端
		* `-u`：
			* 查看所有有效用户的 ID 或名称
		* `-x`：
			* 查看当前用户拥有的、没有控制终端的进程
		* `-e`：
			* 查看所有进程
		* `-f`：
			* 以完整格式显示
				* 重点用于查看 PPID（父进程 ID）
	* `kill`：
		* 向进程发送信号以控制进程状态
		* 默认为终止信号（`15`）
		* `-9`：
			* 强制终止
* 常用快捷键：
	* `Ctrl + C`：发送键盘中断信号
	* `Ctrl + L`：清屏
	* `Ctrl + D`：发送键盘输入结束信号
* 安装和卸载软件：
	* 早期 Linux 安装软件全部依赖源代码直接编译的操作
	* RPM 标准：
		* 用于规范 Linux 系统的文件分发格式
		* 由 Red Hat 推出
		* 记录和关联一键安装的软件包、软件包之间的依赖关系
		* 需要手动下载安装或卸载
	* `yum`：
		* 自动分析 rpm 包的依赖关系
		* 自动完成下载、安装功能
	* `dnf`：
		* 加快了依赖解析的速度
		* 优化资源开销
		* `dnf search <PACKAGE>`：
			* 查找软件包
		* `dnf install <PACKAGE>`：
			* 安装指定软件包
		* `dnf remove <PACKAGE>`：
			* 删除指定软件包
		* `dnf provides <COMMAND|PATH>`：
			* 查找包含指定命令的软件包
		* `dnf update`：
			* 更新所有软件包
			* `-y`：
				* 自动回答 `yes`
