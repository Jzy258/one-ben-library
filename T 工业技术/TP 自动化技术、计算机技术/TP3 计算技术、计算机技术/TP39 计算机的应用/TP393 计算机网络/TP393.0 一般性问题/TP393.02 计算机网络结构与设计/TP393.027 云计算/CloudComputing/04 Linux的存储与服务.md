* Linux 的存储管理：
	* 用户通过文件系统访问文件数据
	* Linux 将目录作为特定文件系统的访问路径（挂载点）
	* `df`：
		* **作用**：
			* 查看文件系统和挂载点之间的关系
		* `-T`：
			* 显示对应文件系统的类型
		* `-h`：
			* 显示人类可读形式
	* `tmpfs`：
		* 临时文件系统
		* **本质**：
			* 内存空间的映射
	* Linux 的文件系统有文件数量的限制
	* `lsblk`：
		* **作用**：列出所有可用块设备
		* 块设备：
			* 存储相关的硬件
		* `-p`：
			* 显示各个块设备的绝对路径
		* `-f`：
			* 显示块设备的文件系统
	* `udev`：
		* 监听硬件变化的服务
		* 为相关硬件编号和设置相关名称
	* 常见硬盘名：
		* `sd[a-z]`：
			* 对应 SATA/SCIS 接口的硬盘
			* 一般默认视为机械硬盘
		* `vd[a-z]`：
			* 对应虚拟化场景
			* 一般是云计算、云服务等常用场景
		* `nvme`：
			* 基于 `nvme` 协议
	* 为系统增加额外存储的方式：
		* 直接在存储设备上创建文件系统并挂载
		* 在磁盘设备上创建分区，在分区上创建文件系统并挂载
		* 使用 LVM 逻辑卷管理器
	* 格式化：
		* **本质**：
			* 在对应的存储空间中创建文件系统
	* `mkfs`：
		* **作用**：
			* 创建文件系统或格式化
		* **常用文件系统**：
			* `ext4`：灵活性好、兼容性好
			* `xfs`：`ext4` 的优化版本，适用于企业级生产环境
		* `-t`：
			* 指定文件系统类型
	* `dd if=源路径 of=目标路径`：
		* **作用**：
			* 将源路径的文件复制到目标路径
	* `mount`：
		* **作用**：
			* 挂载文件系统
		* 当前有效
		* 自动挂载：
			* 将相关信息写入 `/etc/fstab`
			* **格式**：
				* `UUID=UUID值 挂载点 文件系统类型 挂载参数选项 是否进行dump 是否进行fsck`
					* `dump`：
						* 针对整个文件系统的备份工具
					* `fsck`：
						* 文件系统检查和修复工具
			* 修改完毕需要立刻执行 `systemctl daemon-reload` 刷新配置
	* `umount`：
		* **作用**：
			* 卸载文件系统
	* `blkid`：
		* **作用**：
			* 查看指定设备的 UUID
	* 磁盘分区：
		* 主流分区工具：
			* `fdisk`：
				* 适合交互模式操作
			* `gdisk`：
				* `parted`
		* 分区表：
			* **作用**：
				* 记录分区信息
				* 本质上记录起始扇区位置和结束扇区位置
			* 分区一定是连续的扇区
			* 绝大多数情况使用 GPT 分区表：
				* 支持 2TB 以上的磁盘和分区大小
				* 支持更多的分区数量
				* 支持头尾备份，有较高的安全冗余
		* 使用 `fdisk` 创建分区的流程：
			* `g`：
				* 创建 GPT 分区表
			* `n`：
				* 创建分区
			* `w`：
				* 保存更改
	* LVM（逻辑卷管理技术）：
		* **作用**：
			* 将多个物理存储设备虚拟化整合，合并成一个大容量虚拟化设备，再在该设备上划分空间
		* LVM 的管理对象：
			* 物理卷（PV）：
				* 物理存储块设备，包括磁盘、分区等
			* 卷组（VG）：
				* 通过一个或多个物理卷组成的逻辑设备，按照固定大小作为最小分配存储单元
			* 逻辑卷（LV）：
				* 在卷组上分配的一段空间，等效于磁盘的分区
		* `pvcreate`：
			* 创建物理卷
		* `pvscan`：
			* 扫描所有物理卷
		* `pvdisplay`：
			* 显示物理卷详细信息
		* `vgcreate`：
			* 创建卷组
		* `vgscan`：
			* 扫描所有卷组
		* `vgdisplay`：
			* 显示卷组详细信息
		* `vgextend`：
			* 扩充卷组
* Linux 的服务管理：
	* 服务：
		* Linux 发行版通常使用 `systemd` 的组件作为 Linux 系统中的服务管理
		* `systemd` 将所有的管理对象统称为**单元**
		* 常见服务单元类型：
			* `service`（系统服务单元）
			* `socket`（套接字单元）：
				* 用于实现按需启动
			* `target`（目标单元）：
				* 用于将多个服务组合成逻辑组
			* `timer`（定时器单元）：
				* 用于替代传统的 `cron` 定时任务
			* `path`（路径单元）：
				* 用于监控文件或目录的变化，并在时间触发时激活服务
			* `snapshot`（快照单元）：
				* 用于保存系统当前状态的快照
		* Nginx：
			* 全球使用量最大的 web 服务器
			* 支持代理、负载均衡等功能
			* 默认根目录为 `/usr/share/nginx/html`
		* `systemctl`：
			* **作用**：
				* 管理服务
			* `--show-types`：
				* 列出 `systemd` 中管理的单元文件
			* `systemctl start`：
				* 启动服务
			* `systemctl stop`：
				* 停止服务
			* `systemctl enable`：
				* 设置开机自启
				* `--now`：
					* 从现在开始
			* `systemctl disable`：
				* 取消开机自启
			* `systemctl restart`：
				* 重启服务
			* `systemctl cat`：
				* 输出服务配置
		* 服务配置：
			* **本质**：
				* `xxx.service`
			* **作用**：
				* 定义相关程序在启动、关闭、重启重载时执行的命令
				* 指定服务的依赖关系
				* 自动化管理服务
	* 端口转发：
		* `ssh -L 本地端口:localhost:远程端口 -N 用户名@服务器地址`
			* 将远程的端口转发到本地
		* `ssh -R 本地端口:localhost:远程端口 -N 用户名@服务器地址`
			* 将本地的端口转发到远程
* Web 控制台：
	* cockpit：
		* Linux 管理面板
		* Rocky Linux 10 默认安装并作为开机自启的服务之一
		* 默认端口为 `9090`
		* 使用 `socket` 服务
* scp 文件传输：
	* `scp 本地文件 用户名@主机地址:远程文件路径`
		* `-r`：
			* 递归传输，用于发送整个目录及其内容
