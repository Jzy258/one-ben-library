* 一切皆为文件
* FHS（文件系统层次标准）：
	* **作用**：
		* 定义文件的存放规则
* `/` 表示根目录：
	* **整个 Linux 系统**的最顶层
* Linux 以 `/` 分隔文件路径层级
* 根目录下的主要目录：
	* `/boot`：
		* **作用**：
			* 存放系统启动所需的相关资源和配置
	* `/etc`：
		* **作用**：
			* 存放所有软件和操作系统的配置文件
	* `/bin`、`/sbin`、`/usr/bin`、`/usr/sbin`：
		* **作用**：
			* 存放可执行文件
		* `/bin` 和 `/sbin` 本质是指向 `/usr/bin` 和 `/usr/sbin` 的软链接
	* `/var`：
		* **作用**：
			* 存放变化的数据文件
		* **如**：
			* 日志文件、数据库文件
	* `/dev`：
		* **作用**：
			* 存放所有硬件设备和接口的抽象
			* 实现对硬件资源的交互
	* `/proc`：
		* **本质**：
			* 虚拟目录
		* **作用**：
			* 以文件的形式访问 / 调整当前系统的状态信息
	* `/home`：
		* 普通用户的家目录
	* `/root`：
		* `root` 用户的家目录
	* `/tmp`：
		* **作用**：
			* 存放临时文件
* Linux 用户：
	* Linux 是多用户操作系统
	* `root` 用户：
		* 权限最高
		* UID 为 0
	* 系统用户：
		* UID 为 1~999
		* 主要用于一些程序或服务使用
	* 普通用户：
		* UID 为 1000+
		* 由 `root` 创建
	* 用户组：
		* **作用**：
			* 便于批量为用户分配权限
	* 所有用户被记录在 `/etc/passwd` 中
	* `id <USERNAME>`：
		* **作用**：
			* 查看用户的组信息
	* `useradd <NAME>`：
		* **作用**：
			* 创建普通用户
		* `-u`：
			* 指定 UID
		* `-g`：
			* 指定主组 GID
		* `-G`：
			* 指定附加组
		* `-d`：
			* 指定家目录
	* `passwd <USERNAME>`：
		* 为用户设置密码
	* `usermod <USERNAME>`：
		* 修改用户相关信息
		* `-s`：
			* 修改用户登录使用的 Shell
		* `-c`：
			* 修改用户注释
			* 注释通过 GECOS 字段实现，用于存储用户的附加信息
		* `-g`：
			* 修改主组
		* `-G`：
			* 修改附加组
	* `userdel <USERNAME>`：
		* 删除用户
	* `sudo <COMMAND>`：
		* 临时使用管理员权限
	* `visudo`：
		* 通过 `vi` 修改拥有 `sudo` 权限的用户等配置
* vi / vim 编辑器：

	* `vim [FILE]`：

		* `:`：ex 命令
			* `:wq`：

* 文件权限和归属：
	* 所有文件都有归属的用户和组，及其他用户对该文件的 `r`（读）`w`（写）`x`（执行）权限
		* `r`：
			* 对文件：读取文件内容
			* 对目录：列出目录下的文件
		* `w`：
			* 对文件：修改文件内容并保存
			* 对目录：在该目录下创建、删除文件
		* `x`：
			* 对文件：执行文件
			* 对目录：进入该目录
	* `ls -l`：
		* 查看文件详细信息
		* 第 1 个字符：
			* `-`：
				* 普通文件
			* `d`：
				* 目录文件
		* 第 2~10 个字符：
			* `r`、`w`、`x` 分别表示拥有相应的权限
			* `-` 是占位符，表示没有对应的权限
			* 第 2~4 个字符：
				* 文件所属用户拥有的权限
			* 第 5~7 个字符：
				* 文件所属用户组拥有的权限
			* 第 8~10 个字符：
				* 其他用户拥有的权限
	* `chown <USER>[:GROUP] <PATH>`：
		* 修改文件的所属用户和用户组
		* `-R`：
			* 递归修改所有子目录和文件
	* `chmod`：
		* 修改文件的权限信息
		* `chmod u|g|o|a +|-|= r|w|x`：
			* `u`：
				* 针对文件所属用户
			* `g`：
				* 针对文件的所属组
			* `o`：
				* 针对其他用户
			* `+`：
				* 增加权限
			* `-`：
				* 撤销权限
			* `=`：
				* 设置权限
		* `chmod ### <FILE>`：
			* `###`：
				* 9 个权限对应的八进制数
	* 文件的权限管理一般遵循最小权限开放原则
	* 特殊权限：
		* SUID：
			* `chmod u+s`
			* 针对可执行文件
			* 在文件本身具有执行权限的前提下，使其能在运行时拥有所有者对应的权限
		* SGUID：
			* `chmod g+s`
			* 针对目录
			* 任何用户创建的文件所属用户为其自身，文件的所属组为该用户的主组
			* SGID 使任何用户在该目录中创建文件时，文件的所属用户依旧为自身，但所属组与该目录的所属组保持一致
		* SBIT：
			* `chmod o+t`
			* 针对目录
			* 用户只能删除属于自己的文件
	* 隐藏权限：
		* `lsattr`：
			* **作用**：
				* 列出适用于 ex2/3/4 文件系统的文件的权限
		* `chattr`：
			* **作用**：
				* 修改适用于 ex2/3/4 文件系统的文件的权限
* 重定向：
	* Linux 的每个程序启动时默认会有 3 给文件描述符接入：
		* `stdin`：标识符为 `0`，标准输入，默认为键盘
		* `stdout`：标识符为 `1`，标准输出，默认为终端
		* `stderr`：标识符为 `2`，标准错误，默认为终端
	* `>`：
		* 输出重定向符
		* **作用**：
			* 将标准输入流指向指定文件
	* `>>`：
		* 同输出重定向符，但是追加
	* `2>` / `2>>`：
		* 错误输出重定向符
	* `&>` / `&>>`：
		* 合并标准输出和错误输出
	* `<`：
		* 输入重定向
* 管道符：
	* `命令1 | 命令2`：将命令 1 的标准输出作为命令 2 的标准输入
* 通配符：
	* `*`：
		* 任意长度的任意字符
	* `?`：
		* 单个任意字符
* 环境变量：
	* `bash` 在启动时，会加载以下文件：
		* `/etc/profile`
		* `/etc/bashrc`
		* `~/.bash_profile`
		* `~/.bashrc`
	* `alias <ALIAS>=<COMMAND>`：
		* **作用**：
			* 为命令取别名
	* `$LANG`：
		* 当前系统使用的语言
	* `langpacks-core-zh_CN`：
		* 中文支持的语言包
	* `langpack-fonts-zh_CN`：
		* 中文支持的字体包
	* `export`：
		* **作用**：
			* 将环境变量升级为全局变量
	* 环境变量持久化：
		* 将 `export <ENV>` 追加写入上述 4 个预加载文件中
