* 缓存穿透：
	* 请求的 key 在 Redis 和 DB 里都没有
	* **危害**：
		* DB 会被无限的无效请求拖垮
	* **解决方式**：
		* 缓存空值：
			* 若从 DB 查不到，则写入空值到 Redis，设置短过期时间
		* 布隆过滤器：
			* 请求前使用存在性判断过滤，key 不满足条件则直接拒绝，不查询 Redis 和 DB
		* 参数校验：
			* 非法 ID 直接拦截
* 缓存击穿：
	* 极热门的 key 缓存刚好过期，瞬间产生大量 DB 请求
	* **解决方式**：
		* 互斥锁：
			* 只放行一个 DB 请求，其他请求等待缓存重建
		* 逻辑过期：
			* value 带上过期时间戳，发现逻辑过期则在后台异步刷新，保证有数据可读
* 缓存雪崩：
	* 大量 key 同时过期，导致同时产生大量 DB 请求
	* **解决方式**：
		* 过期时间加随机值
		* 多级缓存：
			* 使用本地缓存兜底
		* 限流降级：
			* DB 请求过载时降级到返回默认值或排队
