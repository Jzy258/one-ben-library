* `.gitignore`：
	* **作用**：
		* 忽略提交指定内容
	* **语法**：
		* 直接写文件名，则该文件被忽略
		* `#` 开头的行被视为注释
		* 以 `/` 结尾，则忽略整个目录
		* 支持通配符 `*`
		* 以 `!` 开头表示取反，该文件不被忽略
	* Java 项目常用忽略清单：
		```gitignore
node_modules/
dist/
*.log
*.class
.idea/
log/
.env
.out/
.vscode/
		```
	* 只对未跟踪的文件有效
* Pull Request：
	* **作用**：
		* 申请将代码合并进 `main`，经过 Code Review，通过后合并
	* 完整流程：
		* fork 远程仓库
		* clone 远程仓库到本地
		* 创建 feature 分支
		* 开发
		* push 到远程
		* 发起 PR
		* 队友 Code Review
		* 通过
		* merge
* Code Review：
	* 检验标准：
		* 逻辑是否正确，是否存在 bug
		* 命名是否清晰，代码可读性如何
		* 是否有更简单的实现
		* 是否安全
		* 改动是否太大
* 常用命令：
	* `git remote -v`：
		* 查看远程仓库
	* `git remote add origin URL`：
		* 关联远程仓库
	* `git push -u origin feature/xxx`：
		* 推送并建立远程分支的关联
	* `git fetch`：
		* 拉取远程信息
	* `git pull`：
		* 拉取并合并
		* 相当于 `git fetch && git merge`
