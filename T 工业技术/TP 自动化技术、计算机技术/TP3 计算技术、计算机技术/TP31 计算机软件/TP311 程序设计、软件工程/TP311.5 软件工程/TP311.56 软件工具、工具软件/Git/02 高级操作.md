# 02 高级操作

* Git 的历史记录是有向无环图
	* 每个提交都是一个**结点**，记录其父结点
* `git log --oneline --graph --all`：
	* `--oneline`：
		* 每个提交只显示一行
	* `--graph`：
		* 提交图
	* `--all`：
		* 显示所有分支
* `merge` 与 `rebase`：
	* Merge（合并）：
		* 将一个分支汇合到另一分支
		* 历史记录分别保留
		* 会产生一个 `merge commit`
		* **适用于**：
			* `develop` 合并入 `main`
		* 冲突解决时机：
			* 一次性全部解决
			* `git commit`
	* Rebase（变基）：
		* 将当前分支的提交挂在目标分支的顶端
		* 提交后会获得全新的 hash
		* 历史记录为直线
		* **适用于**：
			* 合并前清理功能分支，保持主分支线性
			* 私有分支
		* 应当只变基未推送过的分支，否则队友拉取时会产生分叉
		* 冲突解决时机：
			* 逐个提交解决
			* 每个冲突解决后 `git rebase --continue`，直到全部结束
* `git cherry-pick 提交hash`：
	* 精准拣选某一次提交
	* **适用于**：
		* `hotfix` 修复某一次提交
* `git stash`：
	* 临时寄存未提交的更改
	* **适用于**：
		* 切换分支，防止将半成品带到别的分支
* `git reset`：
	* 将 `HEAD` 指针后移
	* `--soft`：
		* 将更改留在暂存区
	* `--mixed`【默认】：
		* 将更改退回工作区
	* `--hard`：
		* 丢弃所有更改
	* **适用于**：
		* 合并多次连续提交
		* 尚未 `push` 的提交
* `git revert`：
	* 生成反向提交，抵消某一次提交的改动
	* 不会删除历史记录
	* **适用于**：
		* 已经 `push` 的提交
