* `git remote`：
	* `-v`：
		* 显示远程信息
	* `rename`：
		* 重命名远程
	* `remove`：
		* 移除远程
* tag：
	* 贴在某次提交上的不可变的标签
	* 常用于标记版本号
	* `git tag`：
		* 列出所有标签
	* `git tag 标签名`：
		* 创建轻量标签
	* `git tag -a 标签名 -m "标签描述"`：
		* 创建注解标签
		* 建议在标签描述中说明作者、日期等信息
	* `git show 标签名`：
		* 查看标签详情
	* `git push origin 标签名`：
		* 将标签推送到远程
		* 标签不会自动被推送
	* `git push origin --tags`：
		* 推送时附带本地标签
	* `git tag -d 标签名`：
		* 删除本地标签
	* `git ls-remote --tags origin`：
		* 确认远程已经有标签
* 子模块：
	* 将本项目依赖的另一个 Git 仓库嵌入
	* `git submodule add 子模块URL`：
		* 添加子模块
	* `git submodule update`：
		* 拉取子模块内容
	* 实际开发常用 Maven / Gradle 等依赖管理工具替代
