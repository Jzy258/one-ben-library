# 23 异步方法

* 异步方法：
	* **作用**：
		* 将耗时的操作放到后台线程执行，避免阻塞 `main` 线程
		* 提高系统吞吐量和响应速度
	* **本质**：
		* 使方法调用后立即返回，实际执行由线程池异步完成
	* Spring Boot 提供了默认的线程池，但不适合生产环境
	* 常用线程池：
		* IO 密集型线程池：
			* 线程数较多
		* CPU 密集型线程池：
			* 线程数 = CPU 核心数 + 1
	* **实现步骤**：
		* 使用 `@Async` 注解定义异步方法
			* 可以传入线程池 Bean 名称指定线程池
		* 在主入口使用 `@EnableAsync`
	* **注意事项**：
		* 异步方法必须是 `public` 方法
		* 同类内部不能调用异步方法
			* 因为异步方法的实现基于代理机制
		* 建议为不同的业务配置不同的线程池
		* 生产环境要配置合理的线程池参数和拒绝策略
