# 17 错误处理

* Spring Boot 的默认错误处理方案：
	* 若 `Accept` 为 `application/json`，则直接响应 json
	* 若 `Accept` 为 `text/html`：
		* 精确错误码：
			* 在 `classpath:/templates/error/` 目录下找 `404.html` 模板文件
			* 在 `classpath:/error` 目录下找 `404.html` 静态资源文件
		* 模糊错误码：
			* 在 `classpath:/templates/error/` 目录下找 `4xx.html` 模板文件
			* 在 `classpath:/error` 目录下找 `4xx.html` 静态资源文件
		* 通用错误页面：
			* 找 `classpath:/templates/error.html` 模板文件
		* 使用内置默认错误处理机制，即 `/error` 端点
* Spring Boot 会默认在 `Model` 中
