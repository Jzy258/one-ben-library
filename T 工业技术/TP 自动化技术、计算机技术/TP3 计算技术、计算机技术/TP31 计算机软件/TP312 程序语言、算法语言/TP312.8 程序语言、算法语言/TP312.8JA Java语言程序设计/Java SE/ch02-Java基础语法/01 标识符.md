# 01 标识符

* 什么是标识符
	* 凡是 Java 源程序中程序员能够自己命名的单词
	* 用于给**变量、方法、类、接口、枚举、注解、包、常量**等命名
* 标识符命名规则
	* 由字母、数字、\_、\$组成
	* 不能以数字开头
	* Java 采用 Unicode 编码方式，支持任何一个国家的文字
	* 标识符严格区分大小写
	* 关键字不能做标识符
	* 标识符理论上没有长度限制，但是最好不要太长
* 标识符命名规范
	* 见名知意
	* 类名、接口名：首字母大写，后面每个单词首字母大写
	* 变量名、方法名：首字母小写，后面每个单词首字母大写
	* 常量名：全部大写，单词之间用 “\_” 分隔
	* 包名：全部小写
