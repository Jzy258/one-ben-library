* 二叉树
	* 由一个结点及两棵互不相交的、分别称作这个根的左子树和右子树的二叉树组成
	* 5 种形态：
	* 空树
	* 仅有一个结点的二叉树
	* 仅有左子树而右子树为空的二叉树
	* 仅有右子树而左子树为空的二叉树
	* 左、右子树均非空的二叉树
* 排序二叉树
	* 采用左小右大原则存储，按照中序遍历方式，自动排序
	* 中序遍历：左根右
	* 前序遍历：根左右
	* 后序遍历：左右根
	* 添加元素时，从根结点按照中序遍历逐个比较大小
	* 如果插入的节点集有序，最后得到的排序二叉树将变成普通的链表，检索效率很差
* 平衡二叉树（AVL）
	* 为了避免出现上述一边倒的存储，科学家提出了 “平衡二叉树”
	* 任何结点的两个子树的高度最大差别为 1，所以也被称为高度平衡树
	* 增加和删除结点可能需要通过树旋转来重新平衡
	* 结点的平衡因子是它的左子树的高度减去右子树的高度（有时相反）
	* 带有平衡因子 1、0 或 -1 的节点被认为是平衡的；带有平衡因子 -2 或 2 的节点被认为是不平衡的，需要重新平衡
* 红黑二叉树
	* 自平衡的排序二叉树
	* 在原有排序二叉树增加如下要求：
	* 每个结点只可能为红色或黑色
	* 根结点是黑色
	* 所有的叶子结点都是 `null`，并且是黑色
	* 每个红色结点的两个子结点都是黑色（从叶子结点到根结点的路径上不会有两个连续的红色结点）
	* 从任一结点到其子树中每个叶子结点的路径都包含相同数量的黑色结点
	* 每个新结点都是红色，插入后会根据约束条件进行旋转和变色
	* 从根到叶子的最长可能路径不多于最短可能路径的两倍
	* 检索更高效
	* `TreeMap`、`TreeSet`实现了红黑树实现
	* 基本操作：插入、删除、左旋、右旋、着色
