* 类的定义
	```java
	[修饰符列表] class 类名 {
		类体
	}
	```
	* 实例变量属于成员变量，若未手动赋值，则系统赋默认值
* 对象的创建和使用
	* 类名可作为引用数据类型
	* 通过 `引用数据类型 变量名 = new 类名();` 创建对象
	* `引用.变量名` 或 `引用.方法名()` 访问实例变量或实例方法
	* 实例变量不能通过 `类名.变量` 访问
	* 实例方法的定义：
	```java
	[修饰符列表] 返回值类型 方法名() {
		方法体;
	}
	```
* JVM 内存结构
	* ![[3.1.png]]
	* 元空间中存储类的元信息（字节码等）
	* 元空间是 Java 8 之后引入的，可看作 JVM 规范中方法区的实现
	* JVM 是一套规范，各个厂家都可以根据这个规范实现具体的 Java 虚拟机
	* 虚拟机栈中存储栈帧（该方法的活动空间，包括局部变量表、操作数栈等）
	* 变量（引用）中存储的是该对象的内存地址
	* 实例变量存储在对象里（堆内存中）
	* Java中，程序员不能直接访问堆内存
	* 引用一旦为 null，表示引用不再指向对象，访问实例变量或实例方法时会发生空指针异常（NullPointerExeption）
	* 引用为 null 时，对象会被垃圾自动回收机制回收
	* Java 中 GC 主要针对堆内存
	* `this` 关键字本质上是一个引用，保存的是当前对象的内存地址
	* 实例方法局部变量表的 0 号槽位存储的都是当前对象的内存地址
	* `this.`通常可以省略
	* 方法调用时，变量中的值复制一份传递至参数中
