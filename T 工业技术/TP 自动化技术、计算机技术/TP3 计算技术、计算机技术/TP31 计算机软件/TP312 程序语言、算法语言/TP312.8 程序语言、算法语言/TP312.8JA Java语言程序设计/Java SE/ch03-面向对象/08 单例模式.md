* 设计模式
	* 设计模式：可以重复利用的解决方案
	* 常见的设计模式：
	* GoF 设计模式
	* 架构设计模式
	* 企业级设计模式
	* 领域驱动设计模式
	* 并发设计模式
	* 数据访问模式
	* GoF 设计模式分类：
	* 创建型：对象的创建问题
	* 结构型：设计和构建对象之间的关系，达到更好的重用性、扩展性、灵活性
	* 行为型：处理对象之间的算法和责任分配
* 饿汉式单例模式
	* 单例模式属于创建型，是最简单的设计模式
	* ==比较的是变量保存的值，而不是变量的内存地址
	* 饿汉式在类加载时创建对象
	* 实现：
	* 构造方法私有化，防止从外部调用构造方法
	* 提供公开**静态**方法，用于获取单个实例
	* 定义一个静态变量作为单个实例，在类加载时初始化
* 懒汉式单例模式
	* 懒汉式在用到这个对象时创建对象
	* 实现：
	* 构造方法私有化，防止从外部调用构造方法
	* 提供公开静态方法，获取单个实例
	* 定义一个静态变量，赋值为 `null`
	* 静态方法中判断静态变量为空时创建对象，否则不创建对象
