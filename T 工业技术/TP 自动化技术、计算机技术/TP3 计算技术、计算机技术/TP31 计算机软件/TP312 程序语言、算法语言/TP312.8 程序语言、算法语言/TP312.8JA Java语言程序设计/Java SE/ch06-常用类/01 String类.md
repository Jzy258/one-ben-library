# 01 String类

* 初识String
	* 堆中有一个字符串常量池，能够省去对象的创建过程，提高程序执行效率
	* 常量池属于缓存技术，是提高程序执行效率的重要手段
	* 初始化字符串常量池时，会将所有字符串字面量提前创建好，存储在字符串常量池中
	* （Java 8）字符串常量池在堆内存中
	* 比较两个字符串是否相等，应使用 `equals()` 方法
	* 字符串一旦创建不可变：
	* `String` 有 `private final byte[] value` 属性且没有提供修改这个属性的方法
	* `String` 被 `final` 修饰导致其不能被继承
	* 常用的实现 `CharSequence` 接口的类
	* `String`
	* `StringBuffer`
	* `StringBuilder`
* String的拼接
	* 使用 `+` 拼接的生成的新字符串不会存储在字符串常量池中，而是作为对象在堆中
	* `+` 两边至少有一个是 `String` 对象时，拼接时会自动创建 `StringBuilder` 对象，调用 `append` 方法完成拼接，最后调用 `toString()` 方法返回结果
	* 每使用一次 `+` 都会在底层创建一个 `StringBuilder`，无法服用
	* 需要大量字符串拼接建议手动创建 `StringBuilder`，使用 `append` 方法
	* `.class` 文件中 `ldc` 的作用：从常量池加载常量
	* 对于字符串：
		* 检查字符串常量池中是否已经有该字符串
		* 如果有，则 `ldc` 将该字符串对象加载到操作数栈上
		* 如果没有，则 JVM 在字符串常量池中创建新的字符串对象，并由 `ldc` 加载到操作数栈上
	* 利用 `"" + n` 实现将 `int` 类型的 `n` 转换为 `String`
	* （JDK 9）`+` 使用动态方法 `makeConcatWithConstants` 实现，通过提前分配空间减少了部分临时对象的创建
	* 这种优化主要针对简单的字符串拼接
	* 常量折叠：
	* 编译器会将常量表达式的值求出来作为最终生成的字节码中，从而优化运行
	* 只有在编译期可以确定的常量才能被折叠
* String 类的常用构造方法
	* 仅有 `byte[]` 一个参数时，使用默认的编码方式
* String 的常用方法
	* `charAt()`：返回字符串的某一字符
	* `length()`：返回字符串长度
	* `isEmpty()`：返回字符串是否为空
	* `equals()`：判断字符串是否相同
	* `equalsIgnoreCase()`：判断字符串是否相同（无视大小写）
	* `contains()`：判断字符串是否包含某一字符串
	* `startWith()`：判断字符串是否以某一字符开始
	* `endWith()`：判断字符串是否以某一字符结尾
	* `compareTo()`：按照字典顺序比较两个字符串，返回首次出现不同的字符相差的字典顺序
	* `compareToIgnoreCase()`：同上，无视大小写
	* `indexOf()`：返回首次出现某一字符串的下标，未发现则返回 `-1`
	* `lastIndex()`：返回最后一次出现某一字符串的下标，未发现则返回 `-1`
	* `toCharArray()`：返回字符数组
	* `toUpperCase()`：返回全大写的字符串
	* `toLowerCase()`：返回全小写的字符串
	* `concat()`：拼接字符串
	* 使用 `+` 进行字符串拼接时，会自动创建 `StringBuilder` 对象，最终调用 `toString()` 方法返回新字符串，拼接 `null` 时不会出现空指针异常
	* 使用 `concat()` 方法不会创建 `StringBuilder` 对象，但拼接 `null` 时会出现空指针异常
	* 大量字符串拼接不建议使用以上两种方法，建议使用 `StringBuilder` 的 `append()` 方法
	* `subString()`：截取子字符串
	* `trim()`：去除首尾空白
	* `trim()` 方法只能去除半角空白或制表符，无法去除全角空白（`\u3000`）
	* （Java11）
	* `strip()`：去除首尾空白（包括全角空白）
	* `stripLeading()`：去除前空白
	* `stripTrailing()`：去除后空白
	* `toString()`：返回自身（已重写）
	* `intern()`：将字符串放入字符串常量池
	* `join()`：用某一字符拼接若干字符串
	* `valueOf(T t)`：将 `t` 转换为字符串
	* `getBytes()`：转换为 `byte[]`
	* `contentEquals()`：比较 `this` 和 `cs` 内容（所存的字符串）是否一致，忽略形式
* 正则表达式初步
	* 正则表达式：用于描述特定模式的表达式，可以匹配、查找、替换文本中于该模式匹配的内容
	* 应用：
	* 验证输入内容的格式是否正确
	* 在文本编辑器中搜索和替换
	* 数据挖掘和信息提取
	* 编写脚本语言
	* 服务器端编程
* 正则表达式常用符号
	* 元字符：
	* `.`：除换行符以外的任意字符
	* `\w`：任意字母、数字、下划线、汉字
	* `\s`：任意空白符
	* `\d`：任意数字
	* `\b`：单词的开始或结束
	* `^`：字符串的开始
	* `$`：字符串的结束
	* 字符转义：
	* `\.`
	* `\*`
	* 重复次数：
	* `*`：重复0次或更多次
	* `+`：重复1次或更多次
	* `?`：重复0次或1次
	* `{n}`：重复n次
	* `{n,}`：重复n次或更多次
	* `{n, m}`：重复n到m次
	* 字符类：
	* `[abcdefg]`：括号中的任意一个字符
	* `[0-9]`：0-9中的任意一个数字
	* `[a-zA-Z0-9]`：a-z、A-Z、0-9中的任意一个字符
	* `[abc-]`：a、b、c、-中的任意一个字符（-只能出现在末尾）
	* 分支条件：`|`
	* 分组：`()`
	* 反义：
	* `\W`：任意不是字母、数字、下划线、汉字的字符
	* `\S`：任意不是空白符的字符
	* `\D`：任意不是数字的字符
	* `\B`：不是单词的开始或结束的位置
	* `[^abcde]`：任意不是a、b、c、d、e的字符
* 正则表达式的使用
	* `replace()`：将字符串中的一部分替换为另一字符串
	* `replaceAll()`：按照正则表达式替换字符串
	* `split()`：按照正则表达式拆分字符串
* String 面试题
	* 字符串常量池和堆中的字符串都算作对象
	* `final` 修饰的 `String` 对象已经确定，相当于一个双引号括起来的字符串
