# 04 大数字（高精度）

* 整数超过 long 最大值
	* 使用 `java.math.BigInteger`
	* `BigInteger` 继承 `Number`
	* `add()`：求和
	* `subtract()`：求差
	* `multiply()`：求积
	* `divide()`：求商
	* `abs()`：求绝对值
	* `max()`：求较大值
	* `min()`：求较小值
	* `pow()`：求幂
	* `sqrt()`：求平方根
* 浮点型数据超过 double 最大值
	* 使用 `java.math.BigDecimal`
	* `movePointLeft()`：小数点左移
	* `movePointRight()`：小数点右移
	* 财务软件通常使用
* 数字格式化
	* 使用 `java.text.DecimalFormat`
	* `format()`：将 `number` 格式化
	* 如12345678.123：
		* `"###,###.##"`：12,345,678.12
		* `"###,###.0000"`：12,345,678.1230
