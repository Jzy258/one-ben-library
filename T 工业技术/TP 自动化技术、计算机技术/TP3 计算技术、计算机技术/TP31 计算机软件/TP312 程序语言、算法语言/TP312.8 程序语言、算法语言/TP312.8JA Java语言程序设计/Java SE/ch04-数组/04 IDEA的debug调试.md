* 在方法体内代码左侧添加断点，执行 debug，程序执行到此处就会暂停
* 断点处代码尚未执行
* 重新运行：重新运行程序
* 停止：终止当前程序
* 恢复程序：恢复当前程序的运行，执行到下一个断点
* 步过：下一步
* 步入：进入方法
* 步出：执行到当前方法结束
* 查看断点...：查看所有断点
* 忽略断点：可暂时取消断点，再次点击可恢复
* 右键断点可以设置暂停条件，点击恢复程序可快速到达条件断点
* 调试窗口可以显示目前线程和变量等信息
* 右键监视窗口，“新建监视...”和“对表达式求值”可以监视变量值
* 多线程调试时，将“挂起”选为“所有”可在到达断点时暂停所有进程，选“线程”时则暂停当前线程
