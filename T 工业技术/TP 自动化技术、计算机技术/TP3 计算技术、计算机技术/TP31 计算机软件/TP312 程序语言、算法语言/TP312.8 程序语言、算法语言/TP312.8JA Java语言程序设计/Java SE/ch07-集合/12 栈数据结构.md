* 符合 LIFO（后进先出）原则
* 可使用数组或双向链表实现栈
* 使用数组数据结构模拟栈可使用 `ArrayDeque` 或 `Stack` 类
* `Stack`类：
* Java 6后不建议使用，效率较低
* 线程安全的
* `E push(E item)`：压栈
* `synchronized E pop()`：弹栈
* `synchronized int search(Object o)`：查找栈中元素
* `boolean empty()`：清空栈
* `synchronized E peek()`：窥视栈顶元素（为空时抛出 `EmptyStackException` 异常）
* `ArrayDeque`类：
* 底层为数组
* 实现了双端队列和栈数据结构
* `void push(E e)`：压栈
* `E pop()`：弹栈s
