* 数据类型概述
	* 作用：决定分配给变量的空间大小以及数据的表示形式
	* 数据类型：
	* 基本数据类型
		* 整数型：`byte`，`short`，`int`，`long`
		* 浮点型：`float`，`double`
		* 布尔型：`boolean`
		* 字符型：`char`
	* 引用数据类型
		* 类：`String`，`Object`, ...
		* 接口
		* 数组
		* 枚举
		* ...
	* 在 Java 中若**成员变量**未手动赋值，则系统会赋默认值
	* 引用数据类型默认值为 `null`
* 整数型
	* 整数型字面量默认当作 `int` 类型处理
	* 自动类型转换：小容量可自动转换为大容量
	* `byte` < `short` < `int` < `long` < `float` < `double`
	* 整数型字面量后加 “L”（或者 “l”，建议大写），则该字面量当作 `long` 类型处理
	* 强制类型转换：大容量转小容量，在字面量前加强制转换符
	* 强制转换后，编译通过，但运行后可能会有精度损失
	* `byte`、`short` 或 `char` 运算时，各自先转换成 `int` 再运算
	* 字面量之间的运算会在编译时完成
* 浮点型
	* 浮点型数据类型：
	* `float`：单精度，精确到 7 位小数
	* `double`：双精度，精确到 15 位小数
	* 浮点型字面量默认当作 `double` 类型处理
	* 浮点型字面量后加 `F`（或 `f`，建议大写）可将其转换为 `float` 类型
	* `float` 类型的变量中只能存储 `float` 类型的字面量
	* 浮点型数据的两种表现形式：
	* 标准：3.14159265
	* 科学计数法：2.99792458E8
	* “0.1” 可简写为 “.1”（不推荐）
	* 存储原理：
	* 1 符号位：0 为正数，1 为负数
	* 8 指数位（偏移量）
	* 23 尾数位：浮点数小数部分的有效数字
	* 由于指数位，`float` 容量比 `long` 大
	* 浮点型数据不能使用 “`==`” 与其他数字进行相等比较，因为计算机存储的都是近似值
* 字符型
	* `char` 采用 Unicode 编码
	* `char` 不能存储空字符文字（单引号里面什么也没有）
	* `char` 的默认值：`\u0000`
	* 转义：
	* `\t`：制表符
	* `\n`：换行符
	* `\"`：双引号
	* `\'`：单引号
	* `\\`：反斜杠
	* 整数型字面量没有超出 `byte`、`short`、`char` 的范围时，可直接赋值给 `byte`、`short`、`char` 类型的变量
	* 多种数据类型混合运算时，各自转换为最大的再运算
* 布尔型
	* `boolean` 只有 `true` 和 `false` 两个值
