# 13 IntelliJ IDEA工具的使用

* `~` 代表 Windows 当前用户的主目录
* IDEA 会自动保存、自动编译
* 常用快捷键：
* `.sout`：相当于 `System.out.println();`
* `.var`：自动生成变量
* `.if`：相当于 `if (布尔表达式) {}`
* `.castvar`：快速向下转型
* `.notnull`：相当于 `if (对象 != null) {}`
* `ESC`：退出任何窗口
* `F5`：复制类
* `double Shift`：全局查找
* `Ctrl` + `D`：复制一行
* `Ctrl` + `H`：查看继承结构
* `Ctrl` + `O`：方法覆盖
* `Ctrl` + `P`：提示参数
* `Ctrl` + `Y`：删除一行
* `Ctrl` + `/`：注释
* `Ctrl` + `F12`：文件中查找
* `Alt` + `Insert`：用于新建/新增任何东西
* `Ctrl` + `Alt` + `L`：代码格式化
* `Ctrl` + `Alt` + `T`：自动代码包裹
* `Ctrl` + `Alt` + `←`：后退
* `Ctrl` + `Alt` + `→`：前进
* `Ctrl` + `Shift` + `/`：多行注释
* `Ctrl` + `Shift` + `F8`：断点
* `Ctrl` + `Shift` + `F10`：运行
* `Ctrl` + `Shift` + `F12`：最大化源码编写窗口
* `Alt` + `Shift` + `Up` / `Down`：上下移动本行代码
* 按住 `Ctrl` 单击类名可快速查看源码
* 按住 `Alt` 拖动多行可多行编辑
* 默认当前路径是 Project 的根目录
