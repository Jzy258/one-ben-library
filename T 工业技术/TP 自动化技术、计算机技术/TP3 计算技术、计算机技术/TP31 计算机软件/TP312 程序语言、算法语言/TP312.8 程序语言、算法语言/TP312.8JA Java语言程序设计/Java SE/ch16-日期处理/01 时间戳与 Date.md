* `System.currentTimeMillis()`：
	* 获取 `1970-01-01 00:00:00 UTC` 至今的毫秒数
	* **本质**：
		* `long`
		* 无时区、无格式
* `java.util.Date`：
	* 基于 `long` 时间戳
	* `new Date()`：
		* 创建表示当前时刻的日期对象
	* `new Date(ms)`：
		* 从毫秒构造
	* `toString` 的默认实现：
		* 按系统默认时区格式化输出
	* **问题**：
		* 可变：
			* 可以通过 `setTime()` 改变内部值
			* 线程不安全
		* 方法大量废弃
		* 语义混乱：
			* 同一个类既表示时刻，又表示日期
			* 不支持时区处理
	* `getTime()`：
		* 获取对应时间戳
	* `before()`：
		* 判断是否早于指定日期
	* `after()`：
		* 判断是否晚于指定日期
	* `compareTo()`：
		* 与指定日期相比较
