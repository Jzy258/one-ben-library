* 数据结构概述
	* 数据结构：存储和组织数据的方式，有助于我们整理和管理程序中的数据
	* 数据的逻辑结构：数据元素之间的逻辑关系，抽象，不涉及具体的村塾方式或实现细节，关注问题的本质、特点和抽象模型
	* 数据的物理结构：数据在计算机中实际存储和组织的方式，具体，包括数据元素在内存中的存储分布和访问方式，关注问题的具体实现和操作
	* 逻辑结构的划分：
	* 集合结构：元素和元素之间只有“同属一个集合”的关系
	* 线性结构：一对一
	* 树形结构：一对多
	* 图形结构：多对多

	* 物理结构的划分：
	* 顺序存储结构：连续的存储空间单元，如数组
	* 链式存储结构：任意的存储空间单元，通过保存地址找到关联元素，元素之间的逻辑关系用引用表示，如链表
	* 散列存储结构：根据节点 `key` 计算出节点的存储地址，如 `HashMap`，添加、查询效率高（顺序和链式的结合）

* 算法概述
	* 算法：解决问题的方法和步骤，良好的算法可以提高程序的执行效率
	* 算法建立在数据结构之上
	* 优良算法：时间复杂度小（执行时间短）、空间复杂度小（空间占用少）
* 数据结构与算法的关系
	* 程序的灵魂 = 数据结构 + 算法
	* 数据结构提供算法的运行环境和基础，算法设计和操作数据结构
	* 数据结构和算法互相依存
* 时间复杂度
	* 用 $T(n)$ 表示算法中基本操作（如比较、赋值、运算）的重复执行次数
	* 问题规模 $n$：程序需要处理的数据量
	* 若有某个趋势函数 $f(n)$（代表时间复杂度的趋势），使当 $n$ 趋近于无穷大时，$\displaystyle \frac{T(n)}{f(n)}$ 的极限值为不等于零的常数，则称 $f(n)$ 是 $T(n)$ 的同数量级函数，记作 $T(n)=O(f(n))$，$O(f(n))$ 即为时间复杂度，又称大 $O$ 表示法
	* 计算 $T(n)$：考虑最坏的情况，执行次数最多
	* 得到 $f(n)$：忽略常数项、低次幂项、最高次幂项的系数
	* 常见的时间复杂度：
	* 常数阶：$O(1)$，无论代码执行多少行，没有循环等复杂结构
	* 对数阶：$O(\log _2 n)$，每次循环执行完毕循环变量乘2
	* 线性阶：$O(n)$，一层循环
	* 线性对数阶：$O(n \log _2 n)$
	* 平方阶：$O(n^2)$，两层循环
	* 指数阶：$O(2^n)$
	* 阶乘阶：$O(n!)$
