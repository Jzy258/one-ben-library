# 07 原码反码补码

* Byte 与 Bit
	* 比特（bit， b）：计算机中最小的存储单位，只能存储 1 或 0 两种状态
	* 字节（Byte，B）：计算机存储和处理数据的基本单位，由 8 个比特组成
	* 常用单位换算：
	* 1 kB = 1024 B
	* 1 MB = 1024 kB
	* 1 GB = 1024 MB
	* 1 TB = 1024 GB
	* 1 PB = 1024 TB
* 原码、反码、补码
	* 原码、反码、补码是计算机二进制的三种表现形式
	* 二进制最高位为符号位，0 为正数，1 为负数
	* 正数的原码、反码、补码是相同的
	* 负数：
	* 原码：绝对值转换为二进制后，最高位改为 1
	* 反码：原码的符号位不变，其余取反
	* 补码：反码 + 1
* 为什么采用补码
	* 简化电路设计，将加减法操作转化为相同的操作
	* 解决了 0 的正负问题
	* 解决了负数的溢出问题
	* 提高运算效率
