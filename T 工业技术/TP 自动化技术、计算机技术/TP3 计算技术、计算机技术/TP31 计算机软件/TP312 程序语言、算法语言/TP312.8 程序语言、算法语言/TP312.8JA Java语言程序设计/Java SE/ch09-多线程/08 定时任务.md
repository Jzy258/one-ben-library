# 08 定时任务

* Java 中提供了 `Timer` 和 `TimerTask` 两个类来实现定时任务，使用步骤：
* 创建 `Timer` 对象
* 创建 `TimerTask` 对象（可通过匿名内部类实现）
* 将 `TimerTask` 对象和时间间隔传递给 `Timer` 对象：
	* `timer.schedule(task, delay, period);`
	* 其中 `delay` 表示定时任务的延迟时间，`period` 表示定时任务的时间间隔，单位均为毫秒
* 构造方法：
* `Timer(boolean isDaemon)`
* `Timer()`
* `Timer` 本质上是一个线程
