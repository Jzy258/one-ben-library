# 04 构造方法（构造器）

* 构造方法
	* 作用：
	* 对象的创建
	* 对象的初始化
	* 定义：
      ```java
      [修饰符列表] 类名(形参列表) {
  	构造方法体;
      }
      ```
	* 构造方法不需要提供返回值类型
	* 构造方法名必须和类名一致
	* 使用 `new` 运算符调用
      ```java
      new 构造方法名(实参);
      ```
	* 构造方法执行结束后会自动返回所创建的对象的内存地址，不需要 `return` 语句
	* 当一个类中没有定义任何构造方法，系统会默认提供一个无参数构造方法（缺省构造器）
	* 当已经定义了有参数的构造方法，系统就不会再默认提供无参数构造方法
	* 一个类中可以构造多个构造方法，相互构成方法重载
	* 对象的创建在构造方法体执行之前就已经完成，实例变量赋初始值
	* 构造方法体的执行标志着实例初始化的开始
* 构造代码块
	* 构造代码块位于类体中：
      ```java
      {
  	Java语句;
      }
      ```
	* 每一次 `new` 的时候都会执行一次构造代码块
	* 构造代码块在构造方法执行之前执行
	* 对象的创建在构造代码块执行之前就已经完成
