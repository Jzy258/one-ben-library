* 控制语句
	* 控制语句：
	* 分支语句：`if` 语句、`switch` 语句
	* 循环语句：`for` 循环、`while` 循环、`do while` 循环
	* 跳转语句：`break` 语句、`continue` 语句
* 分支语句 if
	```java
	if (条件表达式) {
	  Java语句;
	}
	```
	```java
	if (条件表达式) {
	  Java语句;
	} else {
	  Java语句;
	}
	```
	```java
	if (条件表达式1) {
	  Java语句;
	} else if (条件表达式2) {
	  Java语句;
	} else if (条件表达式3) {
	  Java语句;
	} else {
	  Java语句;
	}
	```
	* 如果分支中只有一条 Java 语句，大括号可以省略，但可读性差，不建议省略
	* 字符串的比较使用 `equals()` 方法，不能使用 `==`
	* 一个 `if` 语句只能执行一个分支
	* `return` 直接结束当前方法
	* 在 `if` 选择结构中还可以嵌套别的选择结构或循环结构
* 分支语句 switch
	```java
	switch (表达式) {
	  case 值1:
	    Java语句;
	    break;
	  case 值2:
	    Java语句;
	    break;
	  case 值3:
	    Java语句;
	    break;
	  default:
	    Java语句;
	}
	```
	* `switch` 语句中，条件表达式执行后的值为：int、枚举类型、字符串类型
	* `default` 语句不是必须的
	* `break` 语句只要执行，`switch` 语句就会结束
	* `case` 是可以合并的
	* 缺少 `break` 语句可能会发生 `case` 穿透现象（即符合某个 `case` 后，无视下文其他 `case` 继续执行）
	* `if` 侧重于区间，`switch` 侧重于值
	* `default` 不一定放在最后，但要注意穿透
	* （Java12）
	```java
	switch (x) {
	  case 1,2,3,4 -> {
	    Java语句
	  }
	}
	```
	* 使用 `->` 代替 `:`
	* 省略 `break;` 语句
* 循环语句 for
	```java
	for (初始化表达式; 条件表达式; 更新表达式) {
	  循环体;
	}
	```
	* 初始表达式最先执行，只执行一次
	* 条件表达式为布尔类型
	* 更新表达式负责更新某个变量
	* 执行原理：
	* 初始化表达式
	* 条件表达式（`true`）-> 循环体 -> 更新表达式
	* 条件表达式（`true`）-> 循环体 -> 更新表达式
	* ... 
	* 条件表达式（`false`）-> 循环结束
	* `for` 语句中声明的变量不能在大括号外访问
* 循环语句 while 
	```java
	while (布尔表达式) {
		循环体;
	}
	```
	* 只要布尔表达式为 `true` 则一直循环，直到布尔表达式为 `false`
	* `for` 一般用于固定次数的循环，`while` 一般用于不固定次数的循环
* 循环语句 do while 
	```java
	do {
	  循环体;
	} while (布尔表达式);
	```
	* 不要漏掉最后的分号
	* 循环体至少执行一次
* 跳转语句 break
	* 可用于 `switch` 语句，用于终止 `switch`
	* 可用于循环语句，用于终止循环
	* 可以通过标签标记循环语句以终止特定的循环
	```java
	f1:
	for (int i = 0; i < 10; i++) {
	  f2:
	  for (int j = 0; j < 10 ; j++) {
	    System.out.println("j=" + j);
	    if (i == 3) {
	      // 终止f1的for语句
	      break f1;
	    }
	  }
	  System.out.println("i=" + i);
	}
	```
* 跳转语句 continue
	* 用于循环语句，终止本次循环，直接进入下一次循环
