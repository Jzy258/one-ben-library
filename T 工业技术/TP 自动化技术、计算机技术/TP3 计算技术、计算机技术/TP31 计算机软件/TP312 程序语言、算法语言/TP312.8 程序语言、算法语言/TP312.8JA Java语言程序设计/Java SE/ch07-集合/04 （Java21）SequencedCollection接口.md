# 04 （Java21）SequencedCollection接口

* `void addFirst(E e)`：在头部添加一个元素
* `void addLast(E e)`：在尾部添加一个元素
* `E getFirst()`：获取头部的元素
* `E getLast()`：获取尾部的元素
* `E removeFirst()`：移除头部的元素
* `E removeLast()`：移除尾部的元素
* `SequencedCollection<E> reversed()`：将有序集合反转
