# 01 线程概述

* 进程：
* 操作系统中的一段程序，是一个正在执行中的程序实例，具有独立的内存空间和系统资源，如文件、网络端口等
* 在计算机程序执行时，先创建进程，再在进程中执行程序
* 一般一个进程可以包含多个线程
* 线程：
* 进程中的一个执行单元，是进程的一部分，负责在进程中执行程序代码
* 每个线程都有自己的栈和程序计数器，可以共享进程的资源
* 多个线程可以在同一时刻执行不同的操作，从而提高了程序的执行效率
* 现代操作系统支持多进程，可以启动多个软件，一个软件就是一个进程（多进程并发）
* 通常一个进程可以启动多个线程（多线程并发）
* 作用：
* 提高处理效率（能够使 CPU 在处理一个任务时同时处理多个线程，可以充分利用 CPU 的资源，提高 CPU 的利用效率）
* JVM 规范规定：
* 堆内存、方法区 是线程共享的
* 虚拟机栈、本地方法栈、程序计数器是每个线程私有的
* 关于 Java 程序的运行原理
* `java HelloWorld` 执行后，会启动 JVM，此时一个进程启动
* JVM 进程首先启动一个主线程（`main-thread`），主线程负责调用 `main` 方法，`main` 方法是在主线程中运行的
* 除了主线程外还启动了一个垃圾回收线程，因此启动 JVM 至少启动了两个线程
* 在 `main` 方法的执行过程中，程序员可以手动创建其他线程对象并启动
