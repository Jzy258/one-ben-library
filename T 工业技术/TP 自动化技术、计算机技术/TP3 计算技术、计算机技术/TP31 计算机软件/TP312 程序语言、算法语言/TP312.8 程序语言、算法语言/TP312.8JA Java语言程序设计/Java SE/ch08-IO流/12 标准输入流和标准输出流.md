* 标准输入流
	* 标准输入流：`System.in` 获取到的 `InputStream`，用来接收用户在控制台上的输入（普通的输入流获得文件或网络中的数据）
	* 标准输入流不需要关闭（是一个系统级的全局的流，JVM 负责最后的关闭）
	* 可以使用 `BufferedReader` 包装标准输入流，可以方便地接收用户在控制台上的输入（JDK 中提供了更好用的 `Scanner`）
	```java
	BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
	String s = br.readLine();
	```
	* 可以通过 `System.setIn()` 修改输入流的方向，让其指向文件
* 标准输出流
	* 标准输出流：`System.out` 获取到的 `PrintStream`，用来向控制台上输出（普通的输出流向文件和网络等输出）
	* 标准输出流不需要关闭（它是一个系统级的全局的流，JVM 负责最后的关闭）也不需要手动刷新
	* 可以通过 `System.setOut()` 修改输出流的方向，让其指向文件
