# 08（Java5）枚举

* 一种引用数据类型
* 枚举类型可以使代码更清晰、可读性更高，避免一些常见的错误
* 有限的
* 类型安全的
* 定义：
  ```java
  enum 枚举类型{
	枚举值1, 枚举值2, 枚举值3, 枚举值4;
  }
  ```
* 使用 `switch` 语句判断枚举值时，`case` 后直接使用枚举值，不要在前面加 `类型.`
* 每一个枚举值都可以看作类中的常量
* 枚举较常量的优点：可以自定义类型
* 枚举类型实际被 `final` 修饰
* 枚举类型中有一个`values`数组
* `Type[] values()`：返回枚举值数组
* 枚举中可以像普通类一样定义静态代码块、构造代码块、静态方法、构造方法、实例方法、静态变量、实例变量等，但前提是必须定义至少一个枚举值（记得加分号）
* 枚举值的定义只能出现在类体的最上面
* 通过 `枚举值(参数类型1 参数名1, 参数类型2 参数名2, 参数类型3 参数名3...)` 调用构造方法
* 枚举类型的构造方法不能使用 `new` 来调用
* 枚举类的构造方法只能在本类使用
* 枚举类默认继承 `java.lang.Enum`，所以不能继承其他类，但是可以实现接口
* 可以通过以下方式实现接口：
  ```java
  enum 枚举类型 {
	枚举值 (参数类型 参数名) {
		实现;
	}
  }
  ```
* 枚举值使用全大写字母，单词之间用下划线分隔
