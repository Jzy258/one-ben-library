# 01 数组概述

* 数组储存在堆中
* 一维数组是线性数据结构
* 数组中的元素在内存地址上是连续的
* 数组中每一个元素都有一个对应的索引（下标）
* 数组中只能存储相同数据类型的元素
* 数组第一个元素的地址作为数组的地址
* 数组是一种引用数据类型，隐式继承 `Object`
* 数组包括：一维数组、二维数组、多维数组……
* 数组长度一旦确定不可变
* 首元素索引为0
* 数组有 `length` 属性，末尾数组的下标为 `length-1`
* 优点：查询效率极高（$O(1)$），只需要知道数组的地址（首元素地址）、元素的下标和占用空间就能迅速查询到地址
* 缺点：随机增删元素的效率极低（$O(n)$）；在内存中很难找到一块连续的空间
* 静态数组初始化
  ```java
  int[] nums = new int[]{100, 200, 300};
  ```
* 简写形式：
  ```java
  int[] nums = {100, 200, 300}
  ```
* `ArrayIndexOutOfBoundsException`：数组下标越界异常
* （Java 5）for-each 增强循环
  ```java
  int[] nums = new int[]{1, 2, 3};
  for(int num : nums) {
	System.out.println(num);
  }
  ```
* 动态数组初始化：
  ```java
  int[] nums = new int[10];
  ```
