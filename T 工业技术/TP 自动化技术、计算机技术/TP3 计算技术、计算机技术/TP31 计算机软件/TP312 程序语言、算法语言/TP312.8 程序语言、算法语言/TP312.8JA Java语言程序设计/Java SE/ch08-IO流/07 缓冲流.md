* 缓冲流
	* `BufferedInputStream` 和 `BufferedOutputStream` 适合读写非普通文本文件
	* `BufferedReader` 和 `BufferedWriter` 适合读写普通文本文件
	* 读写速度快，原理：内存中准备了一个缓存，读的时候从缓存中读，写的时候将缓存中的数据一次写出，**减少和磁盘的交互次数**
	* 缓冲区（`byte` 数组）由 `BufferedInputStream` 和 `BufferedOutputStream` 自动维护
	* 缓冲流都是处理流 / 包装流，`FileInputStream` / `FileOutputStream` 是节点流
	* 关闭流只需关闭最外层的处理流，此时底层节点流也会关闭
	* 输出效率提高的原理：在缓冲区中先将字符数据存储起来，当缓冲区达到一定大小或者需要刷新缓冲区时，再将数据一次性输出到目标设备
	* 输入效率提高的原理：`read()` 方法从缓冲区中读取数据，缓冲区中的数据不足时会自动从底层输入流中读取一定大小的数据，并将数据存储到缓冲区中。大部分情况下，调用 `read()` 方法时都是从缓冲区中读取，而不需要和硬盘交互
	* `BufferedReader` 的特有方法：
	* `String readLine()`：
		* 读取一行文本，未读取到则返回 `null`
	* 缓冲流的特有方法（输入流），允许在读取数据流时回退到原来的位置（重复读取数据时用）：
	* `void mark(int readAheadLimit)`：
		* 标记位置（Java21 中参数无意义，低版本 JDK 中参数表示在标记处最多可以读取的字符数量，如果超出上限则调用 `reset()` 方法时抛出 `IOException`）
	* `void reset()`：
		* 重新回到上一次标记的位置
	* 先后顺序：
		* 先 `mark()` 再 `reset()`，且不是在所有流中都能用
		* 有些流中有这个方法，但是不能用
* 解决字符读写乱码问题
	* `FileReader`（`InputStreamReader`）和 `FileWriter`（`OutputStreamWriter`）都是转换流
	* `InputStreamReader` 的构造方法：
	* `InputStreamReader(InputStream in, Charset cs)`
	* `FileReader` 的构造方法：
	* `FileReader(File file, Charset charset, boolean append)`
	* `Charset` 类：
	* `static Charset defaultCharset()`：
		* 获取默认字符编码
	* `static Charset forName(String charsetName)`：
		* 根据名称获取字符编码对象
