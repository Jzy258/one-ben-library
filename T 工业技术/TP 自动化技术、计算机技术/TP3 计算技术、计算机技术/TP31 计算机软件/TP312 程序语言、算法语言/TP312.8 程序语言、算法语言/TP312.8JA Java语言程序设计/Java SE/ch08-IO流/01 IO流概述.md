# 01 IO流概述

* IO 流：程序中数据的流动
	* 从内存流动到硬盘：输出
	* 从硬盘流动到内存：输入
* 基本作用：文件的读和写
* 分类：
	* 根据数据流向：输入（读）和输出（写），相对于内存而言
	* 根据读写数据形式：
		* 字节流：一次读取一个字节，适合读取非文本数据，如图片、声音、视频等
		* 字符流：一次读取一个字符，只适合读取普通文本，统一使用 Unicode 编码，避免出现乱码
		* Java 中以 `Stream` 结尾的都是字节流，以 `Reader` 或 `Writer` 结尾的都是字符流
	* 根据流在 IO 操作中的作用和实现方式:
		* 节点流：负责数据源和数据目的地的连接，IO 中最基本的组成部分
		* 处理流：对节点流进行装饰 / 包装，提供更多高级处理操作，方便用户处理数据
* Java 已将 IO 流实现，在 `java.io` 包下可以直接使用
