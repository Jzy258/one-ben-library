* 异常的两种处理方式
	* 声明异常：当当前方法出现异常，将该异常抛出给调用（推卸责任）
	* 捕捉异常：在当前方法
* 声明异常
	* 在方法声明语句中加上 `throws 异常名`
	* `throw new 异常;` 后的语句永远不会执行
	* 若异常最终被抛给 JVM，则控制台打印信息，JVM 停止运行
	* `throws` 可以抛出父类异常
* 捕捉异常
	* 语法格式：
	```java
	try {
		尝试执行的程序;
	} catch (异常类型1 e) {
		捕捉到异常类型1时执行;
	} catch (异常类型2 e) {
		捕捉到异常类型2时执行;
	} catch (异常类型3 e) {
		捕捉到异常类型3时执行;
	} ...
	```
	* `catch` 可以多个，但是必须自上而下，从小到大
	* 异常类的 `toString()` 方法已经重写
	* （Java 7）
	* 异常类型之间可以用 `|` 分隔，表示 “或者”
	* 异常捕捉语句执行完毕后，后面的代码仍可执行
