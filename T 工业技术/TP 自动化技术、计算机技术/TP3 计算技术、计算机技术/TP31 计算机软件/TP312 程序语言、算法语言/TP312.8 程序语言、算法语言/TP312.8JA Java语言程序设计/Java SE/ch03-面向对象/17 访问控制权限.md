# 17 访问控制权限

* `private`：私有的，只能在本类访问
* 可以提供 getter / setter 方法对成员变量访问（[[03 封装|封装]]）
* 将所有构造方法用 `private` 修饰可以阻止任何人创建该类的对象（[[08 单例模式|单例模式]]实现）
* 包访问：默认的，同一个包下可以访问
* `protected`：受保护的，本包和子类可以访问
* 父类的 `protected` 成员在包内可见，并对子类可见
* 若子类和父类不在同一个包下，则在子类中，子类实例可以访问**从父类继承**来的 `protected` 成员，而不能访问父类实例中的 `protected` 成员
* `public`：公开的，任何位置均可访问
* 非内部类的访问权限只有 `public` 和包访问
* 内部类可以被 `protected` 和 `private` 修饰
* 访问权限控制符不能修饰局部变量
