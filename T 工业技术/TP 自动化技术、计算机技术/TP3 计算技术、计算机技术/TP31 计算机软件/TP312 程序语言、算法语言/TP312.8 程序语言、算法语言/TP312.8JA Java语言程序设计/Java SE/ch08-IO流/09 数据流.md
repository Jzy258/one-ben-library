* `DataOutputStream` /  `DataInputStream` 都是包装流，读写数据专用
* `DataOutputStream` **直接**将程序中的数据写入文件，不需要转码，效率高
* 文件中直接存储的是二进制码
* 使用 `DataOutputStream` 写的文件，只能使用`DataInputStream`读取，并且读取的顺序需要和写入的顺序一致
* 构造方法：
* `DataInputStream(InputStream in)`
* `DataOutputStream(OutputStream out)`
* 写的方法：
* `writeXXX()`：以 `XXX` 类型写
* `writeUTF(String)`：以 UTF-8 格式写
* 读的方法：
* `readXXX()`：以 `XXX` 类型读
* `readUTF()`：以 UTF-8 格式读
