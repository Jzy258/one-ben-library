# 11 线程间的通信

* `Object` 类中关于同步机制的方法：
	* `wait()`：
		* 使线程进入等待状态，释放对象锁
	* `notify()`：
		* 唤醒优先级最高的等待状态的线程
			* 若优先级相同，则随机选一个
		* 被唤醒的线程从执行 `wait()` 的位置继续执行
	* `notifyAll()`：
		* 唤醒所有 `wait()` 的线程
	* **使用条件**：
		* 在同步代码块或同步方法中调用
		* 调用对象必须是共享锁
	* `wait()` 和 `sleep` 的区别：
		* `wait`：
			* `Object` 的实例方法
			* 只能用在同步代码块或同步方法中调用
			* 执行后释放对象锁
			* 结束时机：
				* `notify` 唤醒
				* 达到指定时间
		* `sleep`：
			* `Thread` 的静态方法
			* 结束时机：到达指定时间
* 生产者消费者模式：
	* 生产者和消费者不直接交换数据，而是通过共享缓冲区实现信息交换
		* 生产者只负责向缓冲区添加数据
		* 消费者只负责从缓冲区取出数据
	* **优点**：
		* 解耦、缓冲、削峰
	* 常见案例：
		* 消息队列、高并发业务、日志
	* **原理**：
		* 生产者线程：
			* 向缓冲区添加数据
			* 缓冲区满则触发等待
			* 添加至少一个数据后唤醒消费者
		* 消费者线程：
			* 从缓冲区取数据
			* 缓冲区空则触发等待
			* 取出至少一个数据后唤醒生产者
	* 虚假唤醒：
		* 唤醒的线程不是需要被唤醒的那一类
		* 使用 `notifyAll` 全部唤醒
