* 在配置文件中配置信息：
* `classInfo.properties`
* `className=com.powernode.javase.reflect.UserService`
* `methodName=login`
* `parameterTypes=java.lang.String,java.lang.String`
* `parameterValues=admin,123456`
* 参数之间不能有空格
* 通过反射机制创建对象，调用配置的方法
* 本案例的实现类似于 Spring 框架中部分实现，主要通过修改配置文件创建不同的对象，调用不同的方法
* 完整示例：
```java
ResourceBundle bundle = ResourceBundle.getBundle("classInfo");
String databaseConnectionName = bundle.getString("database");
Class clazz = Class.forname(databaseConnectionName);
```
