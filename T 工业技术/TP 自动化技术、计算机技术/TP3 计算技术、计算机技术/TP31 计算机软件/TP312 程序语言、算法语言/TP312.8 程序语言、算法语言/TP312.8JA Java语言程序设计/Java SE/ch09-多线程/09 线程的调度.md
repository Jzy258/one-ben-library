# 09 线程的调度

* 线程合并
	* `Thread` 类的 `join()` 方法可以合并线程，等待指定线程执行完成之后再继续执行当前线程
	* `final void join(long millis)`：指定合并毫秒数
* 线程优先级
	* 可以指定线程的执行优先级，优先级高的线程会优先获得 CPU 资源，执行速度也会更快
	* 线程优先级受到底层操作系统调度的影响，不同操作系统调度方式不同，在不同的操作系统上表现也不同，也很容易引起线程死锁等问题，要慎用
	* 可以通过 `Thread` 类的 `setPriority()` 方法和 `getPriority()` 方法来设置和获取线程的优先级，数字越大表示优先级越高
	* 一些常量：
	* `psf int MIN_PRIORITY = 1`：最低优先级
	* `psf int NORM_PRIORITY = 5`：默认优先级
	* `psf int MAX_PRIORITY = 10`：最高优先级
* 线程让位
	* `static void yield()`： 当前正在执行的线程主动放弃 CPU 资源，让其他线程先执行
	* 作用：调整线程执行顺序，使得高优先级的线程能够更快地执行完任务，从而提高程序的响应性和效率
