# 04 变量

* 什么是变量
	* 变量：内存当中的一块空间，是计算机中存储数据的最基本的单元
	* 变量三要素：
	* 数据类型（决定空间的大小）
	* 变量名（合法的标识符）
	* 变量值（存储的数据）
	* [[08 数据类型|数据类型]]（前瞻）：
	* int 整数
	* double 浮点数
	* String 字符串
	* 变量的声明、赋值、访问：
	* 声明：`数据类型 变量名`
	* 赋值：`变量名 = 字面值`
	* 访问：`变量名`
* 变量的作用
	* 便于代码的维护
	* 增强代码的可读性
* 变量的小细节
	* 变量必须先声明，再赋值，才能访问（遵循代码自上而下执行原则）
	* 一行代码上可以声明多个变量
* 变量的作用域
	* 在同一个作用域（一对{}）中变量名不能重名，但可以重新赋值
	* 作用域：变量的有效范围（出了大括号就不认识了）
	* 生命周期：从内存开辟到内存释放
* 变量的分类
	* 局部变量：定义在方法体中的变量，只在该方法体中有效
	* 成员变量：在类体中定义的变量
	* 静态变量：关键字 `static` 修饰的成员变量
	* 实例变量
