* 包装类
	* 包装类：Java 为 8 种基本数据类型分别提供了对应的包装类
	* `Integer` 使用最多
	* 包装类属于引用数据类型
	* 作用：将基本数据类型包装为引用数据类型，方便开发
* Number 类
	* `Byte`、`Short`、`Integer`、`Long` 类都继承了 `Number` 类
	* 所有 `Number` 类都可以互相转换为基本数据类型，称为拆箱
* 常量
	* 所有包装类除 `Boolean` 外，都设有以下常量：
	* `MIN_VALUE`：该类型所能表示的最小值
	* `MAX_VALUE`：该类型所能表示的最大值
* 构造方法
	* （Java9）因为允许自动装箱拆箱，构造方法已过时
	* 装箱：将基本数据类型包装成引用数据类型
	* `NumberFormatException`：数字格式化异常，转换的数据类型不兼容
* 常用方法
	* `static int compare(int a, int b)`：比较两个整数大小
	* `static int max(int a, int b)`：返回较大值
	* `static int min(int a, int b)`：返回较小值
	* `static int parseInt(String str)`：将字符串 `str` 转换为 `int` 类型
	* `static String toHexString(int num)`：将整数转换为十六进制数的字符串
	* `static String toBinaryString(int num)`：将整数转换为二进制数的字符串
	* `static String toOctalString(int num)`：将整数转换为八进制数的字符串
	* `static Integer valueOf(int i)`：将基本数据类型 `int` 转换为 `Integer`
	* `static Integer valueOf(String s)`：将字符串转换为 `Integer`

* 自动装箱和自动拆箱
	* （Java5）属于编译阶段的功能
	* 如果基本数据类型被传递到一个需要引用数据类型对象的地方，编译器会在幕后插入一个对引用数据类型构造方法的调用，称为**自动装箱**
	* 如果引用数据类型对象被传递到一个需要基本数据类型的地方，编译器会在幕后插入一个对 `xxxValue()` 方法的调用，称为**自动拆箱**
	* 注意空指针异常
* 整数型常量池
	* -128 ~ 127 这些整数由于过于常用，Java提前创建了 `Integer[] integerCache` 用于存储这256个
	* `Integer` 对象，称为整数型常量池
