* 方法
	* 方法是一段可以被重复利用的代码片段
	* 一个方法一般都是一个独立的功能
	* C 语言中被称为函数
	* 方法只定义不调用是不会执行的
* 方法的定义
	* 语法格式：
	```java
	[修饰符列表] 返回值类型 方法名(形式参数（形参）列表) {
		方法体;
	}
	```
	* 返回值类型：Java 语言中任何一种数据类型或 `void`（无任何返回值）
	* 返回值类型不为 `void` 时，方法结束必须使用 `return 值;` 完成数据的返回
	* `return` 语句执行后方法结束
* 方法的调用
	* 通过 `方法名(实际参数列表)` 调用方法
	* 对调用者来说，方法执行后的返回值可以接收，也可以不接收
	* 形参是局部变量
	* 方法体中的代码遵循自上而下的顺序执行
	* 方法的修饰符列表中有 `static` 关键字时，使用 `类名.方法名(实际参数列表)` 调用方法
	* 实际参数列表与形式参数列表一一对应，顺序、类型、数量不能变化
	* 调用者与被调用者在同一个类中，调用方法时的 `类名.` 可以省略
	* `return` 语句后的语句无法执行
* 方法执行的内存变化
	* 方法如果只定义不调用，就不会分配内存空间
	* 从 Java 8 开始，方法的字节码指令存储在元空间 metaspace 中
	* 方法调用时会在 JVM 的栈内存中分配空间，发生压栈
* 方法重载（静态多态）
	* Java 中允许在一个类中定义多个名字相同的方法
	* 作用：方便调用，无需记更多方法名
	* 条件：
	* 在同一个类中
	* 方法名相同
	* 形参列表不同（个数、类型、顺序）
	* 方法重载是编译阶段的机制
	* 当传入方法的参数符合多个重载的方法时，会选择更具体的方法执行
* 递归
	* [[递归]]
	* 方法自己调用自己
	* 递归必须有结束条件，否则会出现 `java.lang.StackOverflowError`（栈溢出错误）
	* 即使有结束条件，递归也可能导致栈溢出（当压栈过多时），应尽量避免使用递归，用循环代替
	* 元空间存放字节码信息，使用本地内存，而不是 JVM 的内存
