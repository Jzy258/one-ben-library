# 05 基于 TCP 协议的编程

* TCP 协议编程概述
	* 客户端（Client）：
	* 第一次主动发起通讯的程序
	* 服务端（Server）：
	* 第一次通讯中等待连接的程序
	* 一旦通讯建立完成，则客户端和服务器没有本质的区别
	* 套接字与主机地址和端口号相关联
	* 在客户端和服务器中，分别创建独立的 Socket，并通过 Socket 的属性进行连接，使用 IO 流进行通信
	* 服务器先启动
	* 流程：
	* 服务端建立倾听 Socket
	* 服务端等待请求，客户端创建 Socket（指定端口，即目标服务器的地址），向服务端发送请求，建立连接
	* 服务端接收请求，创建连接 Socket（随机端口）
	* 服务端和客户端建立输入流和输出流，开始通信
	* 服务端和客户端关闭 Socket 及相关资源，结束通信
	* Socket 也是资源，用完需要关闭
* `Socket` 类概述
	* `Socket` 类实现客户端套接字
	* 构造方法：
	* `Socket(InetAddress a, int p)`：创建套接字并连接到指定 IP 地址的指定端口号
	* 实例方法：
	* `InetAddress getInetAddress()`：返回此套接字连接到的远程 IP 地址
	* `InputStream getInputStream()`：返回此套接字的输入流（接收网络消息）
	* `OutputStream getOutputStream()`：返回此套接字的输出流（发送网络消息）
	* `void shutdownInput()`：禁用此套接字的输入流
	* `void shutdownOutput()`：禁用此套接字的输出流
	* `synchronized void close()`：关闭此套接字（默认会关闭 IO 流）
* `ServerSocket` 类概述
	* `ServerSocket` 类实现服务器套接字
	* 服务器套接字等待请求通过网络传入，基于该请求执行某些操作，然后可能向请求者返回结果
	* 构造方法：
	* `ServerSocket(int port)`
	* 实例方法：
	* `Socket accept()`：侦听要连接到此的套接字并接受它
	* `InetAddress getInetAddress()`：返回此服务器套接字的本地地址
	* `void close()`：关闭此套接字
* TCP 单向通讯的实现
	* 先启动服务器程序，然后再启动客户端程序
	* 服务器端实现步骤：
	* 创建 `ServerSocket` 对象，绑定并监听端口
	* 通过 `accept()` 监听客户端的请求
	* 建立连接后，通过输出输入流进行读写操作
	* 调用 `close()` 方法关闭资源
	* 客户端实现步骤：
	* 创建 `Socket` 对象，指定服务端的地址和端口号
	* 建立连接后，通过输入输出流进行读写操作
	* 通过输出输入流获取服务器返回信息
	* 调用 `close()` 方法关闭资源
* TCP 双向通讯的实现
	* 客户端给服务端发送数据时，数据发送完毕必须调用 `shutdownOutput()` 方法来关闭 Socket 输出流，否则服务端读取数据会一直阻塞
	* 服务器端实现步骤：
	* 创建 `ServerSocket` 对象，绑定监听端口
	* 通过 `accept()` 监听客户端请求
	* 使用输入流接收客户端发送的数据，然后通过输出流保存数据
	* 通过输出流向客户端发送信息
	* 调用`close()`方法关闭资源
	* 客户端实现步骤：
	* 创建 `socket` 对象，指明需要连接的服务器地址和端口号
	* 建立连接后，通过输出流向服务器端发送数据
	* 通过输入流获取服务器的发送数据
	* 调用`close()`方法关闭资源
