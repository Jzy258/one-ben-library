# 01 反射机制概述

* 反射机制：在运行时动态获取类的信息或动态调用对象的方法、修改属性等操作
* 主要应用于框架开发、动态代理、ORM 框架、JDBC 驱动等方面
* 通过反射机制，程序员能够获得在编译期间不被知晓的类、属性、方法等信息
* 性能较低，常常被认为是一种牺牲性能换取灵活性的实现方式
* 反射机制核心包：`java.lang.reflect`
* 反射机制核心类：
* `java.lang.Class`
* `java.lang.reflect.Field`
* `java.lang.reflect.Method`
* `java.lang.reflect.Constructor`
* `java.lang.reflect.Modifier`
