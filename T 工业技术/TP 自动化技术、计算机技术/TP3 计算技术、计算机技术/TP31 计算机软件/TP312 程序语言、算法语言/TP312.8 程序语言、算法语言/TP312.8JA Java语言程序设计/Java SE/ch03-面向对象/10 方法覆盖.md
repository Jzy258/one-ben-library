* 从父类继承过来的方法不能满足子类的业务需求时，可重写方法
* 方法重载是编译阶段的功能
* 条件：
* 具有继承关系的父子类之间
* 相同的方法名
* 相同的形参列表
* 相同的返回值类型
* 子类将父类方法重写后，子类对象调用方法时一定会执行重写之后的方法
* （Java 5）`@Override` 注解可以在编译阶段检查该方法是否重写了父类方法
* 如果返回值类型时引用数据类型，那么这个返回值类型可以是原类型的子类型
* 访问权限不能变低，但可以变高
* 抛出异常不能变多，可以变少
* 私有方法和构造方法不能继承，所以不存在方法覆盖
* 方法覆盖针对实例方法，与静态方法无关，因为没有对象的参与
* 方法覆盖和实例变量无关
