* `PrintStream`
	* 打印流（字节形式）
	* 提供便捷的打印方法和格式化输出,主要打印内容到文件或控制台
	* 常用方法：
	* `print(Type x)`
	* `println(Type x)`
	* 能直接输出各种数据类型
	* 自动刷新和自动换行（`println()` 方法）
	* 支持字符串转义
	* 自动编码（自动根据环境选择合适编码方式）
	* `printf`：格式化输出
	* `%s`：字符串
	* `%d`：表示整数
	* `%f`：表示小数（`%.2f` 代表保留两位小数的数字）
	* `%c`：表示字符
* `PrintWriter`
	* 打印流（字符形式）
	* 使用 `PrintWriter` 需手动调用 `flush()` 方法刷新
	* 比 `PrintStream` 多一个构造方法，`PrintStream` 参数只能是 `OutputStream` 类型，但 `PrintWriter` 参数可以是 `OutputStream`，也可以是 `Writer`
	* 常用方法：
	* `print(Type x)`
	* `println(Type x)`
	* `printf`：格式化输出
