# 02 一维数组

* 将数组的所有元素反转：
* 创建一个新的数组
* 首尾交换
* `main` 方法的 `args` 参数：命令行参数，用空格分隔
* 命令行参数可用于区分管理员与普通用户使用该程序
* 可变长度参数：
  ```java
  public static void method(int... nums) {}
  ```
* 可变长度参数只能有一个，且只能在参数列表的末尾出现
* 数组的扩容：创建一个新的更大的数组，将原来的数组拷贝到新数组中
* 数组拷贝：
  ```java
  System.arraycopy(原数组, 起始位置, 目标数组, 目标位置, 新数组长度);
  ```
