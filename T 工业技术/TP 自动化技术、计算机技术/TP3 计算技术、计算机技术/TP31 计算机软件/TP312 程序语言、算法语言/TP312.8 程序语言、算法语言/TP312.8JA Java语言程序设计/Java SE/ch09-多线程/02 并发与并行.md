* 并发（concurrency）
	* 使用单核 CPU 时，同一时刻只能有一条指令执行，但多个指令被快速的轮换执行，使得在宏观上具有多个指令同时执行的效果，但在微观上并不是同时执行的，只是把时间分成若干端，使多个指令快速交替的执行
	* 在同一时间点，一个 CPU 只能支持一个线程执行，因为 CPU 运行的速度很快，CPU 使用抢占式调度模式在多个线程间进行着高速的切换，因此我们看起来的感觉就像是多线程一样，也就是看上去就是在同一时刻运行
* 并行（parallellism）
	* 使用多核 CPU 时，同一时刻有多条指令在多个 CPU 上同时执行
* 并发编程与并行编程
	* CPU 比较繁忙（假设为单核 CPU）时，如果开启了很多个线程，则只能为一个线程分配仅有的 CPU 资源，这些线程就会为自己尽量多抢时间片，这就是通过多线程实现并发，线程之间会竞争 CPU 资源争取执行机会
	* CPU 资源比较充足时，一个进程内的多个线程可以被分配到不同的 CPU 资源，这就是通过多线程实现并行
	* 多线程可能被分配到一个 CPU 内核中执行，也可能被分配到不同 CPU 执行，分配过程是操作系统所为，不可人为控制（并发或并行都有可能）
	* 单核 CPU 上的多线程，只是由操作系统来完成多任务间对 CPU 的运行切换，并非真正意义上的并发
	* 随着多核 CPU 的出现，不同的线程能被不同的 CPU 核得到真正的并行执行，故而多线程技术得到广泛应用
	* 不管并发还是并行，都提高了程序对 CPU 资源的利用率，最大限度地利用 CPU 资源，而使用多线程的目的就是提高 CPU 资源的利用率
