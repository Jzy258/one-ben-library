* 自定义注解：
* 使用 `@interface` 自定义注解
* 注解默认可以出现在类上、方法上、属性上、构造方法上、方法参数上等
* 所有自定义注解继承 `java.lang.annotation.Annotation`
* 注解属性：
* 定义：`String name();`
* 属性的类型只能是：
	* `byte`、`short`、`int`、`long`、`float`、`double`、`boolean`、`char`
	* `String`、`Class`、枚举、注解
	* 以上所有类型的一维数组形式
* 必须为属性赋值，除非使用了 `default` 关键字为属性指定了默认值
* 如果只指定一个属性，且属性名为 `value`，则 `value = ` 可以省略不写
	* 如：`@Foo(value = "bar")` 可以简写为 `@Foo("a")`
* 如果注解的属性是一个数组，使用注解时数组只有一个元素，则数组的大括号可以省略
	* 如：`@Foo(name = {"bar"})` 可以简写为 `@Foo(name = "a")`
