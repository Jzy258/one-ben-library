* package 包机制
	* 作用：便于代码管理
	* `package` 语句只能在代码的第一行（除注释外）
	* `javac -d 源文件路径` 可以带包编译
	* 有了 `package` 之后，完整的类名是带包名的，运行时要加包名
	* 命名规范：
	* 全小写
	* 公司域名 + 项目名 + 模块名 + 功能名
	* 一个项目中不能有相同的两个包（包括 JDK 自带的包）
* import
	* 不在一个包内的类在访问时需要加包名，或使用 `import` 语句导包
	* `import` 语句只能出现在 `package` 语句和 `class` 定义之间
	* 可以编写多个 `import` 语句
	* 模糊导入：使用通配符 `*`
	* 静态导入：`import static 静态变量和静态方法名`
