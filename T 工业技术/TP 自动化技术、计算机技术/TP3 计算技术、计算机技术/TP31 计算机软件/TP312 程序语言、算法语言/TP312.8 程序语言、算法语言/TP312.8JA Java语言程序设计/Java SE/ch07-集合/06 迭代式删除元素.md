# 06 迭代式删除元素

* 在迭代器遍历集合时使用集合的`remove()`方法删除元素时有可能出现 `ConcurrentModificationException`（并发修改异常）
* 使用迭代器的 `remove()` 方法删除元素不会出现上述异常
* 迭代集合的线程与删除元素的线程并发可能会导致空指针异常等错误发生
* 虽然执行的是单线程程序，但使用迭代器且同时使用集合的修改元素方法时，系统会认定为并发行为
* 解决方案：fail-fast（快速失败机制），实现原理：
* 集合中设置 `modCount` 属性，集合进行增、删、改操作时该属性自加1
* 迭代器中存在 `expectedModCount` 属性，实例化迭代器对象时初始化 `expectedModCount = modCount`
* 使用集合的 `remove()` 方法时，`modCount` 自加1，`expectedModCount` 不变，此时判断两者是否相等，若不等则抛出 `ConcurrentModificationException` 异常
* 使用迭代器的 `remove()` 方法时，`modCount` 和 `expectedModCount` 都会自加 1，不会出现上述异常
