* 内部类
	* 内部类：定义在一个类中的类
	* 作用：
	* 减少类的数量，提高代码的可读性
	* 根据不同的访问权限要求，提供更细粒度的访问控制
	* 内部类可以访问外部类的私有成员，提高封装性
	* 分类：静态内部类、实例内部类、局部内部类、匿名内部类
* 匿名内部类：
	* 没有类名
	* 没有构造方法
	* 内部不可以重新定义静态成员，常量除外
	* 一般只使用一次，如在事件处理中
	* 必须继承一个父类或实现一个接口
	* 在实例化后立即转型为父类 / 接口
	* 可在普通语句和成员变量赋值时使用
	* 外部类无法访问到内部类
	* 编译产生的名字：外部类名 + $ + 数字编号
* 静态内部类
	* 可以定义静态成员和非静态成员
	* 不能直接访问外部类的非静态成员（必须先 `new` 外部类对象）
	* 外界可以通过嵌套类名访问静态内部类的静态成员，或通过其对象访问其非静态成员
* 实例内部类
	* 可以直接访问外部类中的实例成员和静态成员（`new` 内部类实例时已经 `new` 了外部类的实例）
	```java
	Outer.Inner inner = new Outer().new Inner();
	```
	* 必须先创建外部类实例才能创建内部类实例（不允许单独的内部类实例存在）
	* 编译后名称：外部类名 + $ + 内部类名
	* 可以继承其他类或实现其他接口
* 局部内部类
	* 能不能访问外部类的数据取决于局部内部类所在的方法
	* 如果定义在静态方法中，则只能访问外部类的静态成员
	* 不能访问被访问权限修饰符修饰的变量、方法
	* 访问所在方法的局部变量时，该变量需要用 `final` 修饰
	* 可以继承其他类或实现其他接口
	* 局部内部类不能是一个接口
	* 编译后名称：外部类名 + $ + 数字编号 + 内部类名
	* （JDK8）局部内部类所在方法的局部变量默认被 `final` 修饰
* 变量遮蔽
	* 如果内部类变量与外部类变量重名：
	* 就近原则
	* 优先级高的变量会遮蔽优先级低的变量
	* `Outer.this.变量名` 可以访问外部类的成员变量
	* 静态内部类不能访问非静态变量
