* 与其他方式的区别：可以返回一个值或者抛出一个异常，使 `Callable` 在某些场景下更加灵活和方便
* 实现 `Callable` 接口并重写 `call()` 方法，`call()` 方法会在 `Thread` 对象中通过 `start()` 方法运行
* 在实际应用中一般利用 `Executor` 接口启动 `Callable` 任务，可以通过线程池重用线程和减少线程创建和销毁的开销
* 主要优点：
* 可以方便地获取到线程执行的结果或者处理异常
* 支持泛型，可以避免类型不匹配的问题
* 由于需要手动启动 `Thread` 对象，相对来说比较繁琐，还需要利用 `Executor` 接口进行管理，需要在实际应用中进行评估选用
