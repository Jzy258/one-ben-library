# 02 异常的继承结构

* `Throwable`：
* 可抛出
	* `Error`（错误）：
	* 无法（或不建议）处理的异常，一旦出现则虚拟机线程必定终止执行
	* 如：
		* `OutOfMemoryError`（内存溢出错误）
		* `VirtualMachineError`（虚拟机运行错误）
		* `NoClassDefFoundError`（类定义错误）
			* 编译时存在的类在运行时链接不到（如 `jar` 包缺失）
* `Exception`：
	* 可处理
	* 一定在运行时发生
	* `RuntimeException`（Unchecked Exception，运行时异常，未检查异常，非受控异常）：
		* 编译器不会强制检查
		* 即使方法可能抛出该异常，也无需在方法中捕获或使用 `throws` 声明
		* 属于编程错误，应通过改进代码避免
		* 如：
			* `NullPointException`（空指针异常）
			* `ArrayIndexOutOfBoundsException`（数组下标越界异常）
			* `ArithmeticExcpetion`（算术异常）
			* `IllegalArgumentException`（非法参数异常）
	* 其余的 `Exeption`（Checked Exception，编译时异常，检查异常，受控异常）：
		* 可预料的、由外在因素导致的
		* 编译器强制检查，必须在编译阶段预先处理，否则编译器报错
		* 处理方式：
			* 使用 `try-catch` 捕获并处理
			* 在方法签名中使用 `throws` 声明抛出
		* 如：
			* `IOException`（输入输出异常）
			* `SQLException`（数据库操作异常）
			* `ClassNotFoundException`（类未找到异常）
