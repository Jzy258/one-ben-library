# 11 多态

* 多态的基础语法
	* 基本数据类型之间的类型转换：
	* 自动类型转换：小 -> 大
	* 强制类型转换：大 -> 小
	* 向上转型和向下转型
	* 向上转型（upcasting）：子 -> 父
	* 向下转型（downcasting）：父 -> 子
	* 向上转型和向下转型要求两种类型之间有继承关系才能通过编译
	* 子类实例调用重写后实例方法时，编译阶段会将该实例与父类中的实例方法静态绑定
	* 运行时会自动调用该实例的子类（重写过的）实例方法，称为动态绑定
	* 编译与运行为两种不同的形态，称为多态
	* 父类型引用指向子类型对象是多态机制最核心的语法
	* 通过 `(子类型)父类型实例` 向下转型
	* `ClassCastException` 类型转换异常：运行时堆中的实例类型与向下转型成的类型不一致
	* `instanceof` 运算符：判断实例是否为某个类型，返回 `boolean` 类型
* 多态在开发中的作用
	* 面向抽象编程而非面向具体编程
	* 降低耦合度，提高扩展力
* 使用多态时容易产生的问题
	* 数组的类型不兼容：
      ```java
      public class Person {}
      ```
```java
public class Student extends Person {}
```
```java
public class Employee extends Person {}
```
```java
public class Main {  
    public static void main(String[] args) {  
        Person[] students = new Student[10];  
        students[0] = new Employee(); // java.lang.ArrayStoreException
    }  
}
```
	* 抛出异常的原因：
	* `students` 数组编译时为 `Person` 类型，运行时实际是 `Student` 类型
	* 向 `students` 中添加 `Employee` 元素时，由于 `Employee` 继承 `Person`，编译通过
	* 但由于实际类型不兼容，导致数组存储异常
* 协变、逆变与不变
	* 协变（Covariant）：
	* 如果 `B` 是 `A` 的子类，且 `F(B)` 是 `F(A)` 的子类，则 `F` 为协变
		* 通常表现为子类型可以安全地赋值给父类型
	* 如数组（子类型的数组是父类型数组的子类）、上界通配符
	* 逆变（Contravariant）：
	* 如果 `B` 是 `A` 的子类，但 `F(B)` 是 `F(A)` 的父类，则 `F` 为逆变
	* 如下界通配符
	* 不变（Invariant）：上述两种均不适用
	* 由里氏替换原则，子类型可以胜任父类型的任何场景
	* 为了解决[[05 （Java 5）泛型|泛型]]的协变性问题，引入了[[05 （Java 5）泛型#5.4 泛型通配符|泛型通配符]]
