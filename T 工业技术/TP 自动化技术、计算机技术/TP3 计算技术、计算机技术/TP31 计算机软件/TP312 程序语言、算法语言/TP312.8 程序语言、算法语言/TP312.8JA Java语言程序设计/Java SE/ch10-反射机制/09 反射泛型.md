* 反射父类的泛型：
```java
// 获取父类泛型
Type genericSuperclass = clazz.getGenericSuperclass();
// 判断父类是否使用泛型
if (genericSuperclass instanceof ParameterizedType parameterizedType) {
  // 获得泛型数组
  Type[] actualTypeArguments = parameterizedType.getActualTypeArguments();
}
```

