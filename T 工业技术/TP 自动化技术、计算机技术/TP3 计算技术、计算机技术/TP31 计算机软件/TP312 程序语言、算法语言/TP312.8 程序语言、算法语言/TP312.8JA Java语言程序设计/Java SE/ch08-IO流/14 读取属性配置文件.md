* Properties + IO 模式
* `.properties`文件：属性配置文件
* 可以配置一些简单的信息，如连接数据库的信息，可以做到在不修改 Java 代码的前提下切换数据库等操作
* 格式：
```
key1=value1
key2=value2
key3=value3
```
* 使用 `#` 注释
* `key` 不能重复，重复则 `value` 覆盖
* `key` 和 `value` 之间用等号分割，等号两边不要有空格
* 使用 `Properties` 类读取 `.properties` 文件：
* `synchronized void load(Reader reader)`：
	* 通过 `Reader` 读取
* `String getProperty(String key)`：
	* 根据 `key` 获取 `value`
* 可以使用 Java 中的 `ResourceBundle` 工具类快速获取配置信息
* 要求文件必须是 `.properties` 文件
* `static final ResourceBundle getBundle(String baseName)`：
	* 根据 `.properties` 文件的名称获取捆绑包（将 `.properties` 文件视作类）
* `final String getString(String key)`：
	* 根据 `key` 获取 `value`
* 属性配置文件必须放在类路径中
