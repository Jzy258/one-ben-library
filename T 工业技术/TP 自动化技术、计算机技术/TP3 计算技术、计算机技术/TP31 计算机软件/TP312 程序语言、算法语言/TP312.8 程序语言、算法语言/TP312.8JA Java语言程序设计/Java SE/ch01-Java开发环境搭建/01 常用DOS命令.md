# 01 常用DOS命令

* 常用 Windows 组合键
	* 常用windows组合键
	* Win + D：显示桌面
	* Win + E：打开资源管理器
	* Win + R：打开运行窗口
	* Win + L：一键锁屏
	* Alt + Tab：在应用之间切换
* 常用DOS命令
	* 打开 DOS 命令窗口：
	* Win + R 打开运行窗口
	* 输入 `cmd`，回车（cmd 是 command 的缩写）
	* 在DOS窗口中复制粘贴：
	* 左键选定，单击右键，选定内容就进入剪贴板了
	* 直接在空白处单击右键即可将剪贴板中的内容粘贴到光标处
	* 当前路径
	* DOS 窗口光标左侧的路径，是当前命令执行的位置
	* 路径包括相对路径和绝对路径
	* 绝对路径：在windows中，以盘符开头的路径，如：`C:\Windows\System32`
	* 相对路径：从当前路径开始找
	* 常用DOS命令
	* `dir`：列出当前路径下的目录
	* `cls`：清屏
	* `exit`：退出DOS窗口
	* `C:`、`D:`、`E:`：切换盘符
	* `del 文件名`：删除一个或多个当前路径下的文件
	* `ipconfig`：查看本机IP信息，如IP地址、mac地址等
		* `ipconfig /all`：显示更详细的IP信息
	* `ping IP地址`：查看两台计算机之间是否可以通信
		* `ping IP地址 -t`：持续测试
	* ctrl + C：强行中止DOS窗口中正在执行的命令
	* `mkdir 目录名`：在当前路径下新建目录
	* `rd 目录名`：删除当前路径下的某一目录
	* `ren 目录名 新名称`：重命名当前路径下的某一目录
	* `cd 路径`：改变当前路径
		* `..`：上级目录
		* `.`：当前路径
		* `\`、`/`：根目录
	* `con 文件名 文件内容...`：新建文件
	* `shutdown`：关机
		* `shutdown -s -t 时间（单位：s）`：设置指定时间后关机
	* 通配符：用 `*` 代替任何字符
	* 在DOS窗口中按 Tab 键可自动补全命令、路径
	* 在资源管理器的地址栏中输入 `cmd` 后回车，可从资源管理器当前位置打开 DOS 窗口
	* 批处理文件
	* 批量执行DOS命令的文件
	* 文件名以 .bat 结尾
	* 从上至下逐行运行
