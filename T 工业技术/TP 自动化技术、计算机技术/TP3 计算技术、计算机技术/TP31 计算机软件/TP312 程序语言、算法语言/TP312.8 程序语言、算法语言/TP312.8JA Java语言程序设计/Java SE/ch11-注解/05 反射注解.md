# 05 反射注解

* 获取类上的所有注解：
  ```java
  Annotation[] annotations = clazz.getAnnotations();
  ```
* 获取类上指定的某个注解：
  ```java
  if (clazz.isAnnotationPresent(Annotation.class)) {
	Annotation an = clazz.getAnnotation(Annotation.class);
  }
  ```
* 获取属性上的所有注解：
  ```java
  Annotation[] annotations = field.getAnnotations();
  ```
* 获取属性上指定的某个注解：
  ```java
  if (field.isAnnotationPresent(Annotation.class)) {
	Annotation an = field.getAnnotation(Annotation.class);
  }
  ```
* 获取方法上的所有注解：
  ```java
  Annotation[] annotations = method.getAnnotations();
  ```
* 获取方法上指定的某个注解：
  ```java
  if (method.isAnnotationPresent(Annotation.class)) {
	Annotation an = method.getAnnotation(Annotation.class);
  }
  ```
