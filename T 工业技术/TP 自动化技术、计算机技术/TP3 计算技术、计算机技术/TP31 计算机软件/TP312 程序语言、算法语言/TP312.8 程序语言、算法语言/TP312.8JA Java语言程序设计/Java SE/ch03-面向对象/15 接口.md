# 15 接口

* 接口的基础语法
	* 接口：一种规范或契约，定义了一组抽象方法和常量，描述一些实现这个接口的类应该具有哪些行为和属性
	* 接口也是一种引用数据类型
	* 接口编译也生成 .class 文件
	* 抽象类是半抽象的，接口是完全抽象的，没有构造方法，也无法实例化
	* 接口中只能定义常量和抽象方法，且用 `public` 修饰
	* 常量（`public static final`）和抽象方法（`public abstract`）的修饰符列表可以省略
	* ==接口与接口之间可以多继承==
	* 类和接口之间的关系称为实现
	* 使用 `implements` 关键字进行接口的实现
	* 一个非抽象的类实现接口必须将接口中的方法全部重写
	* 一个类可以同时实现多个接口
* 接口新特性
* （Java 8）默认方法
	* 格式：
      ```java
      public default 返回值类型 方法名(参数列表) {
  	方法体;
      }
      ```
	* 可以解决接口演变问题：
	* 接口可以定义抽象方法，但是不能实现这些方法，而所有实现该接口的类都必须实现这些抽象方法，导致**接口升级**的问题
	* 当在该接口中添加或删除一个抽象方法时，会破坏该接口的全部实现，所有实现该接口的类必须修改
	* 默认方法不是抽象方法，不强制重写，但是可以被重写，重写时去掉 `default` 关键字
	* `public` 可以省略
* （Java 8）静态方法
	* 格式：与在普通类中定义静态方法相同
	* 只能通过接口名调用，不能通过实现类名或实例对象调用
	* 无法在实现类中覆盖
	* `public` 可以省略
	* 工具类：提供大量静态方法和常量的类，不能实例化
	* 如 `DBUtil` 类可用于提供数据库连接相关初始化操作和静态方法
* （Java 9）私有方法
	* 解决了 Java 8 中默认方法与静态方法的共用私有函数问题
	* 格式与普通类中私有方法的定义相同
	* 默认方法可以调用私有静态方法和非静态方法
	* 静态方法只能调用私有静态方法
	* 私有的实例方法（为默认方法服务）和私有的静态方法（为静态方法服务）
	* 所有接口隐式继承 `Object` 类，因此可以调用相关方法
* 接口的作用
	* 面向接口编程
	* 降低程序的耦合度
	* 提高程序的扩展力
* 接口与抽象类如何选择
	* 抽象类主要适用于公共代码的提取
	* 接口主要适用于功能的扩展
