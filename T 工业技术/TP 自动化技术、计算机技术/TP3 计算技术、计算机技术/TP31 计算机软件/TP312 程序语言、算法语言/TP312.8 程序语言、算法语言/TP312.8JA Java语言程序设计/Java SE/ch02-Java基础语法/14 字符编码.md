# 14 字符编码

* 字符编码概述
	* 字符编码：人为规定的文字与二进制之间的转换关系
	* 早期计算机系统采用 ASCII 编码，采用一个字节编码，最多表示 256 个字符
	* 常用ASCII码：
	* 0 -> 49
	* a -> 97
	* A -> 65
	* 编码与解码：
	* 字符到二进制码：编码
	* 二进制码到字符：解码
	* 乱码：编码与解码时编码方式不同

	* 常见的字符编码：ASCII、ISO 8850-1、ANSI、unicode（占用 2~3 个字节）、UTF-8（使用 1~4字节，可变长度）、UTF-16（使用 2~4 字节）、UTF-32（占用 4 字节，固定长度）、GB2312（小，2 字节）、GBK（中，2 字节）、GB18030（大）、Big5（台湾使用，2 字节）
* ASCII
	* 美式键盘上所能表示的字符不超过 128（2^7）个，因此计算机用 7 个 bit 位就可以表示这些字符。计算机内部在 7 位的前面补一个 0，变成 8 位，也就是一个存储单元，即一个字符存放在一个存储的单元内。每种字符对应一个二进制数，即用一个二进制数就可以表示一个字符。这就是 ASCII 码表。
	* ASCII码对应了 128 个字符。这些字符被分成三类：可印刷字符、控制字符、通信字符：
	* 通信字符：0~32，用于早期计算机通信的指示。
	* 可印刷字符：32~126 都是可印刷字符。可以打印出来给人看的。
	* 控制字符：127 是控制字符，DEL 就是键盘上的 delete，用于删除。
	* 内存中存放的数据是该字符在 ASCII 码对应的二进制值。
* 汉字编码
	* 为了能够存储和打印中文字符，中国发明了属于自己的汉字编码，如：GB 2312 -80、GBK、GB18030、Big5
	* GB 2312-80 是由区位码演变而来的：
	* 区位码中，汉字被分成了 94 个区域，每个区域有 94 个位置，每个汉字对应一个区域中的一个位置，赋予一个区位码。如：”啊“ 这个字符，区位码：1601，区是 16，位是 01。
	* 区位码的存放与取出：
		* 存放：区位码在内存中是分开存储的，就是将区码和位码分开存放。而为了适应计算机，在计算机内部，无论是区码还是位码，都是由 8 个 bit 位组成的。一个区码或是位码都会放到一个存储单元内。
		* 取出：区位码取出时，会将区码和位码结合，变成 16bit 的二进制。高 8bit 是区码，低 8bit是位码。然后计算机再通过区位码读取出信息。
	* GB 2312-80：
		* 在网络传输的过程中，A 要给 B 传输一个数据，如果 A 传去的数据是用 GB 2312-80 编的，而 B 读取地方式是用 ASCII 方式的，GB 2312-80将区位码传过去，当 B 收到时会先读到区码，因为区码和位码的范围用十进制表示都是 0~93，如果此时的区码的十进制是 6，那么ASCII 对应的 6 则是 ACK，会发现 ACK 是回包的指示，那么就会出现问题。
		* 为了解决这一问题，科学家就将区位码加上 32，因为 ASCII 的通信字符是 0~32，如果将区位码的区码和位码都加 32，那么区码和位码的范围就变成了 32-125，就避开了与 ASCII 中通信字符与控制字符的相同的情况，提高了 ASCII 和区位码的兼容性。而这种 32~125的区位码就是所谓的国标码（GB 2312 -80）。
		* 国标码是用十六进制表示的，实际上是在区位码的区码和位码分别加上 20H（32D），也就是加上 2020H，最后得到了GB 2312-80。
	* GB 2312 :
	* 出现国标码是为了防止与 ASCII 的控制字符和通信字符冲突，但是还是会和打印字符发生冲突，因此为了彻底让国标码和 ASCII 兼容。就在 GB 2312-80 的基础上分别再加上 8080H，也就是在区码和位码上再加上 128D（80H）。最后得到了**汉字机内码**，GB 2312 就是汉字机内码。
	* 由于 ASCII 的范围是 0-127，而 GB 2312 在 160~253，GB 2312 与 ASCII 不会发生冲突，使中国汉字与外国英文兼容。
	* 最后在计算机内部，使用的就是汉字机内码（GB 2312）
	* 汉字机内码也有别的称呼：汉字内码、内码。
	* 汉字在计算机内部的输入和输出：
	* 输入：
		* 如果此时要用输入法打出一个 "内" 字，那么我需要在键盘上输入 ”nei“，然后选择 ”内“。
		* 输入法会将 ”nei“ 转换成国标码，然后计算机系统或者是应用软件，会将国标码再转换成汉字机内码，最后计算机或是手机再去保存这个汉字机内码。
		* 输入法也可能会直接将 "nei" 转换成机内码。
	* 输出：
		* 汉字要输出，就需要用到另一种编码：汉字字形码。
		* 汉字字形码是通过用一块一块的像素拼组而成的，1 表示这里的像素为黑色，0 表示白色，从而达到输出一个汉字。 
		* 计算机会将汉字机内码转换成国标码，再将国标码转换成汉字字形码，或是直接由汉字机内码转换成汉字字形码，最后输出。 
	* 汉字机内码转换成汉字字形码需要经过以下步骤：
	* 根据汉字机内码的编码规则，将每个汉字转换成相应的二进制编码。
	* 对于一些早期的编码规则，需要使用专门的编码转换表将汉字机内码转换成Unicode编码。
	* 根据汉字字形库中的字形信息，将汉字机内码转换成相应的汉字字形码。
	* 在显示设备上根据汉字字形码渲染出汉字的图形形态，供用户观看和使用。
