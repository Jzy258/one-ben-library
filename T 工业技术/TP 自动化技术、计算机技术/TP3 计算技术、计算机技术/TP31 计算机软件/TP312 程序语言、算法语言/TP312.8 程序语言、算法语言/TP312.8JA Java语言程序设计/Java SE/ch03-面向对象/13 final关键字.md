# 13 final关键字

* `final` 修饰的类无法被继承（如 `String`）
* `final` 修饰的方法不能被覆盖
* `final` 修饰的变量一旦赋值，不能重新赋值
* `final` 修饰的实例变量在构造方法执行前必须手动赋值，且不能重新赋值
* `final` 修饰的引用指向的对象不能改变，但对象的内部数据可以改变
* 类库中一部分 `final` 修饰的变量未被赋值是为了便于 JVM 在运行时赋值
* 常量：
* 被 `public static final` 修饰的变量
* 命名规范：所有单词大写，下划线分隔单词
