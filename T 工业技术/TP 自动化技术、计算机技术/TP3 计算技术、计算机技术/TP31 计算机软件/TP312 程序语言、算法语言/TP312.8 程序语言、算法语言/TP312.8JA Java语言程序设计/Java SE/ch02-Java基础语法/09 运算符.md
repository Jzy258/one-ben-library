# 09 运算符

* 运算符
	* 算术运算符：`+`、`-`、`*`、`/`、`%`、`++`、`--`
	* 关系运算符：`==`、`!=`、`>`、`>=`、`<`、`<=`
	* 逻辑运算符：`&`、`|`、`!`、`&&`、`||`
	* 按位运算符：`&`、`|`、`^`、`~`、`<<`、`>>`、`>>>`
	* 赋值运算符：`=`、`+=`、`-=`、`*=`、`/=`、`%=`、`&=`、`|=`、`^=`、`<<=`、`>>=`、`>>>=`
	* 条件运算符：`? :`
	* 其他运算符：`instanceof`、`new`、`.`
	* 优先级不需要记忆，不确定加小括号
* 算术运算符
	* `+`：
	* 求和（两边均为数字时）
	* 字符串拼接（只要有一边是字符串，且结果还是字符串）
	* `-`：求差，负数
	* `*`：求积
	* `/`：求商
	* 两个int相除时，得到的结果去尾
	* `%`：取模（约等于求余数）
	* 取模和取余的区别：
		* 取余：向0方向舍入
		* 取模：向负无穷方向舍入
	* `++`：自加一
	* `--`：自减一
* 接受用户输入
  ```java
  java.util.Scanner s = new java.util.Scanner(System.in);
  int num = s.nextInt();
  ```
	* 程序执行到 `s.nextInt()` 会停下来，等待键盘输入，用户输入内容后回车，代码执行结束
	* `s.nextInt()` 会从键盘扫描 `int` 类型的数字，然后赋值给 `num` 变量
	* `s.nextDouble()` 接收 `double` 类型的数据
	* `s.next()` 接收**第一个空格之前**的字符串
	* `s.nextLine()` 接收 `\n` 之前的内容
	* `s.nextLine()` 若调用了 `s.next()` 等方法，缓冲区中会留存 `\r` 字符（回车符），此时 `s.nextLine()` 就会读取到 `\r` 并返回值
* 自加1和自减1
	* **以下对 `--` 也适用**
	* `++` 可以出现在变量前，也可以出现在变量后
	* 一元运算符：运算符两边只有一个操作数
	* 二元运算符：运算符两边有两个操作数
	* `++` 在变量前或后的区别：
	* `++` 在后（后缀自加）：先获取值，后自加 1
	* `++` 在前（前缀自加）：先自加 1，后获取值
* 栈数据结构
	* 先进后出原则
	* 栈底：栈底部的元素
	* 栈顶：栈顶部的元素
	* Push（压栈，入栈）：元素进入栈，成为栈顶
	* Pop（弹栈，出栈）：栈顶元素出栈
* 字节码解读
	* `javap -c .class字节码文件`命令：查看字节码文件
	* 在 Java 语言中，任何一个方法执行时都会为该方法分配所属的内存空间，包括：局部变量表，操作数栈
	* 局部变量表存储局部变量，有若干槽位
	* `bipush 10`：将字面量 10 压入操作数栈
	* `istore_1`：将栈顶元素存储到局部变量表的 1 号槽位
	* `iload_1`：将局部变量表 1 号槽位上的数据复制一份，压入操作数栈
	* `iinc 2,1`：将局部变量表 2 号槽位上的数据加 1
* 关系运算符（比较运算符）
	* `>`：判断是否大于
	* `>=`：判断是否大于等于
	* `<`：判断是否小于
	* `<=`：判断是否小于等于
	* `==`：判断是否等于
	* `!=`：判断是否不等于
	* 所有关系运算符的结果都是布尔类型
* 逻辑运算符
	* `&`：逻辑与（并且）
	* `|`：逻辑或（或者）
	* `^`：逻辑异或
	* `!`：逻辑非
	* `&&`：短路与
	* `||`：短路或
	* 逻辑运算符两边的操作数都是布尔类型，运算结果也是布尔类型
	* 逻辑与和逻辑或无论运算符前后计算结果如何，都会执行；短路与若运算符前为 `false`，则结果为 `false`，运算符后不执行；短路或若运算符前为 `true`，则结果为 `true`，运算符后不执行
	* 大多数情况下使用短路与和短路或，能提高效率
* 按位运算符
	* `<<`：左移，将二进制数所有位向左移动 n 位，相当于将数值乘以 2 的 n 次方；不改变符号；左移后右补 0；溢出截断
	* `>>`：右移，将二进制数所有位向右移动 n 位，相当于将数值除以 2 的 n 次方；不改变符号；正数时右移后左补 0。负数时右移后左补 1；溢出截断
	* `>>>`：无符号右移，将二进制数所有位向右移动 n 位，相当于将数值除以 2 的 n 次方；右移后左补 0，结果一定是非负数；溢出截断
	* `&`：按位与，将二进制数每一位进行与运算
	* `|`：按位或，将二进制数每一位进行或运算
	* `^`：按位异或，将二进制数每一位进行异或运算，具有自反性
	* `~`：按位取反，将二进制数每一位进行非运算
	* 按位运算符的操作数为整数
	* 位运算符操作的都是补码
* 赋值运算符
	* 基本的赋值运算符：`=`
	* 扩展的赋值运算符：`+=`、`-=`、`*=`、`/=`、`%=`（、`>>=`、`<<=`、`>>>=`、`&=`、`|=`、`^=`、`~=`）
	* 扩展的赋值运算符自带强制类型转换
* 条件运算符
	* 语法格式：`布尔表达式 ? 表达式1 : 表达式2`
	* 布尔表达式为 `true` 时，返回表达式 1 的值；布尔表达式为 `false` 时，返回表达式 2 的值
