* Java语言概述
	* 面向对象
	* 底层由 C++ 语言实现
	* 由 Sun Microsystems 公司推出，后被甲骨文（Oracle）收购
	* Java之父：詹姆斯·高斯林（James Gosling）
	* Java 原名 Oak，Java 的名字源于印度尼西亚的爪洼岛
* Java 语言发展史
	* 1995年：Java语言诞生
	* 2014年：Java SE 8（长期支持的版本）
	* 2018年9月：Java SE 11（长期支持的版本）
	* 2021年9月：Java SE 17（长期支持的版本）
	* 2023年9月：Java SE 21（长期支持的版本）
	* 每半年推出一个新版本
* Java的三大分支
	* Java SE（Java Standard Edition）：用于开发桌面应用程序、控制台程序和小型服务端应用程序等
	* Java EE（Java Enterprise Edition）：用于开发大型企业级应用程序，如电子商务系统、ERP 系统、CRM 系统等
	* Java ME（Java Micre Edition）：用于嵌入式设备和移动设备上的应用程序开发，如手机、平板电脑、数码相机、路由器等
* Java语言特点
	* 跨平台性：一次编译到处运行
	* 健壮性：自动垃圾回收机制（GC）
