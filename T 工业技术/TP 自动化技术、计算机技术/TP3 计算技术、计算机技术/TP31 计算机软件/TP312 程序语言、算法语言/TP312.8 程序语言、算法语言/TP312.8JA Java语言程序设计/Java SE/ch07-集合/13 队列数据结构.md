* 一种特殊的线性表，只允许在表的前端（出口、队头）删除，在表的后端（入口、队尾）插入
* FIFO：先进先出
* `Deque` 同时支持 FIFO 和 LIFO，被称为双端队列
* 实现
* 使用链表实现：`LinkedList`
* 使用数组实现：`ArrayDeque`
* `LinkedList` 实现了双线链表，因此实现了双端队列；既实现了队列的 `offer()` 和 `poll()` 方法，也实现了双端队列的 `offerFirst()`、`offerLast()`、`pollFirst()` 和 `pollLast()` 等方法
* `ArrayDeque` 底层使用环形数组实现，比 `LinkedList` 更高效
* 环形数组下标的查找：`index = (start + i) % capacity`
* `Queue` 类：
* `offer()`：入队
* `poll()`：出队，队列为空则返回 `null`
* `remove()`：出队，队列为空则抛异常
* `peek()`：查看队头元素，为空则返回null
* `element()`：查看对头元素，为空则抛异常
* `Deque` 类：
* `offerLast()`：从队尾入队
* `pollFirst()`：从队头出队
* `offerFirst()`：从队头入队
* `pollLast()`：从队尾出队
