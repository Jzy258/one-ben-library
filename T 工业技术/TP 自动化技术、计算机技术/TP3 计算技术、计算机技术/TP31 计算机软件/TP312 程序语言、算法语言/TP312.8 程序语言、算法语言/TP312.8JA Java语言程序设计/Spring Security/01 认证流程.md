* 认证（Authentication）：
	* 证明用户身份
	* 需要检验：
		* 用户名、密码、JWT、验证码
* 授权（Authorization）：
	* 检验用户是否拥有权限
	* 需要检验：
		* 用户角色、是否有特定权限
* Spring Security：
	* **本质**：
		* 一系列过滤器，依次处理每个请求
	* 主要功能：
		* 认证
		* 授权
		* 安全防护
* 过滤器链：
	* `SecurityContextPersistenceFilter`：
		* 从 Session 获取认证信息，结束后存回
	* `UsernamePasswordAuthenticationFilter`：
		* 拦截 `/login`，提取用户名和密码并尝试认证
	* `ExceptionTranslationFilter`：
		* 将认证 / 授权异常转换为 401 / 403 响应
	* `FilterSecurityInterceptor`：
		* 检查当前用户是否有权限访问当前 URL
* 一次用户名密码登录的流程：
	* 用户在登陆页面提交用户名和密码
	* `UsernamePasswordAuthenticationFilter` 构造 `UsernamePasswordAuthenticationToken`
	* `AuthenticationManager` 挑选能处理的 `Provider`
	* `DaoAuthenticationProvider` 调用 `UserDetailsService` 的`loadUserByUsername` 查数据库，返回 `UserDetails`
	* `DaoAuthenticationProvider` 调用 `PasswordEncoder.matches` 比对密码
		* 成功：
			* 生成认证的 `Authentication` 并存入 `SecurityContext`
		* 失败：
			* 抛出 `BadCredentialsException`
			* `ExceptionTranslationFilter` 处理为 401 响应
* 需要自定义的组件：
	* `UserDetailsService`：
		* 包装用户名、加密后的密码、角色等信息，保存在内存中或数据库中
		* 实现 `loadUserByUsername`
	* `PasswordEncoder`：
		* 指定密码的加密方式
		* 通常使用 `BCryptPasswordEncoder`
	* `SecurityFilterChain`：
		* 指定认证规则
		* 设定放行的 URL 和需要认证的 URL
		* 是否启用默认登录页 `/login`
* 最小认知闭环：
	* 所有接口默认需要认证
	* 未登录访问默认跳转到登录页 `/login`
	* 控制台会答应一个随机默认用户 `user` 和默认密码
* BCrypt：
	* 加盐单向哈希
	* 单向：
		* 只能由明文推出密文，无法反向推出
	* 随机盐：
		* 每次加密随机生成盐，结果都不一样
	* 自包含：
		* 盐内嵌在密文里
		* 密文中各段信息使用 `$` 分隔
		* 第二段表示加密强度，默认强度为 10
	* 验证时使用 `matches()` 重新计算，而非使用 `equals()` 直接比较
		* Spring Security 会自动调用
* `UserDetailsService` 的实现：
	* `User` 采用建造者模式
		* `withUsername`：
			* 指定用户名
		* `password`：
			* 指定密码（加密后的）
		* `roles`：
			* 指定角色
	* `InMemoryUserDetailsManager`：
		* 实现了 `UserDetailsService`
		* 将用户信息存放在内存中
* `SecurityFilterChain` 的实现：
	* 传入 `HttpSecurity` 对象，采用建造者模式：
		* `authorizeHttpRequests`：
			* 注册访问权限规则
			* 先匹配的先生效
			* `requestMatchers`：
				* 匹配路径
				* 支持 `/**` 通配符匹配所有下级路径
			* `permitAll`：
				* 无需登录即可访问
			* `hasRole(角色)`：
				* 需要指定的角色身份
				* 自动添加 `ROLE_` 前缀
			* `anyRequest`：
				* 兜底剩余请求
			* `authenticated`：
				* 需要登录才能访问
		* `formLogin`：
			* 配置登录表单，使用默认登录页
			* 登陆成功自动跳转回原页面
		* `csrf`：
			* 配置 POST 请求是否被 403 拦截
			* 默认开启
* 会话机制：
	* 登录成功
	* 服务器存 Session，包含认证信息
	* 浏览器存 `JSESSIONID` Cookie
	* 每次请求附带 Cookie 便于认证
	* `SecurityContextHolderFilter` 从服务器中存储的 Session 恢复认证
