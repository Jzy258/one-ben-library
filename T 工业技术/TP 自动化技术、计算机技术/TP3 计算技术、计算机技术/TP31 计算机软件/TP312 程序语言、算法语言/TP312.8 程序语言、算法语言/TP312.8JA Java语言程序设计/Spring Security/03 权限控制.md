* 授权粒度：
	* URL 级：
		* 先校验
		* 使用 `SecurityConfig` 的 `requestMatchers` 按路径整段检验
	* 方法级：
		* 后校验
		* 使用 `@PreAuthorize` 注解按接口 / 方法精细控制
* 角色-权限模型：
	* `hasRole`：
		* 检验是否为指定角色
		* 存储格式：
			* `ROLE_ADMIN`
	* `hasAuthority`：
		* 检验用户是否有指定权限
		* 存储格式：
			* `user:delete`
	* `hasAnyRole`：
		* 检验是否为指定角色中的任意一种
* 开启方法级安全：
	* `@EnableMethodSecurity`
	* `@PreAuthorize(权限检验语句)`
* 集成 JWT：
	* `JwtAuthenticationFilter` 设置认证时可以指定 `authorities` 参数
		* `@PreAuthorize()` 等检查的就是 `authorities`
	* `JwtUtil`：
		* 生成 token 时添加角色列表的 `claim`
	* 过滤器：
		* 解析出 `roles`，拼接 `ROLE_`，转换成 `List<GrantedAuthority>`
	* 接口：
		* 加 `@PreAuthorize`
* 无权限的响应：
	* 已认证但无权限：
		* `@PreAuthorize` 抛出 `AccessDeniedException`
		* 403
	* 未认证：
		* 401
