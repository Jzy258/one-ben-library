现代开发一般集成第三方缓存（如 redis），并使用 Spring Cache 管理

二级缓存的范围为 `SqlSessionFactory`

开启二级缓存：
* 在 `mybatis-config.xml` 中配置：
	```xml
	<setting name="cacheEnabled" value="true">
	```
	* 默认开启
* 在需要使用二级缓存的 SqlMapper XML 文件中添加配置：
	```xml
	<cache />
	```
* 实体类对象可序列化，实现 `java.io.Serializable`
* `SqlSession` 提交或关闭后，一级缓存的数据写入二级缓存

只要出现增删改操作，二级缓存就会清空

配置项：
* `eviction`：
	* 指定从缓存中移除某个对象的淘汰算法，默认为 LRU
	* `LRU`：优先淘汰间隔时间内使用频率最低的对象
	* `FIFO`：先进入缓存的对象优先被淘汰
	* `SOFT`：软引用，内存不够时垃圾回收器才会回收
	* `WEAK`：弱引用，只要垃圾回收器一工作就回收
* `flushInterval`：
	* 二级缓存的刷新时间间隔
* `readOnly`：
	* `true`：多条相同的 `SELECT` 语句执行后返回同一个对象，在多线程并发的情况下可能出现问题
	* `false`：多条相同的 `SELECT` 语句执行后返回对象的副本（调用 `clone` 方法），性能一般但安全
* `size`：
	* 二级缓存中最多缓存的 Java 对象数量，默认为 1024
