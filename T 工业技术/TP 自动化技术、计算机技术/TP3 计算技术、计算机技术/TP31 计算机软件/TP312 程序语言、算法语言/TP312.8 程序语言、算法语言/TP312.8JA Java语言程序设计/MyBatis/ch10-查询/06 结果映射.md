# 06 结果映射

解决查询结果的字段名与对象属性名不能对应的问题：
* 方案一：为字段名起别名
* 方案二：使用 `<resultMap>` 进行结果映射
	* `id` 属性为该 `resultMap` 的唯一标识
	* `type` 属性为配置的 POJO 类（由于别名机制，可以只写简名）
	* 包含一个 `<id>` 标签，用于指定主键，提高 MyBatis 效率；若干 `<result>` 标签：
		* `property` 属性为对象的属性名
		* `column` 属性为字段名
* 方案三：
	* 在 `mybatis-config.xml` 的 `<settings>` 中配置：
      ```xml
    	<setting name="mapUnderscoreToCamelCase" value="true"/>
      ```
	* MyBatis 能自动将数据库中 snake_case 风格的字段名映射到 camelCase 风格的对象属性名
