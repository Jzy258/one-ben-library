# 01 占位符

`#{}` 和 `${}` 的区别：
* `#{}`：
	* 预编译占位，将 SQL 语句中的参数用 `?` 替换，再将参数传入
	* 会自动在参数外包裹 `'`
* `${}`：
	* 直接字符串替换
	* SQL 注入会导致安全问题

一般优先使用 `#{}`，保证安全

使用 `${}` 的情景：
* 指定语句中的关键字（如 `asc`、`desc` 等）
* 拼接表名
* 批量删除（使用 `in(...)`）
* 模糊查询：
	* `'%${...}%'`
	* `concat('%', #{...}, '%')`
	* `concat('%', '${...}', '%')`
	* `"%"#{...}"%"`
