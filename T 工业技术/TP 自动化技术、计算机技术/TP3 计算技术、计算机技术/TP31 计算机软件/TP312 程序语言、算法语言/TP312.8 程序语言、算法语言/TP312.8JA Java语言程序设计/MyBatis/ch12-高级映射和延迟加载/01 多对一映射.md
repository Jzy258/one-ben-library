# 01 多对一映射

多对一映射：
* 多方为主表、主对象，一方为副表、副对象
* 主对象有副对象引用作为属性

级联属性映射：
```xml
<mapper namespace="cn.ginna.mybatis.mapper.EmployeeMapper">  
  
    <resultMap id="employeeResultMap" type="Employee">  
        <id property="id" column="id" />  
        <result property="eno" column="eno" />  
        <result property="ename" column="ename" />  
        <result property="department.dno" column="dno" />  
        <result property="department.dname" column="dname" />  
    </resultMap>  
    
    <select id="selectByEno" 
		resultType="cn.ginna.mybatis.pojo.Employee" 
		resultMap="employeeResultMap">  
        SELECT  
            e.eno, e.ename, d.dno, d.dname        
        FROM        
            t_employee AS e LEFT JOIN t_department AS d ON e.dno = d.dno  
        WHERE        
            e.eno = #{eno}
    </select>  
    
</mapper>
```

Association 映射：
```xml
<mapper namespace="cn.ginna.mybatis.mapper.EmployeeMapper">

    <resultMap id="employeeResultMapAssociation" type="employee">  
        <id property="id" column="id" />  
        <result property="eno" column="eno" />  
        <result property="ename" column="ename" />  
        <association property="department" javaType="department">  
            <id property="id" column="id" />  
            <result property="dno" column="dno" />  
            <result property="dname" column="dname" />  
        </association>    
    </resultMap>  
    
    <select id="selectByEnoAssosiation" 
		resultType="cn.ginna.mybatis.pojo.Employee" 
		resultMap="employeeResultMapAssociation">  
        SELECT
            e.eno, e.ename, d.dno, d.dname    
        FROM
	        t_employee AS e LEFT JOIN t_department AS d ON e.dno = d.dno  
        WHERE
	        e.eno = #{eno}    
	</select>
	
</mapper>
```

分步查询：
* 可复用
  ```xml
  <!-- EmployeeMapper.xml -->
  <mapper namespace="cn.ginna.mybatis.mapper.EmployeeMapper">

	<resultMap id="employeeResultMapStep" type="employee">  
	    <id property="id" column="id" />  
	    <result property="eno" column="eno" />  
	    <result property="ename" column="ename" />  
	    <association property="department" 
		    select="cn.ginna.mybatis.mapper.DepartmentMapper.selectByDno" 
		    column="dno" />  
	</resultMap>  
  
	<select id="selectByEnoStep01" 
		resultType="cn.ginna.mybatis.pojo.Employee" 
		resultMap="employeeResultMapStep">  
	    SELECT  
	        t_employee.eno, t_employee.ename, t_employee.dno    
		FROM        
			t_employee    
		WHERE        
			eno = #{eno}
	</select>

  </mapper>
  ```
```xml
<!-- DepartmentMapper.xml -->
<mapper namespace="cn.ginna.mybatis.mapper.DepartmentMapper">  
  
    <select id="selectByDno" 
	    resultType="cn.ginna.mybatis.pojo.Department">  
        SELECT  
            t_department.dno, t_department.dname        
        FROM            
	        t_department        
	    WHERE            
		    dno = #{dno}    
	</select>  
  
</mapper>
```
* 懒加载（Lazy Loading，延迟加载）：
	* **作用**：
		* 优化性能
		* 在查询主对象时不会立即查询其关联的对象，而是等到真正访问该关联对象时执行额外的 SQL 查询
	* **适用于**：
		* `<association>`（一对一查询）
		* `<collection>`（一对多查询）
		* 必须为嵌套查询而非多表连接查询
		* 在同一个 `SqlSession` 中有效
	* **实现原理**：
		* 查询主对象时，对配置了懒加载的关联属性填充代理对象
		* 第一次调用该关联对象的 Getter 方法时，代理对象拦截此次调用
		* 代理对象触发预先定义的关联查询 SQL，获取真实数据
		* 代理对象将帧数数据设置到目标对象的属性中，并替换自身
	* **配置**：
		* 全局配置：
			* 在 `mybatis-config.xml` 中配置 `<setting name="lazyLoadingEnabled" value="true" />` 和 `<setting name="aggressiveLazyLoading" value="false" />`
				* `lazyLoadingEnabled`：
					* 懒加载总开关
				* `aggressiveLazyLoading`：
					* 侵略性懒加载
					* 当执行主对象中的任意方法时获取关联对象的真实数据
		* 局部配置：
			* `<association ... fetchType="lazy" />`
			* `<collection ... fetchType="lazy" />`
	* **优点**：
		* 有效提升性能
	* **缺点**：
		* 可能引发 N+1 查询问题，即查询 1 个主对象后需要额外执行 N 次查询来获取 N 个关联对象，可能导致用户等待时间变长
* 全局延迟加载：
	* 在 `mybatis-config.xml` 中配置：
      ```xml
		<setting name="lazyLoadingEnabled" value="true"/>
      ```
	* 关闭某一条 SQL 语句的延迟加载：
      ```xml
    	<association 
		property="department"
		select="cn.ginna.mybatis.mapper.DepartmentMapper.selectByDno" 
		column="dno"
		fetchType="eager" />
      ```
