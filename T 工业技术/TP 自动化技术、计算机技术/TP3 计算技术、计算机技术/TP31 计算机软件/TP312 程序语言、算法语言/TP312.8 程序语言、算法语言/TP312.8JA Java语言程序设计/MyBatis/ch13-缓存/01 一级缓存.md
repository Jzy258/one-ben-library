# 01 一级缓存

* MyBatis 缓存机制：
	* **作用**：
		* 将 `SELECT` 语句的结果存储到缓存（内存）中，重复执行时直接从缓存获取
		* 减少 IO，且不再执行查找算法，效率提升
	* MyBatis 中的缓存：
		* 一级缓存：
			* 将数据存储到 `SqlSession` 中
				* 默认开启
		* 二级缓存：
			* 将数据存储到 `SqlSessionFactory` 中
				* 不常用，一般使用 redis 等第三方缓存
* 一级缓存：
	* **原理**：
		* 对同一个 `SqlSession` 使用同一条 `SELECT` 语句，则优先从缓存中获取数据
	* 刷新一级缓存：
		* `SqlSession.clearCache();`
	* 若执行了 `INSERT`、`DELETE`、`UPDATE` 则清空一级缓存
