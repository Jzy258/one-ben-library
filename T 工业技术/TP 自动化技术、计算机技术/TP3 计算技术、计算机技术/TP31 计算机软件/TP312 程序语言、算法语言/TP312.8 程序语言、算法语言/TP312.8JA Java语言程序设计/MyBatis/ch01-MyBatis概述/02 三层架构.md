目的：
* 降低代码耦合度
* 提高代码的复用性

三层架构（后端）：
* 表现层（UI）：
	* 通过 AJAX 接收前端的请求
	* 将数据以 JSON 的形式返回给前端
* 业务逻辑层（BLL）：
	* 处理表现层转发来的前端请求（具体业务）
	* 将从持久层获取的数据返回给表现层
* 数据访问层（持久层，DAL）：
	* 与数据库交互完成 CRUD
	* 将获得的数据返回给业务逻辑层

Java 的持久层框架：
* MyBatis
* Hibernate（实现 JPA 规范）
* jOOQ
* Guzz
* Spring Data（实现 JPA 规范）
* ActiveJDBC
* ...
