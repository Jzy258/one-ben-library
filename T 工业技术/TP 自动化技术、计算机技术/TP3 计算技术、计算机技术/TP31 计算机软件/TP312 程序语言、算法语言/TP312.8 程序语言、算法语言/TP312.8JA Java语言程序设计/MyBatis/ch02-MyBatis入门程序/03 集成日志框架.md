# 03 集成日志框架

`mybatis-config.xml` 中 `<settings>` 可指定某些设置，每个设置项对应一个 `<setting>`，包含 `name` 和 `value` 属性

MyBatis 常见日志组件：
* SLF4J
* LOG4J
* LOG4J2
* STDOUT_LOGGING

`<setting name="logImpl" value="日志组件">` 可以设定 MyBatis 使用的日志组件
* STDOUT_LOGGING 是 MyBatis 对日志框架的实现，信息包括连接对象创建时间、关闭时间、SQL 语句等
* 未指定时自动查找

引入 logback 日志框架：
* 引入依赖
* 配置 `logback.xml`
