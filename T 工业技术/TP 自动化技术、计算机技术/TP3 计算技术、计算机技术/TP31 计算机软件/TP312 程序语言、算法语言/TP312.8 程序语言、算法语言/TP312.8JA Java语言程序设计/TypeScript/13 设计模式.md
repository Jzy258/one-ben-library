* TS 可以通过自定义类型简化设计模式的实现
* 单例模式：
	* 构造器私有化与 Java 的区别：
		* Java：`private` 修饰的构造器在使用 `new` 时会被 JVM 拒绝
		* JS：`private` 只在编译期检查，编译后擦除，运行时 `new` 能成功
	* 现代 JS 项目中通常将模块作为单例
		* ESM 模块天然只会执行 1 次
		```ts
export const config = { theme: 'dark', version: '1.0' }
		```
* 策略模式：
	```ts
type PayStrategy = (amount: number) => string;  
  
const alipay: PayStrategy = (amount: number) => `支付宝支付 ${amount} 元`;  
const wechat: PayStrategy = (amount: number) => `微信支付 ${amount} 元`;  
const creditCard: PayStrategy = (amount: number) => `银行卡支付 ${amount} 元`  
  
class PaymentContext {  
    constructor(  
        private _payStrategy: PayStrategy  
    ) {}  
  
    setPayStrategy(payStrategy: PayStrategy): void {  
        this._payStrategy = payStrategy;  
    }  
  
    pay(amount: number): string {  
        return  this._payStrategy(amount);  
    }  
}
	```
* 观察者模式：
	```ts
type Observer<T> = (data: T) => void;  
  
class Subject<T> {  
    private _observers: Observer<T>[] = [];  
  
    subscribe(fn: Observer<T>): () => void {  
        this._observers.push(fn);  
        return () => {  
            this._observers = this._observers.filter(o => o !== fn);  
        }  
    }  
  
    notify(data: T): void {  
        for (const observer of this._observers) {  
            observer(data);  
        }  
    }  
}
	```
* 工厂模式：
	```ts
type ShapeInput =  
    | { kind: 'circle', radius: number }  
    | { kind: 'square', size: number }  
  
function createShape(input: ShapeInput): Shape {  
    switch (input.kind) {  
        case 'circle':  
            return new Circle(input.radius);  
        case 'square':  
            return new Square(input.size);  
        default:  
            const _: never = input;  
            throw new Error(`未知的 Shape 类型`)  
    }  
}
	```
* 适配器模式：
	```ts
interface LegacyUser {  
    username: string;  
    age: number;  
    email: string | null;  
}  
  
interface AppUser {  
    name: string;  
    age: number;  
    email: string;  
}  
  
function adaptToAppUser(legacy: LegacyUser): AppUser {  
    return {  
        name: legacy.username,  
        age: legacy.age,  
        email: legacy.email === null ? '无' : legacy.email  
    }  
}
	```
