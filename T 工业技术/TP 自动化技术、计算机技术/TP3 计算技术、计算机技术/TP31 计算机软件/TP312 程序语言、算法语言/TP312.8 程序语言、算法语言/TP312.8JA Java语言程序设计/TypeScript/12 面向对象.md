# 12 面向对象

* 构造器：
  ```ts
  class User {
  id: number;
  name: string;
  age?: number;

  constructor(id: number, name: string, age?: number) {
    this.id = id;
    this.name = name;
    if (age !== undefined) {
      this.age = age;
    }
  }
  }
  ```
	* 参数属性：
      ```ts
      class NewWay {
      constructor(
      public name: string,
      private age: number,
      readonly id: number
      ) {}
      }
      ```
		* 能自动生成 `this.属性` 并赋值
		* `private`  属性在类外部不能直接访问
		* `readonly` 属性不能再次赋值
	* TS 的属性默认修饰符为 `public`
* Getter 和 Setter：
  ```ts
  class BankAccount {
  private _balance: number = 0;

  get balance(): number {
    return this._balance;
  }
  
  set balance(amount: number) {
    if (amount < 0) {
      throw new Error('余额不能为负数！');
    }
    this._balance = amount;
  }
  }
  ```
	* 私有属性通常使用 `_` 开头，以避免与 Getter 和 Setter 重名
	* （ES2022）运行时私有字段：
		* 以 `#` 开头的字段是真正意义上的私有属性
* 抽象类：
	* TS 的抽象类在编译成 JS 后会变成普通类，抽象方法会被移除
      ```ts
      abstract class Animal {

      abstract makeSound(): void;
  
      sleep(): void {
      console.log('Zzz...');
      }
      }

      class Dog extends Animal {
      makeSound(): void {
      console.log('汪汪！');
      }
      }
      ```
	* 抽象方法默认是 `public`，可以设为 `protected`，但不能是 `private`
	* 不支持多继承
* 接口：
	* `interface` 与 `class` 允许同名共存
* 装饰器：
	* **作用**：
		* 在调用方法前 / 后执行额外逻辑
          ```ts
          function log(target: any, key: string, descriptor: PropertyDescriptor) {
          const original = descriptor.value;
          descriptor.value = function (...args: any[]) {
          console.log(`调用 ${key}:`, args);
          return original.apply(this, args);
          };
          }

          class Calculator {
          @log
          add(a: number, b: number) { return a + b; }
          }
          ```
