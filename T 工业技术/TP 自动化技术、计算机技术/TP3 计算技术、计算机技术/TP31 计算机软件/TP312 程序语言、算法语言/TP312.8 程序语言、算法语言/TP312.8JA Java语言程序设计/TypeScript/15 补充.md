# 15 补充

* 提取二维数组的某一列：
  ```ts
  const matrix: number[][] = [
	[1, 2, 3],
	[4, 5, 6],
	[7, 8, 9]
  ]

  const column: number = matrix.map(row => row[1]);

  console.log(column);  // [2, 5, 8]
  ```
* 导入时在模块名前添加 `node:` 以标识为内置模块
* `node:readline` 模块：
	* Node.js 内置的逐行读取模块
	* **作用**：
		* 从任何可读流中按行读取数据
		* 等待用户输入
		* 逐行读取大文件
	* `readline/promises`：
		* Promise 版，支持 `Promise` 返回值，避免编写回调函数
	* `readline.createInterface({ input, output })`：
		* 创建逐行读取器实例，并绑定 `input` 输入流和 `output` 输出流
	* `readline#question(string)`：
		* 
* `node:process` 模块：
	* Node.js 的核心全局对象
	* **作用**：
		* 提供当前 Node.js 进程的运行时信息和控制能力，如：
			* 环境变量、命令行参数、标准输入输出流、进程退出
* 导入模块时可以使用 `as` 取别名：
  ```ts
  import { stdin as input, stdout as output } from 'node:process';
  ```
