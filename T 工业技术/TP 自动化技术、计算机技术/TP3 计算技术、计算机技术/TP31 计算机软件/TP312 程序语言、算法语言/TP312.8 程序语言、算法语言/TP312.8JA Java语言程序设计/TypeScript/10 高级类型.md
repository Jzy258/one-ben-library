* 可辨识联合：
	```ts
type FormState =
	| { status: 'idel' }
	| { status: 'filling', data: Record<string, unknown> }
	| { status: 'submitting', progress: number }
	| { status: 'success', message: string }
	| { status: 'error', code: number, message: string }
	```
	* 核心思想：
		* 每个联合成员都有一个唯一的标签字段
	* 穷举性检查：
		```ts
function assertNever(x: never): never {
	throw new Error('意外的状态：' + x);
}
		```
		* 本身在运行时没有任何作用
		* 用于在编译期确认上文中的条件已经被完全穷举，该方法不可能被执行
		* 当后续需要添加条件时，此处会因为类型不匹配而显式报错（编译错误）
* 映射类型与条件类型：
	* 将所有属性变为只读：
		```ts
type MyReadonly<T> = {
	readonly [K in keyof T]: T[K];
}
		```
	* 将所有属性变为可选：
		```ts
type MyPartial<T> = {
	[K in keyof T]?: T[K];
}
		```
	* 条件类型：
		```ts
type MyReturnType<T> = T extends (...args: any[]) => infer R ? R : never;
		```
	* 实际使用 `Partial`、`Pick`、`Omit`、`ReturnType` 即可，无需手动实现
