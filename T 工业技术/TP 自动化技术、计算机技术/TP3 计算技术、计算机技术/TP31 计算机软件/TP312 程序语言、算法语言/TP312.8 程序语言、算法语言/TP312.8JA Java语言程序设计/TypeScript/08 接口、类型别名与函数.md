* `interface`：
	* 声明：
		```ts
interface Config {
	url: string;
	method?: 'GET' | 'POST',
	timeout?: number;
}
		```
	* 索引签名：
		```ts
interface StringMap {
	[key: string]: string;
}
		```
	* 接口继承：
		```ts
interface BaseEntity {
	id: number;
	readonly createdAt: Date;
}

interface Product extends BaseEntity {
	name: string;
	price: number;
}
		```
* `type` 与交叉类型：
	* 类型合并：
		```ts
type WithId = {
	id: number;
}
type WithTimestamp = {
	createdAt: Date;
	updatedAt: Date;
}

type Entity = WithId & WithTimestamp;
		```
* 函数类型与重载：
	* 函数类型表达式：
		```ts
type GreetFn = (name: string) => string;

const greet: GreetFn = (name) => 'Hello, ${name}';
		```
	* 回调函数中的 `this` 类型：
		```ts
interface Button {
	onClick(this: HTMLElement, event: MouseEvent): void;
}
		```
	* 函数重载：
		```ts
function getData(id: number): User;
function getData<T extends keyof User>(id: number, field?: T): User[T];

function getDate(id: number, field?: string): unknown {
	const user = fetchUser(id);
	return field ? user[field] : user;
}
		```
* 类型断言与 `as const`：
	* 双重断言：
		```ts
const x = 'hello' as unknown as number;
		```
		* 强制转换
		* 极少使用
	* 非空断言：
		```ts
function process(id: string | null) {
	const sureId = id!;  // 若 id 为 null 则运行时崩溃
}
		```
