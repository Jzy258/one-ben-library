* 事件循环机制：
	* 将慢操作挂起，先执行其他任务
	* **解决问题**：
		* JS 单线程执行慢任务导致整个程序卡死
* `Promise`：
	* `Promise.all()`：
		* 接收一个 `Promise` 数组，并发执行所有异步任务，并等待全部成功
		* `resolve` 值为顺序与输入完全一致的结果数组
		* 能将结果数据推断为元组类型而非宽泛的数组
		* 快速失败：
			* 只要有一个 `reject`，则整个 `Promise` 立即 `reject`，其他的 `resolve` 会被直接放弃
	* `resolve`：
		* 将 `Promise` 从等待状态变为成功状态，并设为最终结果值
		* 回调函数自带的参数，由 JS 引擎注入
		* `async` 函数的返回值会自动被 JS 使用 `resolve` 包装
* IIFE（Immediately Invoked Function Expression）：
	* 定义完则立即执行的函数
	```ts
(function() { /* 函数体 */ })();

(() => { /* 函数体 */ })();
	```
	* **作用**：
		* 不创建函数对象，防止污染全局
		* 在不支持顶级 `await` 的旧版本中创建独立的异步作用域
