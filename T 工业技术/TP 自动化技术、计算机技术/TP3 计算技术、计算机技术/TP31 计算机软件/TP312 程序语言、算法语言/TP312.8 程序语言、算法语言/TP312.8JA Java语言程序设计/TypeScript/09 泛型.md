# 09 泛型

* 泛型约束：
	* `extends` 约束：
      ```ts
      // 约束 T 类型必须要有 length 属性
      function logLength<T extends { length: number }>(item: T): number {
    	console.log(item.length)
    	return item.length
      }
      ```
	* `keyof` 约束：
      ```ts
      function getProp<T, K extends keyof T>(obj: T, key: K): T[K] {
    	return obj[key];
      }
      ```
		* 安全的更新函数：
          ```ts
          function update<T, K extends keyof T>(obj: T, key: K, value: T[K]): T {
        	return { ...obj, [key]: value }
          }
          ```
* 泛型工具类型：
	* `Partial<T>`：
      ```ts
      type PartialUser = Partial<User>;
      ```
		* 将所有属性变为可选
	* `Required<T>`：
      ```ts
      type RequiredConfig = Required<Partial<User>>;
      ```
		* 将所有属性变为必填项
	* `Pick<T, K>`：
      ```ts
      type UserPublicInfo = Pick<User, 'id' | 'name' | 'email'>;
      ```
		* 挑选部分属性
	* `Omit<T, K>`：
      ```ts
      type UserWithoutPassword = Omit<User, 'password'>;
      ```
		* 排除部分属性
	* `Record<K, T>`：
      ```ts
      type PageInfo = Record<string, string>;
      const pages: PageInfo = { home: '/', about: '/about' }
      ```
		* 构造对象类型
	* `Readonly<T>`：
      ```ts
      type ImmutableUser = Readonly<User>;
      ```
		* 所有属性只读

---
补充：
* `<T = unknown>`：
	* 默认泛型
	* 自定义类型的属性类型为 `T` 时，则 `T` 被赋值为该属性的特定类型
	* 指定了默认泛型后，支持不传入该属性
