# 11 模块系统

* 模块系统：
	* 命名导出：
      ```ts
      export function add(a: number, b: number): number { return a + b }
      export const PI = 3.14159;
      ```
		* 必须使用原名或使用 `as` 重命名
	* 默认导出：
      ```ts
      export default class Calculator { /* ... */ }
      ```
		* 导入时可以随意取名
		* 每个文件中只能有 1 个
	* 导入：
      ```ts
      import Calculator, { add, PI } from './path/to/file'
      ```
	* 类型导入导出在编译后会被移除
	* 行内类型导入：
      ```ts
      import { ref, type Ref } from './path'
      ```
	* 重导出：
      ```ts
      export { add } from './origin/path'
      ```
* ESM 规则要求导入路径必须带真实文件扩展名

补充：
* `String.prototype.replace`：
	* **作用**：
		* 匹配字符串并替换
	* 基本替换：
      ```ts
      const str = 'hello world, hello TS';

      // 替换第一个匹配项
      str.replace('hello', 'hi');  // 'hi world, hello TS'

      // 使用全局匹配模式的正则表达式替换全部匹配项
      str.replace(/hello/g, 'hi');  // 'hi world, hi world'

      // ES2021+ 的 replaceAll
      str.replaceAll('hello', 'hi');
      ```
	* 动态替换：
      ```ts
      const priceStr = 'Apple: $5, Banana: $10'
      const result = priceStr.replace(/(\d+)/g, (match, firstGroup) => {
    	const n = parseInt(num, 10);
    	return (n * 2).toString();
      })

      console.log(result);  // 'Apple: $10, Banana: $20'
      ```
		* 回调函数中的第一个参数：
			* 匹配的字符串
		* 回调函数中的第二个参数：
			* 第一个捕获组
* `Object.assign(target, ...sources)`：
	* **作用**：
		* 将 `sources` 所有可枚举自身属性复制到 `target` 中，并返回 `target`
		* 常用于实现浅拷贝
	* 返回值类型：
      ```ts
      function assign<T, U>(target: T, source: U): T & U;
      ```
	* 会修改 `target`
	* 若多个源对象有相同的键时，排在后面的源对象会覆盖前面的
		* 若同名属性不兼容，则最终的交叉类型会变成 `never`
	* **示例**：
		* 构造函数参数映射：
          ```ts
          class User {
          id: number = 0;
          name: string = '';
          age?: number;

          constructor(data: Partial<User>) {
          Object.assign(this, data);
          }
          }
          ```
		* 合并配置：
          ```ts
          interface Config {
          timeout: number;
          retry: boolean;
          url: string;
          }

          const defaultConfig: Config = {
          timeout: 5000,
          retry: true,
          url: '/api'
          };

          const userConfig = { timeout: 10000 };

          const finalConfig = Object.assign({}, defaultConfig, userConfig);
          ```
* 异步函数：
	* **作用**：
		* 处理耗时操作
	* 使用 `async` 标记
	* 内部可以使用 `await` 暂停执行
	* 返回值类型必须使用 `Promise<T>` 包裹
* `setTimeout(callback, delay[, args])`：
	* 使回调函数在指定毫秒数后执行
	* 调用带参回调函数时，参数在 `delay` 后面传入
* `typeof null` 的结果为 `'object'`
