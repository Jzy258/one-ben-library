* 原始类型：
	* 模板字符串：
		* 使用 `${}` 插值
	* `number` 类型不分整数或浮点
	* 大整数：
		* `const big: bigint = 100n`
		* 字面量以 `n` 为后缀
* 数组与元组：
	* 联合类型数组：
		* `const mixed: (string | number)[] = ['a', 1]`
	* 只读数组：
		* `const readonlyArr: readonly number[] = [1, 2, 3]`
		* 不能使用 `push` 等方法对数组进行修改操作
	* 元组：
		* 固定长度和类型的的数组
		* `const point: [number, number] = [10, 20]`
		* 元组标签：
			* 用于增强元组元素的可读性
			* `const httpResult: [statusCode: number, msg: string] = [200, 'OK']`
* 枚举：
	* 声明：
		* `enum Direction { Up, Down, Left, Right }`
			* `Direction.UP` 输出 0
			* `Direction[0]` 输出 `'Up'`
	* 手动赋值：
		* `enum HttpStatus { OK = 200, NotFound = 404, InternalError = 500 }`
		* `enum WeekDay { Mon = 1, Tue, Wed }`
			* `Tue` 的值为 `2`，`Wed` 的值为 `3`
	* 常量枚举：
		* `const enum ...`
		* 编译后枚举变量会被替换成对应的枚举值
	* 替代方案：
		* `const Direction = { Up: 'UP', Down: 'DOWN', Left: 'LEFT', Right: 'RIGHT' } as const;`
		* 不支持反向映射
		* 更轻量

补充：
* `for ... of`：
	* **作用**：
		* 遍历可迭代对象中的每一个元素值
	* 与 `for ... in` 的区别：
		* `for ... in` 适用于普通对象，用于遍历属性名
		* `for ... of` 适用于可迭代对象，用于遍历属性值
	* 配合 `[]`（解构）能遍历 `map` 的每个元素并直接获取 `key` 和 `value`
		* 可以用 `数组.entries()` 将数组转换成键值对数组，达到类似效果，以获取索引
	* 可以随时通过 `break` 跳出循环
	* 对于普通对象的 `for ... of` 实现方式：
		* 编写 `[Symbol.iterator]` 逻辑
		* 通过 `Object.values()` 或 `Object.entries()` 将普通对象转换成数组，再使用 `for ... of`
	* 每次获取到的迭代器都是全新的
		* 迭代器本身是有状态的
* `Symbol`：
	* 每个 `Symbol` 都是唯一的
		* *类似于UUID？*
	* 声明：
		* `let s1: symbol = Symbol();`
		* `let s2: symbol = Symbol('描述文字');`
		* `const` 的 `Symbol` 常使用 `unique symbol` 类型
	* 使用场景：
		* 作为唯一属性名
			* 计算属性名（Computed Property Name）：
				* 将 `[]` 中的变量（*或表达式？*）的值作为对象的属性
		* 隐藏私有属性：
			* `Symbol` 在常规的 `for ... in` 和 `Objects.keys()` 中无法被遍历
			* 可以实现伪私有
				* 仍能通过 `Symbol` 变量访问
	* `Symbol.iterator`：
		* 实现了数组的 `for ... of`、扩展运算符、解构赋值、`Array.from`、`new Set(arr)`、`new Map(arr)` 的逻辑
		* 可以在自定义的对象中编写 `[Symbol.iterator]` 逻辑以实现自定义对象的迭代逻辑
* `as const`：
	* 将变量转变为只读的字面值
	* `as const` 的对象，所有属性都会自动加上 `readonly` 修饰符
	* 与 `const` 声明的区别：
		* `const` 是浅层只读，只锁死了变量名的指向
		* `as const` 是深层只读，锁死了数据的内部结构
* 类型定义：
	* `interface`（接口）：
		* `interface User { id: number, name: string, age?: number, readonly createTime: Date; }`
		* `const user1: User = { id: 1, name: "Quecto", createTime: new Date() }`
