	* 未声明类型且赋值为 `null` 的变量推断类型为 `any`
	* `as const` 类型推断时添加 `readonly` 修饰符

补充：
* `Record<Keys, Type>`：
	* TS 内置的工具类型
	* **作用**：
		* 生成一个对象类型，该对象的属性名必须来自 `Keys`，属性值必须都是 `Type`
		* 用于约束普通对象的形状
	* **使用场景**：
		* 定义固定键的对象：
		```ts
type UserInfo = Record<"name" | "age" | "gender", string>

let user: UserInfo = {
	name: "Quecto",
	age: "18", 
	gender: "男" 
}
		```
		* 配合联合类型做映射字典：
		```ts
type Status = "pending" | "success" | "error";

const statusColor: Record<Status, string> = {
	pending: "orange",
	success: "green",
	error: "red"
};
		```
		* 处理动态数据：
		```ts
interface User {
	id: number,
	name: string
}

type UserDict = Record<number, User>;

const users: UserDict = {
	1: { id: 1, name: "Quecto" },
	2: { id: 2, name: "Ronto" }
};

console.log(users[1].name); // "Quecto"
		```
	* `keys` 不一定是 `string`，也可以是 `number` 或 `symbol`
	* 若值的类型不一致，则不能使用 `Record`，需要用 `interface` 分别定义
	* `Record` 中必须包含 `Keys` 中的所有元素
* 自定义类型守卫：
	* **本质**：
		* 返回值类型为 `xxx is Type` 的函数
	* **作用**：
		* 若函数返回 `true`，则 TS 编译器会在后续的代码中将传入该守卫的参数收缩为指定的精确类型
	```ts
interface Dog {
	bark(): void;
}

interface Cat {
	meow(): void;
}

function isDog(pet: unknown): pet is Dog {
	return (pet as Dog).bark !== undefined;
}

function petSound(pet: Dog | Cat) {
	if (isDog(pet)) {
		pet.bark();
	} else {
		pet.meow();
	}
}
	```
	* 过滤数组：结合 `filter`
		```ts
function isString(value: unknown): value is string {
	return typeof value === 'string';
}

const mixedArray: (string | null)[] = ['a', null, 'b', 'c'];
const result = mixedArray.filter(isString); 
result.forEach(item => item.toUpperCase());
		```
	* 穷尽检查：
		```ts
type Shape = Circle | Square | Triangle;

function isCircle(shape: Shape): shape is Circle { /* ... */ }
function isSquare(shape: Shape): shape is Square { /* ... */ }
// 剩下的自动被推断为 Triangle
		```
	* `as`：
		* 强制告知 TS 该变量的类型
	* `assert`：断言守卫
		* 不返回布尔值，而是在判断失败时直接抛出错误中断程序
			```ts
function assertIsString(value: any): asserts value is string {
  if (typeof value !== 'string') {
    throw new Error('不是字符串！');
  }
}
			```
	* 类型识别：
		* 基础类型：
			* `if (typeof x === 'string')`
		* 简单数组：
			* `if (Array.isArray(x))`
		* 自定义接口：
			* 自定义守卫
		* `null` 和 `undefined`：
			* `if (x !== null)`
