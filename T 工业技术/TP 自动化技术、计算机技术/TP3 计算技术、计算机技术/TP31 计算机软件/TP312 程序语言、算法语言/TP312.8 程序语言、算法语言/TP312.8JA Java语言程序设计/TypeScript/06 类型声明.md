# 06 类型声明

* 类型注解：
	* 在变量、参数、函数等后面添加 `: 类型` 指定对应的类型
* **语法**：
	* 基本类型：
		* `name: string`：
			* 字符串
		* `age: number`：
			* 数字类型
		* `flag: boolean`：
			* 布尔类型
	* 数组：
		* `scores: number[]`：
			* 基本类型数组
		* `names: Array<string>`：
			* 泛型数组
	* 对象：
		* `person: { name: string, age: number }`：
			* 内联
		* `type Person = { name: string; age: number; }`：
			* 提取声明
	* 函数：
		* 括号中写参数类型，括号外写返回值类型
		* `function greet(name: string): string { return "Hello, " + name; }`：
			* 普通函数
		* `const add = (a: number, b: number): number => { return a + b; };`：
			* 箭头函数
		* `function logMessage(msg: string): void { console.log(msg); }`：
			* 空返回值函数
	* 特殊语法：
		* `|`：
			* 联合类型
			* 左右两边二选一
		* `?`：
			* 可选属性
			* 该属性可有可无
		* `any`：
			* 任意类型
			* 传染性：
				* 赋值给其他变量，则其他变量也变成 `any` 类型
		* `unknown`：
			* 未知类型
			* 可以赋值任何值
			* 调用方法前必须使用 `typeof` 检查类型
		* `never`：
			* 永不存在的值
			* 是所有类型的子类型，可以赋值给任意类型的变量
			* 用于将断定是合法类型的值返回
	* 类型别名：
		* `type ID = number | string`：
			* 为 `number | string` 类型取别名 `ID`
			* 可以直接使用 `ID` 类型
		* 支持类型别名的嵌套：
			* `type UserInfo = {name: string, id: ID}`
* 函数参数限定：
	* 基础类型参数：
		* 实参与形参列表必须一一对应
	* 可选参数：
		* 部分参数可以使用 `?` 指定为可选，传入实参时可忽略
		* `function buildName(first: string, last: string, middle?: string): string { ... }`
		* 可选参数必须放在所有必填参数之后
	* 默认参数：
		* `function createUser(name: string, role: string = "user"): {name: string, age: number} { return {name, age}; }`
	* 剩余参数：
		* 接收不定数量的参数时可使用扩展运算符 `...` 
		* `function sumAll(...numbers: number[]): number { return numbers.reduce((acc, cur) => acc + cur, 0); }
	* 字面量联合限定：
		* `function sort(order: 'asc' | 'desc' ) { ... }`
		* 该参数只能传入 `asc` 或 `desc`
* 函数返回值限定：
	* 基础类型返回值：
		* `function getTotal(price: number, count: number): number { return price * countl }`
	* 空返回值：
		* `function logInfo(msg: string): void { console.log(msg); }`
	* 中断执行：
		* 该函数永远不会正常结束
		* `function throwError(msg: string): never { throw new Error(msg); }`
		* `function infiniteLoop(): never { while (true); }`
	* 返回复杂对象：
		* 使用 `interface`
	* 异步函数：
		* `async function fetch(): Promise<string> { ... }`
