# 03 为什么需要三级缓存而不是两级

为了解决 AOP 代理问题

假设只有两级缓存：
* 实例化 `Employee` 后，直接将原始对象放入二级缓存
* `Employer` 直接从二级缓存获取到原始对象并注入
* 如果 `Employee` 实例被 AOP 代理，则最终应将代理对象 `$ProxyEmployee$` 放入一级缓存，而 `Employer` 持有的实际是原始对象，导致不一致

最终后果：
* `Employer` 实例调用 `Employee` 的方法时，完全不会经过 AOP 代理的增强逻辑

三级缓存的解决方案：
* 三级缓存存储的 `ObjectFactory` 在调用 `getBean` 时可以决策是否进行代理
