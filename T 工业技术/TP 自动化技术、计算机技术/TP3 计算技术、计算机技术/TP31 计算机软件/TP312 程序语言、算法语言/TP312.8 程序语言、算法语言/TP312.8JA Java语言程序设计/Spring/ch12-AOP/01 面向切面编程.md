# 01 面向切面编程

AOP（Aspect Oriented Programming，面向切面编程）：
* 本质：
	* 对 OOP 的补充
* 底层：
	* 使用动态代理实现
* 作用：
	* 将和业务逻辑无关的代码（交叉业务）提取出来，形成若干组件（切面）
	* 实现代码的复用和对交叉业务的封装
	* 使开发者专注于业务逻辑的实现
	* 使代码更易于维护

概念：
* 连接点（Joinpoint）：
	* 程序执行过程中可以应用切面的位置
	* 包括：方法执行前、方法正常返回后、方法抛出异常后、方法结束时
* 切点（Pointcut）：
	* 本质：一个位置表达式
	* 用于匹配一批连接点
* 通知（Advice）：
	* 在切点处执行的具体交叉业务代码
	* 包括：前置通知、后置通知、环绕通知、异常通知、返回通知
* 切面（Aspect）：
	* 切点 + 通知
* 织入（Weaving）：
	* 将切面应用到目标对象的过程
* 代理对象（Proxy）：
	* 添加增强代码后的对象
	* 由 Spring 自动生成
* 目标对象（Target）：
	* 原始的需要增强的对象
