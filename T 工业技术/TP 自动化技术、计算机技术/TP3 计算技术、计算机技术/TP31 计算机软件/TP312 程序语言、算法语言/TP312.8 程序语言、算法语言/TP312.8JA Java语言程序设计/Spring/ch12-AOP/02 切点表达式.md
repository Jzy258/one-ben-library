# 02 切点表达式

* 切点表达式：
	* **作用**：
		* 定义通知切入的位置
	* **语法**：
		* `execution([访问控制权限修饰符] 返回值类型 [全限定类名]方法名(形式参数列表) [异常])`
		* 访问权限修饰符：
			* 省略则匹配所有
		* 返回值类型：
			* `*` 匹配任意返回值类型
		* 全限定类名：
			* **类路径**中，`..` 匹配当前包及其所有子包
			* 省略则匹配所有的类
		* 方法名：
			* `*` 匹配所有方法
			* `xxx*` 匹配所有以 `xxx` 开头的方法
		* 形式参数列表：
			* `()` 匹配无参数方法
			* `(..)` 匹配任意参数
			* `(*)` 匹配恰好一个参数的方法，类型任意
			* `(String)` 匹配恰好一个 `String` 类型参数的方法
			* `(String, *)` 匹配恰好两个参数，且第一个为 `String` 类型的方法，第二个参数类型任意
		* 异常：
			* 省略时匹配任意异常类型
