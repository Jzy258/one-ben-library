* Web 请求路径匹配：
	* 可以使用正则表达式
* 内容协商：
	* 服务器根据客户端的请求决定返回资源的最佳表现形式
	* 通过设置 `Accept` 响应头或 `format` 查询参数实现
	* 使用 `spring.mvc.contentnegotiation.parameter-name` 配置 `format` 优先
* 消息转换器：
	* `ByteArrayHttpMessageConverter`：
		* **作用**：
			* 实现字节数组和 HTTP 消息体之间的转换
		* **适用于**：
			* 处理二进制数据，如图片、文件
	* `StringHttpMessageConverter`：
		* **作用**：
			* 实现字符串与 HTTP 消息体之间的转换
	* `ResourceHttpMessageConverter`：
		* **作用**：
			* 实现 `Resource` 对象与 HTTP 消息体之间的转换
		* **适用于**：
			* 下载文件、发送静态资源
	* `ResourceRegionHttpMessageConverter`：
		* **作用**：
			* 处理资源的部分内容
		* **适用于**：
			* 处理大文件，如视频
	* `AllEncompassingFormHttpMessageConverter`：
		* **作用**：
			* 处理表单，包括 `application/x-www-urlencoded`、`multipart/form-data` 等
	* `MappingJackson2HttpMessageConverter`：
		* **作用**：
			* 使用 Jackson 库实现 json 数据的序列化和反序列化
