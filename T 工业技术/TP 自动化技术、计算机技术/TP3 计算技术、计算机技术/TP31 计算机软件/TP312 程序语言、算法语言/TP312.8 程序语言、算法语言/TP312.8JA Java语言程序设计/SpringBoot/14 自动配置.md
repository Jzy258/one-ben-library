# 14 自动配置

* `ConfigurableApplicationContext#getBeanDefinitionNames`：
	* 用于获取所有 Bean 的定义名称
* 条件注解：
	* 形如 `@ConditionalOnXxx`
	* **作用**：
		* 基于某些条件决定是否创建 Bean
* 自动配置类加载机制：
	* Spring Boot 启动后加载所有依赖的 jar 包，包括：
		* Spring Boot 的官方配置
		* 第三方启动器的配置
		* 项目自定义配置
	* 所有配置的清单位于各个 jar 包的 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfigure.imports`
	* 合并上述三部分清单得到候选配置类列表
	* 对于每一个配置类，测试是否满足相应的条件
		* 若满足条件，则将配置类加载到容器中
		* 若不满足，则跳过
	* 应用启动完毕，得到上下文
* Web 的核心配置类
> module `springboot-008`
* 自定义 mvc 配置：
	* 编写 `application.yml` 配置
	* 编写类实现 `WebMvcConfigurer` 接口，添加 `@Configuration` 注解
	* 使用 `@EnableWebMvc` 注解会舍弃所有默认配置，不建议使用
* 静态资源处理
	* Webjars：
		* 将 js 文件打包成 jar 包，通过 maven 引入的技术
	* 静态资源缓存
	* `favicon` 默认位置在网站根目录
