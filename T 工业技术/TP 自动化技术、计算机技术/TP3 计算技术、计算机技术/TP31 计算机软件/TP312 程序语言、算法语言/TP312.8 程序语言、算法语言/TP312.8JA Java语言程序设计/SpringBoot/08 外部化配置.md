> module `springboot-004`
* 外部化配置：
	* **定义**：
		* 将配置信息存储在源代码之外的地方
	* **作用**：
		* 可以独立、集中管理
		* 修改后不需要重新编译代码或重新部署项目
* Spring Boot 的外部化配置方式：
	* 命令行参数
	* 系统环境变量
	* `application.properties` 配置文件
	* `application.yml` 文件
	* ...
* `application.properties`：
	* 非必须，Spring Boot 提供了一套默认配置（详见 [[06 Spring Boot核心注解]]）
	* **加载位置**：优先级从高到低，高优先级覆盖低优先级，所有配置会合并
		* `file:./config/`
		* `file:./`
		* `classpath:/config/`
		* `classpath:/`
	* 若同时存在 `application.properties` 和 `application.yml`：
		* 同名属性 `application.properties` 的优先级更高
		* 不冲突的属性会同时生效
		* 不建议同时同一位置存在多个配置文件
* 使用 `--spring.config.location=路径` 命令行参数设置配置文件的位置
* `@Value`：
	* `@Value("${key}")`：
		* 获取配置文件中的配置信息
		* 配置不存在则报错
		* 可以读取操作系统的环境变量值
	* `@Value("${key}: default")`：
		* 可以指定默认值
> module `springboot-005`
* YAML（YAML Ain't Markup Language）：
	* 一种数据交换格式
	* 常见数据存储和交换格式：
		* Properties
		* XML
		* JSON
		* YAML
		* ...
	* 语法：
		* 数据类型：
			* 字符串
				* 使用 `''` 括起来的内容会被当成普通文本
				* 使用 `""` 括起来的内容会转义（`\n`、`\t` 等）
				* 不使用引号的效果与 `''` 一致
			* 数字、布尔值
			* 数组、LIst
				* 使用 `,` 分隔
				* 使用 `-` 创建列表
			* Map
		* 使用 `: ` 分隔属性名和属性值
		* 使用 `换行+空格` 表示层级关系
			* 不能使用制表符
		* 同级元素左对齐
		* 使用 `#` 注释
		* 大小写敏感
		* `|`：下文内容会保留原格式
		* `>`：下文内容中的换行会转换成 ` `
		* `---`：切割为独立的 YAML 文件
* 引入外部配置文件：`spring.config.import`
* 多环境切换：
	* 可以同时配置多个形如 `application-xxx.yml` 的配置文件
		* **例**：
			* `application-dev.yml`
			* `application-prod.yml`
			* `application-test.yml`
	* 指定启动的配置：
		* 在 `application.yml` 中配置 `spring.profiles.active` 
		* 通过命令行参数 `--spring.profiles.active`
* 绑定 Bean：
	* 绑定简单 Bean 对象：
		* `@Component` + `@ConfigurationProperties`
	* `@Configuration`：
		* 生成的项目是代理对象，保证单例
			* 可以通过 `proxyBeanMethods = false`
		* `kebab-case` 的配置属性会自动映射为 `camelCase` 的配置类属性
	* `@PropertySource` ：
		* 指定配置文件数据来源
* `@ImportResource`：
	* 导入外部 XML 配置
*  `Environment`：
	* **作用**：
		* 封装了应用程序的所有环境信息
	* **包括**:
		* Active Profiles：当前激活的配置文件列表
		* System Properties：系统属性
		* System Environment Variables：系统环境变量
		* Command Line Arguments：命令行参数
		* Property Sources：配置源列表
	* Spring 会自动注入
