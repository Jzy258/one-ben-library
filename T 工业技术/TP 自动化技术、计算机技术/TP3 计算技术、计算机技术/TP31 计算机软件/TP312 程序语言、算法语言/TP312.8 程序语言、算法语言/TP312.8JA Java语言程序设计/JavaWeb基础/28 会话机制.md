会话（session）：
* 用户打开浏览器访问一个 Web 站点到关闭浏览器之间的所有交互过程
* 一个会话对应多次请求

session 对应的类：
* `HttpSession`
* 全限定名称：`jakarta.servlet.http.HttpSession`

session 机制是 B/S 结构的一部分，不同语言对会话机制都有实现

session 的最主要作用：保存会话状态

HTTP 是一种无状态协议，请求时 B 与 S 连接，请求结束后连接断开

session 对象存储在服务器中

获取 `session` 对象：
```java
HttpSession session = request.getSession();
```
获取当前 session，若没有获取到任何 session，则新建
```java
HttpSession session = request.getSession(false);
```
获取当前 session，若没有获取到任何 session，则返回 `null`

session 的实现原理：
* Web 服务器中有一个 session 列表（类似于 Map），其中 key 存储 `sessionid`，value 存储 `session` 对象
* 用户第一次发送请求时，服务器创建新的 `session` 对象，同时为之生成一个 id，并发送给浏览器，浏览器将 id 保存在缓存中
* 用户之后再次发送请求，浏览器将 `sessionid` 以 cookie 的形式发送给服务器，服务器在 session 列表中查找
* 关闭浏览器后，浏览器的缓存清除，无法再找到对应的 `session` 对象，会话结束
* `session` 对象超时销毁：
	* 超过指定时间自动销毁
	* 在 `web.xml` 中配置 `<session-config>` 的 `<session-timeout>`
	* 默认超时时间是 30 分钟（`%CATALINA_HOME%/conf/web.xml` 中配置）
* `session` 对象手动销毁：
	```java
	session.invalidate();
	```

浏览器禁用 cookie：
* 服务器正常发送 cookie，浏览器拒收
* 每次请求服务器都会创建新的 session
* 可以使用 URL 重写技术强制绑定 `JSESSIONID`
```
URL;jsession=XXX
```

JSP 页面会自动获取 `session` 对象，可以通过
```jsp
<%@ page session="false"%>
```
禁止
