角色（哪些人参与）：
* Browser 的开发团队
* Web Server 的开发团队
* DB Server 的开发团队
* webapp 的开发团队（我们）

角色和角色之间需要遵守的规范和协议：
- webapp 和 Web Server 之间：JavaEE 规范之 Servlet 规范
	* 作用：Web Server 和 webapp 解耦合
* Browser 和 Web Server 之间：HTTP 协议
* webapp 和 DB Server 之间：JDBC 规范

Servlet 规范：
* 遵循此规范的 webapp 可以在不同的 Web 服务器中运行
* 包括：
    - 接口
    - 类
    - webapp 中配置文件的名字
    - webapp 中配置文件存放的路径
    - webapp 中配置文件的内容
    - webapp 的目录结构
    - ...
