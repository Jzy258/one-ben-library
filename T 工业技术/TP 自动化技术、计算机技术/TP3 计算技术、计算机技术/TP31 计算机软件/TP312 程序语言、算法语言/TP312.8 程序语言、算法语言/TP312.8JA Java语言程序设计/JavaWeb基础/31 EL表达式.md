EL 表达式（Expression Language，表达式语言）：
* 用于代替 JSP 中的某些 Java 语句，实现 CV 分离
* 是 JSP 语法的一部分
* 原理：从某个作用域中取数据，将其转换为字符串（必要时调用 `toString` 方法），并输出到浏览器
* 语法：`${表达式}`

作用域对象使用 `setAttribute` 向域中存放数据后，EL 表达式可通过对应的键获取该数据，如：
```jsp
<%
	request.setAttribute("obj", new Object())
%>

获取到的对象：${obj}
相当于：<%= request.getAttribute("obj") %>
```
* EL 表达式中不需要加 `""`，添加双引号表示普通字符串

EL 表达式可以直接通过 `.` 访问 JavaBean 对象的属性：
```java
public class User {
	private int id
	
	// ...
}
```
```jsp
<%
	User user = new User();
	request.setAttribute("user", user);
%>

获取用户 ID：${user.id}
相当于：<%= request.getAttribute("user").getId() %>
```
* EL 表达式根据 getter 函数（`getXxx` 或 `isXxx`）识别可获取属性，与类中实际的属性无关
或者使用 `[""]`：
```jsp
获取用户 ID：${user["id"]}
```

同名属性：
* 出现同名属性时，EL 表达式从小范围开始获取数据
* 可以使用 EL 隐含的范围对象 `pageScope`、`requestScope`、`sessionScope`、`applicationScope` 区分同名属性
```jsp
<%
	pageContext.setAttribute("data", "pageContext");
	request.setAttribute("data", "request");
	session.setAttribute("data", "session");
	application.setAttribute("data", "application");
%>

获取到的数据来自于：${data}
来自于 pageContext 的数据：${pageScope.data}
来自于 request 的数据：${requestScope.data}
来自于 session 的数据：${sessionScope.data}
来自于 application 的数据：${applicationScope.data}
```

JSP 内嵌 Java 代码自带空处理，试图获取不存在的属性将在页面上输出 `null`
EL 表达式试图获取不存在的属性将不输出（输出为空）

EL 表达式可以通过 `[""]` 访问 `Map` 的项：
```jsp
<%
	Map<String, String> map = new HashMap<>;
	map.put("username", "Schrant_001");
	pageContext.setAttribute("map", map);
%>

获取到的数据：${map["username"]}
```

EL 表达式可以通过 `[下标]` 访问数组或 `List`：
```jsp
<%
	int[] arr = {1, 2, 3};
	List<Integer> list = new ArrayList<>;
	list.add(4);
	pageContext.setAttribute("arr", arr);
	pageContext.setAttribute("list", list);
%>

从 arr 获取到的数据：${arr[0]}
从 list 获取到的数据：${list[0]}
```
* 下标越界会导致输出为空

EL 表达式内置对象：
* `pageScope`、`requestScope`、`sessionScope`、`applicationScope`
* `pageContext`：
	* EL 表达式直接访问外部的唯一 API
	* 通过 `.request`、`.session`、`.application` 访问相应对象（其实调用了 `pageContext` 的 `getRequest`、`getSession`、`getApplication` 方法）
* `param`：
	* 可以通过 `.` 访问请求的参数
	* 相当于 `request.getParameter("参数名")`
	* 若有多个同名参数，则只获取第一个参数
* `paramValues`：
	* 通过参数名返回对应参数列表（字符串数组形式）
	* 相当于 `request.getParameterValues("参数名")`
* `initParam`：
	* 获取在 `web.xml` 中配置的初始化参数
	* 相当于 `application.getInitParameter("参数名")`

EL 表达式的运算符：
* 算术运算符：
	* `+`、`-`、`*`、`/`、`%`
	* `+` 没有字符串拼接的功能，只能算术求和，两边不是数字时会自动转换，转换失败则抛出 `NumberFormatException`
* 关系运算符：
	* `==`、`!=`、`>`、`>=`、`<`、`<=`、`eq`
	* `==`、`!=` 和 `eq` 调用了 `equals` 方法
* 逻辑运算符：
	* `!`、`&&`、`||`、`not`、`and`、`or`
* 条件运算符：
	* `? :`
* 取值运算符：
	* `[]`、`.`
* `empty`
	* 判断是否为空
