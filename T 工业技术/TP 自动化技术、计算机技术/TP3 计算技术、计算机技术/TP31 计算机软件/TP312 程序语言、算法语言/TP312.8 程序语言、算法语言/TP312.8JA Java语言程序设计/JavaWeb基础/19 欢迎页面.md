设置欢迎页面：
* 在 `web.xml` 的 `<web-app>` 中添加：
	```xml
	<welcome-file-list>  
	    <welcome-file>欢迎页面的文件路径</welcome-file>  
	</welcome-file-list>
	```
	* 路径不需要从 `/` 开始
	* 默认从 webapp 的根下开始查找
* 可以设置多个欢迎页面：
	```xml
	<welcome-file-list>  
	    <welcome-file>文件路径1</welcome-file>  
	    <welcome-file>文件路径2</welcome-file>
	    ...
	</welcome-file-list>
	```
	* 越靠前优先级越高
* 如果未配置欢迎页面路径，则默认为 `根目录/index.html`（如果存在）
	* 全局设置：在 `%CATALINA_HOME%/conf/web.xml` 中配置 `<welcome-file-list>`
	* Tomcat 在其中预先配置了 `index.html`、`index.htm` 和 `index.jsp`
	* 局部优先原则（就近原则）
