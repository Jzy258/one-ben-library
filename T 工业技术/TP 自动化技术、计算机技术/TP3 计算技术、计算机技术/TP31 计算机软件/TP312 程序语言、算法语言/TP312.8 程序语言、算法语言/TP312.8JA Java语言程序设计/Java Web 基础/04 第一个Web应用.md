# 04 第一个Web应用

步骤：
* 在 `%CATALINA_HOME%\webapps` 目录下新建一个子目录
	* 目录名就是 webapp 的名字
* 在此目录下新建资源文件，例如：`index.html`
	* 编写 `index.html` 文件的内容。
* 启动 Tomcat 服务器
* 打开浏览器，在浏览器地址栏上输入 URL
* 以 `/项目名/` 开始是一个绝对路径
  ```html
  <a href="/%myapp%/login.html"></a>
  ```

动态网页技术：
* 连接数据库，数据库中有多少条记录，页面上就显示多少条记录（页面中的数据是动态的，根据数据库中数据的变化而变化）
