# 23 资源跳转

两种方式：
* 转发
	* 一次请求，资源跳转后请求不变
	* 地址栏上的 URL 不变
* 重定向
	* 发送新的请求
	* 地址栏的 URL 改变

Javabean 类：
* 有无参构造方法
* 属性私有化
* 有 `setter` 和 `getter` 方法
* 重写 `toString` 方法
* 重写 `hashCode` 和 `equals` 方法
* 实现 `java.io.Serializeble` 接口

重定向：
```java
resp.sendRedirect(路径（包括项目名）);
```
`resp` 将路径响应给浏览器，浏览器自发地向服务器发送一次新的请求

如果在上一个 Servlet 中向 request 域中绑定了数据，希望从下一个 Servlet 中获取该数据，则使用转发
其余情况使用重定向

跳转的资源不一定是 Servlet，只要是服务器内合法资源即可

使用转发可能导致刷新后同一请求的反复执行
