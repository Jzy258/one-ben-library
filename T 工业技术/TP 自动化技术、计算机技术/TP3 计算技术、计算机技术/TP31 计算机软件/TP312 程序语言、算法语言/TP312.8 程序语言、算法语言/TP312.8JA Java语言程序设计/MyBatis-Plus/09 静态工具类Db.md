* `Db`：
	* **作用**：
		* 通过静态方法直接进行数据库操作，无需注入 `Service` 或 `Mapper`
		* 避免 `Service` 产生循环依赖
	* **特点**：
		* 均为静态方法，可直接调用
		* 不依赖 Spring 环境，解决循环依赖问题
		* 需要额外传入 `Class` 类型参数以定位 Mapper
	* **核心方法**：与 `IService` 高度相似
		* 增：
			* `insert`
			* `saveBatch`
		* 删：
			* `removeById`
			* `remove`
		* 改：
			* `updateById`
			* `update`
		* 查：
			* `getById`
			* `list`
			* `listById`
		* 链式调用：
			* `lambdaQuery`
			* `lambdaUpdate`
		* 原生 SQL 方法【不推荐】：
			* `queryList`：
				* 通过传入 SQL 语句查询
			* `update`：
				* 通过传入 SQL 语句更新数据
	* **使用场景**：
		* 出现循环依赖问题
		* 在非 Spring 组件中使用
		* 辅助性的数据处理
