* 枚举：
	* **作用**：
		* 使用有业务含义的枚举类型替代魔法值
	* **特点**：
		* 自身包含语义，使代码更直观，可读性更强
		* 将枚举值的检查提前到编译期
		* 便于集中管理
	* 常用注解：
		* `@EnumValue`：
			* 指定 MyBatis-Plus 存储的值
		* `@JacksonValue`：
			* 指定 Jackson 序列化为 JSON 时返回的值
	* Controller 会自动将前端参数转换为枚举
	* Jackson 能自动将 JSON 反序列化为枚举（通过 `name`）
		* 自定义反序列化规则：
			* `@JsonCreator`：
				* **使用方式**：
					* 传入 `String` 类型参数
					* 编写反序列化逻辑
					* 返回枚举类型
				* Jackson 在反序列化时会自动调用
			* 配置 `spring.jackson.deserialization.accept-empty-string-as-null-object=true`：
				* **作用**：
					* 当 JSON 中字符串字段值为 `""` 时，将其反序列化为 `null`
				* 用于避免报错，正确处理空字符串值
* 枚举处理器（Enum Processor）：
	* **作用**：
		* 解决 Java 枚举与数据库字段之间的自动映射问题
	* **处理策略**：
		* `MybatisEnumTypeHandler`【推荐】：
			* 指定枚举中的任意一个字段作为数据库存储的值
			* **优点**：
				* 能完全控制数据库的存储值，不受枚举名称或顺序变更的影响
		* `EnumTypeHandler`【默认】：
			* 将枚举的 `name` 属性作为字符串存入数据库
			* **缺点**：
				* 数据库数据依赖于枚举常量的名称
		* `EnumOrdinalTypeHandler`：
			* 将枚举常量的声明顺序作为整型存入数据库
			* **缺点**：
				* 数据依赖于枚举顺序，插入新常量会打乱顺序映射
	* **实现步骤**（以 `MybatisEnumTypeHandler` 为例）：
		* 使用 `@EnumValue` 标记存储值字段
			* 或使枚举实现 `IEnum` 接口，并重写 `getValue` 方法
		* 直接在 Entity 中将字段类型声明为枚举
		* 配置枚举处理器（通常不需要）：
			* `mybatis-plus.configuration.default-enum-type-handler=com.baomidou.mybatisplus.core.handlers.MybatisEnumTypeHandler`
	* **注意事项**：
		* 避免使用 `@TableField(typehandler)`：
			* 在一个 `TypeHandlerRegistry` 中，`EnumTypeHandler` 实例会被多个枚举类型共用，可能导致类型转换错误
		* 使用 `@TableName(autoResultMap = true)` 可以确保 MyBatis 正确处理复杂的映射场景
