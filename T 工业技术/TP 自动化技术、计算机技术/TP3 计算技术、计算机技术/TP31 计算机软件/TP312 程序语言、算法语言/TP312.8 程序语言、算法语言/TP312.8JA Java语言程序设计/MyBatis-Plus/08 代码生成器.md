* 代码生成器（Code Generator）：
	* **作用**：
		* 根据数据库表结构自动生成 Entity、Mapper（接口及 XML）、Service（及实现类）、Controller 等各层代码的工具
		* 使开发者专注于核心业务逻辑
	* 基于建造者模式
	* **使用步骤**：
		* 引入依赖 `com.baomidou.mybatis-plus-generator` + 模板引擎
			* MyBatis-Plus 官方支持的模板引擎：
				* `Velocity`、`Freemarker`、`Beetl` 等
		* 编写生成器类并通过 `FastAutoGenerator` 配置
		* 运行并生成代码
	* **核心配置项**：
		* 全局配置：`gobalConfig`
			* `author`：
				* 指定代码作者
			* `outputDir`：
				* 指定代码生成的输出目录
			* `enableSwagger`：
				* 是否开启 Swagger 2 的注解支持
			* `dateType`：
				* 指定时间日期字段的类型
				* `DateType.ONLY_DATE`：
					* 使用 `java.util.Date`
				* `DateType.SQL_PACK`：
					* 使用 `java.sql.Date`
				* `DateType.TIME_PACK`：
					* 使用 `java.time` 包下的新的时间类型
			* `enableKotlin`：
				* 是否开启 Kotlin 模式
		* 数据源配置：`dateSourceConfig`
			* `url`：
				* 指定 JDBC 连接的 URL
			* `username`：
				* 指定数据库用户名
			* `password`：
				* 指定数据库密码
		* 包配置：`packageConfig`
			* `parent`：
				* 父包名
			* `moduleName`：
				* 模块名
			* `entity`：
				* Entity 包名
			* `service`：
				* Service 包名
			* `serviceImpl`：
				* Service 实现包名
			* `mapper`：
				* Mapper 包名
			* `xml`：
				* Mapper XML 包名
			* `controller`：
				* Controller 包名
		* 策略配置：`strategyConfig`
			* `addInclude`：
				* 指定需要生成代码的表名
			* `addTablePrefix`：
				* 指定表前缀
			* `entityBuilder`：
				* 配置 Entity 策略
				* `enableLombok`：
					* 开启 Lombok
				* `logicDeleteColumeName`：
					* 指定逻辑删除字段名
			* `controllerBuilder`：
				* 配置 Controller 策略
				* `enableRestStyle`：
					* 是否生成 `@RestController`
			* `serviceBuilder`：
				* 配置 Service 策略：
				* `formatServiceFileName`：
					* 指定 Service 接口命名格式
			* `mapperBuilder`：
				* `enableMapperAnnotation`：
					* 是否生成 `@Mapper` 注解
				* `enableBaseResultMap`：
					* 是否生成 `BaseResultMap`
	* 生成方式：
		* 快速生成：
			* 如上述所示，在 `main` 方法中配置好所有参数后一次性运行
		* 交互式生成：
			* 运行生成器后在控制台内交互生成
	* 数据库查询方式：
		* `DefaultQuery`：
			* 通过 JDBC 的 `DatabaseMetaData` 接口获取信息
			* **优点**：
				* 通用性好
			* **缺点**：
				* 可能存在部分类型处理不佳的问题
		* `SQLQuery`：
			* 通过执行 SQL 语句查询表和字段信息
			* **优点**：
				* 更可控
			* **缺点**：
				* 通用性差
	* 定制模板引擎：
		* 可以通过继承 `AbstractTemplateEngine` 自定义模板引擎
