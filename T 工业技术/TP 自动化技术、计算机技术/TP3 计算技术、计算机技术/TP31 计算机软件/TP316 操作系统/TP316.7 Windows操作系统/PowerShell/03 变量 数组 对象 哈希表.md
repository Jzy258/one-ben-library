* 变量：
	* **语法**：
		* 以 `$` 开头
		* 使用 `=` 赋值
		* 使用 `.` 访问属性和调用方法
		* 变量名大小写不敏感
	* 常用自动变量：
		* `$PID`：
			* 当前进程 ID
		* `$_`：
			* 管道中的当前对象
		* `$PSVersionTable`：
			* PowerShell 版本列表
		* `$HOME`：
			* 用户家目录
		* `$null`：
			* 空值
* 数组：
	* 使用 `,` 分隔的一系列元素
	* `[]` 按索引访问元素
	* `Count`：
		* 数组长度
	* `+=`：
		* 在数组后追加元素
		* PS 的数组定长，实际上新建了数组
	* `@()`：
		* 空数组
* 对象与管道筛选：
	* `Where-Object { 条件 }`：
		* 按条件筛选
	* `Select-Object`：
		* 选择列
	* `Sort-Object`：
		* 排序
	* `Format-Table` / `Format-List`：
		* 按格式展示
* 哈希表：
	* **格式**：
		* `@{ 键 = 值; 键 = 值 }`
	* `.` 或 `[]` 按键取值
