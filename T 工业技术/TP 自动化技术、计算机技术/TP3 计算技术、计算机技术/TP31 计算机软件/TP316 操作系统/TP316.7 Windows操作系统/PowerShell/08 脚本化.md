* PowerShell 脚本：
	* `.ps1` 文件
* `Get-ExecutionPolicy`：
	* 查询当前执行策略
* `Set-ExecutionPolicy`：
	* 设置执行策略
	* `-Scope`：
		* 生效范围
	* **可选值**：
		* `Restricted`【默认】：
			* 禁止运行脚本
		* `RemoteSigned`：
			* 本地脚本可运行，下载的脚本需要签名
		* `Unrestricted` / `Bypass`：
			* 放行
* 临时放行：
	* `powershell -ExecutionPolicy Bypass -File 脚本路径`
* 脚本骨架：
	```powershell
	param (
		[string]$Name = "world"
		[int]$Count = 3
	)
	...	
	```
* `&`：
	* 调用操作符
	* 带路径 / 变量时必需
* 注释：
	* `#`：
		* 单行注释
	* `<# ... #>`：
		* 块注释
* 多行字符串：
	* `@'...'@`（不支持插值）
	* `@"..."@`（支持插值）
