* 文件操作相关 cmdlet：
	* `Get-Content`：
		* 读文件
		* `-Raw`：
			* 一次读完
		* `-Tail n`：
			* 查看末尾 `n` 行
	* `Set-Content` / `Add-Content`：
		* 写 / 追加
		* `-Encoding`：
			* 指定编码
			* 使用 UTF8 的文件带 BOM
	* `Test-Path`：
		* 判断路径是否存在
	* `Get-Item`：
		* 获取单个文件信息
		* `Length`：
			* 文件大小
		* `FullName`：
			* 全名
		* `LastWriteTime`：
			* 最后修改时间
	* `Copy-Item` / `Move-Item` / `Remove-Item`：
		* 复制 / 移动 / 删除
	* `Select-String`：
		* 文本搜索
		* `-Pattern`：
			* 使用正则表达式匹配
