# 07 作业&补充

* `hostnamectl`：
	* **作用**：
		* 管理系统主机名
		* 重启后仍然生效
* `hostname`：
	* **作用**：
		* 临时查看和修改主机名
		* 重启后失效
* `timedatectl`：
	* **作用**：
		* 管理系统时间和时区
	* `set-timezone`：
		* 设置时区
	* `status`：
		* 查看当前配置
	* Rocky Linux 默认开启 NTP 自动同步，通常不需要手动校准时间
* `groupadd`：
	* 创建附加用户组
	* `-g`：
		* 指定 GID
* `find [START_POINT] [EXPRESSION] [ACTION]`：
	* `[START_POINT]`：
		* 开始搜索的基准点
	* `[EXPRESSION]`：
		* 搜索条件
		* `-name`：
			* 指定文件名
			* 支持通配符
		* `-type`：
			* 指定文件
			* `f`：
				* 普通文件
		* `-exec`：
			* 对符合条件的对象的操作
			* `{}` 作为占位符，表示该对象
			* `\;` 用于退出指令
* `wc`：
	* 计数
	* `-l`：
		* 统计行数
* `Ctrl + S`：
	* 冻结屏幕输出
* `restorecon`：
	* **作用**：
		* 恢复 SELinux 文件安全上下文
	* `-R`：
		* 递归执行到目录下所有文件和子目录
	* `-v`：
		* 显示详细信息
* `setsebool`：
	* **作用**：
		* 设置 SELinux 布尔值
	* `-P`：
		* 永久生效
* `httpd_t` 标签：
	* SELinux 为 Web 服务器进程分配的进程类型标签
	* `httpd_sys_content_t`：
		* 静态网页内容
		* Web 服务器只读
* `httpd_can_network_connect` 开关：
	* 指定以 `httpd_t` 身份运行的 Web 服务器是否能主动发起对外部的网络连接
