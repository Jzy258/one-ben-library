# 01 服务器与Linux操作系统

* 服务器与个人电脑的主要区别：
	* 更多的 CPU 数量和核心数量
	* 更多的内存
	* 更多的磁盘数量
	* 更多的接口和扩展
	* 支持带外管理（Out-of-Band）：
		* **定义**：
			* 通过独立、专用的通道监控和维护 IT 设备
		* **核心思想**：
			* 管理流量与业务流量的逻辑隔离
		* 带（Band）：
			* 数据传输的通道或网络
		* **特点**：
			* 不依赖被管理设备自身的操作系统和主网络
			* 支持远程操作
		* **实现**：
			* BMC（基板管理控制器）芯片
				* 有独立的网络接口和电源，独立于主机工作
			* IPMI（智能平台管理接口）协议
				* 定义了 BMC 与管理系统如何通信
	* ...
* 开源：
	* 通过公开源代码，实现任何人可以直接修改源代码并将优化后的源代码继续共享
* 自由软件：
	* 任何目的运行程序的自由
	* 学习程序如何工作、按需修改的自由
	* 重新分发副本的自由
	* 将修改之后的版本分发的自由
* Linux：
	* 基于 Minix 开发的开源操作系统内核
	* 通常结合 GNU 形成完整操作系统
	* Linux 发行版：
		* 由个人、社区、企业基于 Linux 内核源码、GNU 套件及若干开源、闭源软件组装而成的可用的 Linux 操作系统
* 主流软件包管理器：
	* RPM：
		* 基于 `rpm` 格式软件包
		* 适用操作系统：RHEL、Rocky Linux 等
	* DEB：
		* 基于 `deb` 格式软件包
		* 适用操作系统：Debian、Ubuntu 等
* 虚拟机（第二类）：
	* **本质**：
		* 将物理计算机的资源（CPU、内存、硬盘等）拆分出一部分，组建成一台虚拟计算机，实现在一台设备上运行多个操作系统
	* 常用虚拟机：
		* VMware
* VMware：
	* 虚拟交换机：
		* VMnet1：
			* 带有 DHCP 服务的局域网，包括宿主机和虚拟机的子网，宿主机的网络号为 `192.168.x.1`
		* VMnet8：
			* 带有 DHCP 服务和 NAT 网关的局域网，包括宿主机和虚拟机的子网，宿主机的网络号为 `192.168.x.1`，网关的网络号为 `192.168.x.2`
		* VMnet0：
			* 通过复用物理网卡直接将虚拟机暴露在外部网络中
	* 确保以下三个服务正常启动：
		* `VMware Authorization`：
			* 用于身份认证
		* `VMware DHCP`：
			* 用于分配 IP 地址
		* `VMware NAT`：
			* 用于网络转换
* 通过 SSH 访问虚拟机：
	* `ssh root@虚拟机地址`
* `poweroff`：
	* 关闭电源
* TTY（Teletype，电传打字机）：
	* **起源**：
		* 计算机早期使用的终端是独立于计算机的带键盘的打印机
		* 用户在键盘上输入指令，机器将其转换为电信号发送给计算机
		* 计算机处理完毕后，将结果以电信号形式返回，机器将结果打印在纸上
	* **演化**：
		* TTY 泛指任何类型的**终端**
		* 在 Linux 系统中，TTY 指代内核中的一个关键子系统，用于通过 TTY 驱动程序管理进程、行编辑和会话
