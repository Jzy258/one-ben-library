* 镜像管理：
	* `docker images`：
		* 列出所有镜像
		* 运行任何容器时会先检查本地是否存在镜像
			* 若不存在则自动下载
	* 镜像的 OCI 标准命名规范：
		* 仓库地址：
			* 镜像的来源位置
			* 默认值为 `docker.io`
			* 默认值隐藏
		* 命名空间：
			* 镜像在仓库上分配的用户名或组织名
			* 默认值为 `library`
			* 默认值隐藏
		* 镜像名称：
			* 镜像的实际名称
			* 必须显示其必须指定
		* TAG 标签：
			* 人为标记的信息
			* 默认值隐藏
	* 镜像名的完整写法【推荐】：
		* `仓库地址/命名空间/镜像名称:TAG标签`
	* `docker pull`：
		* 获取镜像
	* FS Layer（文件系统层）：
		* 构成镜像的基本单元
		* 每个层都记录了构建过程中的一次文件系统变更
	* `docker inspect <IMAGE>`：
		* 查看镜像信息
		* **常见属性**：
			* `"RepoDigest"`：
				* 镜像的另一种获取方式，通过sha256的摘要定位镜像
			* `"Created"`：
				* 镜像构建时间
			* `"Config"`：
				* 包含镜像的重要配置和参数
			* `"Cmd"`：
				* 镜像在作为容器运行时的默认运行程序
			* `"Architecture"`：
				* 系统架构
			* `"Os"`：
				* 镜像的运行平台
			* `"RootFS"`：
				* 根文件系统信息
	* `docker rmi <IMAGE>`：
		* 移除镜像
		* 被移除的镜像不能正在使用
	* `docker tag <IMAGE> <NAME>`：
		* 对现有镜像重新命名
		* 镜像通过 ID 唯一标识，可以存在同名镜像，同 ID 镜像可以有多个名称
	* `docker save`：
		* 导出镜像
		* `-o`：
			* 指定输出的文件路径
	* `docker load`：
		* 加载镜像
		* `-i`：
			* 指定加载的文件路径
* 容器管理：
	* `docker run`：
		* **作用**：
			* 下载镜像、创建容器、运行容器
		* **常用参数**：
			* `-i`：
				* 使用交互式界面
			* `-t`：
				* 分配一个终端
			* `-d`：
				* 将容器作为服务运行在后台
			* `--name`：
				* 指定容器的名称
			* `-p`：
				* 通过 DNAT 规则实现端口转发，将主机端口与容器内环境端口建立映射
			* `-v 本机目录:容器目录`：
				* 将宿主机的目录挂载到容器内
			* `-e`：
				* 指定环境变量
	* `docker ps`：
		* 列出所有容器
	* `docker start`：
		* 恢复容器的启动
	* `docker stop`：
		* 停止容器的运行
	* `docker restart`：
		* 重启容器
	* `docker rm`：
		* 删除容器
	* `docker exec`：
		* 运行容器内的程序
		* **常用参数**：
			* `-i`：
				* 使用交互式界面
			* `-t`：
				* 分配一个终端
			* `-V`：
* 构建容器镜像：
	* `docker build`：
		* 构建镜像
		* `-t`：
			* 指定镜像名称
	* `docker push`：
		* 推送镜像，实现发布
	* `docker login`：
		* 登录
	* `docker tag`：
		* 修改镜像标签
