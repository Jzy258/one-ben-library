Windows 错误代码通常是十六进制数字

通用解决方法：
* 重启电脑：
	* 临时性错误往往重启后消失
* 运行系统文件检查（SFC）
	```bash
	sfc /scannow
	```
	* 修复系统文件损坏
* 运行 DISM 工具
	```bash
	DISM /Online /Cleanup-Image /RestoreHealth
	```
	* 修复系统映像
* 检查磁盘错误（CHKDSK）
	```bash
	chkdsk 盘符: /f /r
	```
	* 修复硬盘坏道或文件系统逻辑错误
* 更新或重装驱动程序
	* 驱动不兼容也会导致随机错误
* 使用 Windows 疑难解答
	* 设置 → 更新和安全 → 疑难解答，选择对应类别

`0x80070570`：文件或目录损坏且无法读取
* 常见原因：
	* 文件系统损坏：
		* 如：U 盘 / 移动硬盘突然断电
	* 物理坏道 / 坏块
	* 病毒或恶意软件
	* 硬件连接问题：
		* 数据线接触不良、USB 接口供电不足或内存条故障
	* 安装介质问题
		* （安装或重装系统时）
		* 系统安装光盘 / U 盘本身有损坏或 ISO 镜像文件不完整
* 解决方法
	* 运行 `CHKDSK` 命令检查和修复磁盘
		* 自动检测并修复文件系统错误和坏扇区
		* 操作步骤：
			* 以管理员身份运行 PowerShell
			* 执行命令 `chkdsk 盘符: /f /r /x`
        * `/f`：修复磁盘上的错误
        * `/r`：扫描坏扇区并尝试恢复其中的可读信息
        * `/x`：（如果有必要）强制卸载该磁盘
	* 使用查杀病毒运行全盘扫描
	* 硬件排查：
	    * 更换连接：尝试换一个 USB 接口或数据线，排除接触不良
	    * 运行内存诊断：运行 Windows 内存诊断，检查内存条是否存在故障
	* 格式化
