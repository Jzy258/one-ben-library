`Win + X`：
* 弹出 Windows 高级用户菜单（Power User Menu）
* 等同于在开始按钮上右键
* 常用选项（括号内表示弹出菜单后可以使用的快捷键）：
	* 磁盘管理（`K`）：打开 `diskmgmt.msc`，用于管理文件卷、磁盘、分区
	* 终端管理员（`A`）
	* 任务管理器（`T`）
	* 设备管理器（`M`）
	* 事件查看器（`V`）
		* 查看系统、应用程序、安全等日志
		* 用于排查错误、崩溃、安全事件
	* “运行”对话框（`R`）
	* 电源选项（`O`）
		* 调整睡眠时间、电源模式、电源计划
	* 系统信息（`Y`）
	* 文件资源管理器（`E`）
	* 设置（`N`）
	* 应用和功能（`F`）
		* 查看、修改、卸载电脑上安装的程序和可选功能
	* 关机 / 重启（`U`）
	* 移动中心（`B`）
		* 快速调节亮度、音量、电源计划、同步设置、外接显示器
