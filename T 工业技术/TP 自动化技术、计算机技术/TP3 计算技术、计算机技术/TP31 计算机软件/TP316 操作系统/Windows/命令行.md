DOS（磁盘操作系统，Disk Operating System）：
* 早期的操作系统
	* 单任务、实模式、16 位
	* 流行于 1980s ~ 1990s
* 纯命令行，无图形界面

命令提示符（CMD，Command Prompt）：
* 程序名：`cmd.exe`
* 本质：Windows NT 以来的命令行解释器（壳）
	* 用于执行命令和批处理脚本
* 特点：
	* 语法继承 DOS
	* 可以调用 Windows API
	* 功能有限，不支持复杂对象操作
* 只是模拟 DOS 环境，与 DOS 底层完全不同

PowerShell：
* 程序名：`pwsh.exe`
* 本质：面向对象的命令行壳和脚本语言
	* 基于 .NET
* 特点：
	* 输出对象而非文本，便于管道处理
	* 可以管理系统、注册表、证书、WMI 等
	* 语法与 CMD 不同

WSL（Windows Subsystem for Linux）：
* 本质：在 Windows 上运行 Linux 二进制文件的兼容层
* 版本：
	* WSL 1：将 Linux 系统调用翻译为 Windows API 并执行
	* WSL 2：在轻量级虚拟机上直接运行真实的 Linux 内核

终端（Terminal）：
* 本质：图形化应用程序
	* 用于显示字符界面并与壳交互
	* 本身不执行命令
