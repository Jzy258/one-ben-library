WMI（Windows Management Instrumentation，Windows 管理规范）：
* Windows 系统的核心管理技术
* 提供接口以使用脚本或程序查询、监控、修改本地或远程计算机上的硬件、操作系统、应用程序和服务的状态，如：
	* 查询信息：
		* 获取 CPU 序列号、内存大小、硬盘分区、已安装软件列表、当前运行进程、网络配置等
	* 执行操作：
		* 远程重启计算机、创建或结束进程、启用或停止 Windows 服务等
	* 订阅事件：
		* 设置监听特定事件，自动执行预设的操作，如执行脚本或发送邮件
* 在 PowerShell 中使用 `Get-CinInstance` 命令
* 使用命名空间和类组织信息
