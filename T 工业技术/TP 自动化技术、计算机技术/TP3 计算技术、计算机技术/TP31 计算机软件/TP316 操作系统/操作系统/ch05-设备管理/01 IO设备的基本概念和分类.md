# 01 IO设备的基本概念和分类

I/O 设备：
* 可以将数据输入到计算机或接受计算机输出数据的外部设备
* 属于计算机的硬件部件
* UNIX 将外部设备抽象为特殊的文件，用户可以使用与文件操作相同的方式操作外部设备

按使用特性分类：
* 人机交互类外部设备（数据传输速度慢）
* 存储设备（数据传输速度快）
* 网络通信设备

按传输速率分类：
* 低速设备
* 中速设备
* 高速设备

按信息交换的单位分类：
* 块设备：
	* 传输速率较高
	* 可寻址
* 字符设备：
	* 传输速率较慢
	* 不可寻址
	* I/O 时常采用中断驱动方式
