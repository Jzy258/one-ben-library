# 02 IO控制器

I/O 设备：
* 机械部件主要用来执行具体 I/O 操作
* 电子部件通常是一块插入主板扩充槽的 PCB，即 I/O 控制器

I/O 控制器：
* 功能：
    * 接受和识别 CPU 发出的命令：通过控制寄存器存放命令和参数
    * 向 CPU 报告设备的状态：通过状态寄存器记录当前设备状态
    * 数据交换：
	    * 输出：通过数据寄存器暂存 CPU 发来的数据，再由控制器传送给设备
	    * 输入：用于暂存设备发来的数据，之后 CPU 从中取出数据
    * 地址识别：为设备控制器中的各个寄存器设置地址
* 组成：
	* I/O 逻辑：
		* 接收和识别 CPU 的命令，并对设备发出命令
		* 通过地址线和控制线与 CPU 相连
	* 控制器与设备的接口（可能多个）：
		* 实现控制器与设备之间的通信
		* 一个 I/O 控制器可能对应多个设备
	* CPU 与控制器的接口（通过数据总线相连）
		* 实现 CPU 与控制器之间的通信
		* 包括：
			* 数据寄存器
			* 控制寄存器
			* 状态寄存器
		* 内存映像 I/O：一些计算机将寄存器占用内存地址的一部分
			* 优点：简化指令，可以采用一般的内存操作对控制器进行操作
		* 寄存器独立编址：一些计算机采用 I/O 专用地址
			* 缺点：需要设置专门的指令实现对控制器的操作，需要指明寄存器的地址和控制器的编号
