# 09 缓冲区管理

缓冲区：
* 可以由专门的硬件寄存器组成，也可以利用内存
* 使用硬件作为缓冲区成本较高，容量较小，适用于速度要求高的场合（如存储器管理中所用的联想寄存器）
* 一般利用内存作为缓冲区

作用：
* 缓和 CPU 和 I/O 设备之间速度不匹配的矛盾
* 减少对 CPU 的中断频率，放宽对 CPU 中断相应时间的限制
* 解决数据粒度不匹配的问题
* 提高 CPU 与 I/O 设备之间的并行性

单缓冲：
* 在主存中分配一个缓冲区（大小为一个块）
* 缓冲区数据非空时，不能向缓冲区输入数据，只能从缓冲区输出数据
* 缓冲区为空时，可以往缓冲区输入数据，缓冲区满后再从缓冲区输出数据
* 用户进程的内存空间中，会分出一块工作区用于接收输入 / 输出的数据（大小一般与缓冲区相同）
* 计算处理一块数据所需时间：
	* 一般认为初始状态为工作区满，缓冲区空
	* 若 T > C，则平均用时为 T + M
	* 若 T < C，则平均用时为 C + M

双缓冲：
* 在主存中分配两个缓冲区
* 一般认为初始状态为工作区空，一缓冲区满，一缓冲区空
* 若 T > C + M，则平均用时为 T
* 若 T < C + M，则平均用时为 C + M

单双缓冲在通信时的区别：
* 若设置单缓冲，在任一时刻只能实现数据的单向传输
* 若设置双缓冲，同一时刻可以实现双向数据传输

循环缓冲区：
* 将多个大小相等的缓冲区链接成一个循环队列
* `in` 指针指向下一个空缓冲区
* `out` 指针指向下一个满缓冲区

缓冲池：
* 由系统中共用的缓冲区组成，按使用状况可以分为：空缓冲队列、满输入缓冲队列、满输出缓冲队列
* 根据缓冲区在实际运算中的功能不同，设置四种工作缓冲区：
	* 收容输入数据：hin
	* 提取输入数据：sin
	* 收容输出数据：hout
	* 提取输出数据：sout
