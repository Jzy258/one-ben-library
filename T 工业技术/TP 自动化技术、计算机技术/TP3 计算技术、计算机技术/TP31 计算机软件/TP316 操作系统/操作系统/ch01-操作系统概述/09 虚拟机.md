虚拟机：使用虚拟化技术，将一台物理机器虚拟化为多台虚拟机器（VM），每个虚拟机都可以运行一个操作系统

虚拟机管理系统 = 虚拟机监控程序 = Virtual Machine Monitor = Hypervisor

第一类 VMM：直接运行在硬件上
* 硬件 -> 第一类 VMM（内核空间）-> VM（虚拟机器）-> 虚拟内核空间 -> 虚拟用户空间 -> 运行在各操作系统上的进程

第二类 VMM：运行在宿主操作系统上
* 硬件 -> 宿主操作系统（Host OS内核空间）-> 第二类 VMM、宿主操作系统的进程（Host OS 用户空间）-> 客户操作系统 -> 客户操作系统的进程

两类虚拟机管理程序（VMM）的对比：
* 第一类 VMM：
	* 直接运行在硬件上，直接控制和分配物理资源
	* 安装 Guest OS 时，VMM 在硬盘上自行分配存储空间（类似于外核），分配未经抽象的物理硬件
	* 性能更好
	* 可支持的虚拟机数量更多，不需要和 Host OS 竞争资源，相同的硬件资源可以支持更多的虚拟机
	* 虚拟机的可迁移性更差
	* 运行在最高特权级（Ring 0），可以执行最高特权的指令
* 第二类 VMM：
	* 运行在 Host OS 上，依赖于 Host OS 为其分配物理资源
	* Guest OS 拥有自己的虚拟磁盘（实际是 Host OS 的大文件），分配到虚拟内存
	* 性能更差，需要 Host OS 做中介
	* 可支持的虚拟机数量更少，Host OS 本身需要使用物理资源，Host OS 上运行的其他进程也需要使用物理资源
	* 可迁移性更好，只需要导出虚拟机镜像文件即可迁移，商业化应用更广泛
	* 部分运行在用户态，部分运行在内核态，Guest OS 发出的系统调用会被 VMM 截获，转化为 VMM 对 Host OS 的系统调用
