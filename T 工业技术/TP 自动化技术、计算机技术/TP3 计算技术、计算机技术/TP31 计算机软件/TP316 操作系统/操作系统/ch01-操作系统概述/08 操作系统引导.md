# 08 操作系统引导

磁盘架构：
* 主引导记录（MBR）：包含磁盘引导程序和分区表
* 分区：
	* 活动分区：被标记为可引导的分区，安装了操作系统的分区
		* 引导记录（PBR）：负责找到启动管理器
		* 根目录
		* 其他
	* 其他分区

操作系统引导：
* CPU 从一个特定的主存地址开始，执行 ROM 中的引导程序
	* 进行硬件自检
	* 开机
* 将主引导记录读入内存，执行磁盘引导程序，扫描分区表
* 从活动分区（主分区）读入分区引导记录，执行其中的程序
* 从根目录下找到完整的操作系统初始化程序（启动管理器）并执行
* （Windows 的启动管理器在 `C:/Windows/boot` 下）
