# 04 操作系统的运行机制

程序运行的过程就是 CPU 执行一条条指令的过程

内核程序：
* 操作系统内核的核心程序
* 最靠近硬件

特权指令：
* 只允许操作系统使用的指令

CPU 的两种状态：
* 内核态（核心态，管态）：正在运行内核程序，可以执行特权指令
* 用户态（目态）：正在运行应用程序，只可以执行非特权指令

CPU 内部有程序状态字（PSW）寄存器，其中一个二进制标志位用于区分 CPU 状态：
* 1 表示内核态，0 表示用户态

内核态 -> 用户态：
* 执行一条特权指令，修改 PSW 标志位为 0
* 操作系统主动让出 CPU 使用权
用户态 -> 内核态：
* 由**中断**引发，硬件自动完成状态的切换
* 操作系统强行夺回 CPU 使用权，停止运行当前的应用程序，转而运行处理中断信号的内核程序
