# 05 中断和异常

中断是让操作系统内核夺回 CPU 的唯一途径

内中断（异常、例外）：
* 与当前执行的指令有关
* 中断信号来自 CPU 内部
* 产生原因：
	* 陷入（trap）：由陷入指令引发，程序故意为之（如：系统调用）
	* 故障（fault）：由错误条件引起，可能被内核程序修复，修复成功则将 CPU 使用权返还应用程序（如：缺页故障）
	* 终止（abort）：由致命错误引起，内核程序无法修复，直接终止应用程序（如：整数除以 0、非法使用特权指令）

外中断（狭义中断）：
* 与当前执行的指令无关
* 中断信号来自 CPU 外部
* 每一条指令执行结束都会检查是否有外中断信号
* 产生原因：
	* 时钟中断：时钟部件每隔一个时间片会给 CPU 发送一个时钟中断信号
	* I/O 中断请求：设备当输入输出任务完成时向 CPU 发送中断请求

基本原理：
* 不同的中断信号需要用不同的中断处理程序处理
* CPU 检测到中断信号后查询**中断向量表**，找到相应的中断处理程序
* 中断处理程序是内核程序，运行在内核态
