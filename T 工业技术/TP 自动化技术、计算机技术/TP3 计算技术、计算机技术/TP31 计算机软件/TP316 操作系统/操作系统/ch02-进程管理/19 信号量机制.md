# 19 信号量机制

用户进程可以通过使用操作系统提供的一对原语对信号量（一个变量）进行操作，从而实现进程互斥和进程同步

信号量：
* 可以是整数或更复杂的记录型变量
* 表示系统中某种资源的数量
* 可以使用 `wait`（P）和 `signal`（V）原语操作信号量，使用时传入信号量作为参数
* 对信号量的操作只有初始化、P 操作、V 操作三种

整型信号量：
* 用整型变量作为信号量
  ```c
  void wait(int S) {
	while (S <= 0);
	S--;
  }

  void signal(int S) {
	S++;
  }

  int S = 1;

  void P0 {
	wait(S);
	// 临界区
	signal(S);
	// 剩余区
  }

  void P1 {
	wait(S);
	// 临界区
	signal(S);
	// 剩余区
  }

  // ...

  void Pn {
	wait(S);
	// 临界区
	signal(S);
	// 剩余区
  }
  ```
* 问题：不满足让权等待

记录型信号量：
```c
typedef struct {
	int value;
	struct process *L;
} semaphore;

void wait(semaphore S) {
	S.value--;
	if (S.value < 0) {
		block(S.L);
	}
}

void signal(semaphore S) {
	S.value++;
	if (S.value <= 0) {
		wakeup(S.L);
	}
}

semaphore S = {0, null}
;
void P0 {
	wait(S);
	// 临界区
	signal(S);
	// 剩余区
}

void P1 {
	wait(S);
	// 临界区
	signal(S);
	// 剩余区
}

// ...

void Pn {
	wait(S);
	// 临界区
	signal(S);
	// 剩余区
}
```
* 若剩余资源数不够（`S.value < 0`），则使用 `block` 原语将当前进程从运行移入阻塞态，主动放弃处理机，挂到信号量 `S` 的阻塞队列中，遵循了让权等待原则
* 若释放资源后 `S` 的阻塞队列中有等待的进程，则使用 `wakeup` 原语唤醒等待队列中的一个进程，该进程从阻塞态变为就绪态
* `S.value` 的初值表示系统中某种资源的数目
