# 24 哲学家用餐问题

问题描述：
* 圆桌上坐着 5 名哲学家，每两个哲学家之间的桌上摆着刀或叉（其中的一个），桌子中间是食物
* 哲学家只会吃饭或思考，思考时不影响他人
* 哲学家在饥饿时会试图依次拿起刀叉，如果刀叉在他人手中则需等待
* 哲学家只有在同时拿到一副刀叉时才能用餐，用餐完毕后放下刀叉继续思考

关系分析：
* 哲学家可看作进程，刀叉为资源
* 哲学家与其相邻的哲学家对刀叉的访问为互斥关系

整理思路：
* 每个哲学家需要同时拿到刀和叉才能用餐，如何避免临界资源分配不当造成死锁

信号量设置：
* 定义信号量数组 `tableware[5] = {1, 1, 1, 1, 1}`
* 对哲学家按 0~4 编号
* 第 `i` 名哲学家左边的餐具编号为 `i`，右边的餐具编号为 `(i + 1) % 5`

实现方案 1：
```c
semaphore tableware[5] = {1, 1, 1, 1, 1};

void Philosopher() {
	while (1) {
		P(tableware[i]);
		P(tableware[(i + 1) % 5]);
		// 用餐
		V(tableware[i]);
		V(tableware[(i + 1) % 5]);
		// 思考
	}
}
```
* 问题：如果 5 名哲学家并发拿起左边的餐具，则所有哲学家都会等待拿起右边的餐具，造成死锁
* 解决方案：
	* 最多允许 4 名哲学家同时用餐，保证至少有一个哲学家可以拿到一副刀叉
	* 要求奇数号哲学家先拿左边的餐具，然后再拿右边的餐具，偶数号哲学家相反，保证相邻的奇偶号哲学家只有其中一名可以用餐，另一名阻塞
	* 各个哲学家拿左右两边餐具必须互斥地执行
* 方案 3 实现：
  ```c
	semaphore tableware[5] = {1, 1, 1, 1, 1};
	semaphore mutex = 1;
	
	void Philosopher() {
		while (1) {
			P(mutex);
			P(tableware[i]);
			P(tableware[(i + 1) % 5]);
			V(mutex);
			// 用餐
			V(tableware[i]);
			V(tableware[(i + 1) % 5]);
			// 思考
		} 
	}
  ```
* 持有多个临界资源的情况可以参考哲学家用餐问题，分析是否会发生死锁
