单标志法：
* 进程在访问完临界区后将访问权限移交给另一个进程
* 每个进程的访问权限只能被另一个进程赋予
	```c
	int turn = 0; // 默认进程0先获得访问权限
	
	void P0 {
		while (turn != 0);
		// 临界区
		turn = 1;
		// 剩余区
	}
	
	void P1 {
		while (turn != 1);
		// 临界区
		turn = 0;
		// 剩余区
	}
	```
* 实现了同一时刻最多只允许一个进程访问临界区
* 问题：违背了空闲让进原则
	* A 进程失去了访问权限只能等待 B 进程归还，若 B 不执行，则处理机空闲

双标志先检查法：
* 设置一个布尔型数组 `flag[]`，用于标记各进程是否请求进入临界区
* 每个进程在进入临界区之前先检查当前有没有进程请求进入临界区，如果没有则将自身标志设为 `true`，之后开始访问临界区
	```c
	bool flag[2];
	flag[0] = false;
	flag[1] = false;
	
	void P0 {
		while (flag[1]);
		flag[0] = true;
		// 临界区
		flag[0] = false;
		// 剩余区
	}
	
	void P1 {
		while (flag[0]);
		flag[1] = true;
		// 临界区
		flag[1] = false;
		// 剩余区
	}
	```
* 问题：违反忙则等待原则
	* 进入区的检查和上锁不是同步的，检查后、上锁前可能发生进程切换，导致同时进入临界区

双标志后检查法：
* 对双标志先检查法的改版
* 先上锁，后检查
	```c
	bool flag[2];
	flag[0] = false;
	flag[1] = false;
	
	void P0 {
		flag[0] = true;
		while (flag[1]);
		// 临界区
		flag[0] = false;
		// 剩余区
	}
	
	void P1 {
		flag[1] = true;
		while (flag[0]);
		// 临界区
		flag[1] = false;
		// 剩余区
	}
	```
* 解决了忙则等待的问题
* 问题：
	* 违反了空闲让进和有限等待原则
	* 会导致饥饿

Peterson 算法：
* 结合双标志法和单标志法的思想
* 进入区逻辑：主动争取、主动谦让、检查对方是否请求且自身取得主动权
	```c
	bool flag[2];
	int turn = 0;
	
	void P0 {
		flag[0] = true;
		turn = 1;
		while (flag[1] && turn = 1);
		// 临界区
		flag[0] = false;
		// 剩余区
	}
	
	void P1 {
		flag[1] = true;
		turn = 0;
		while (flag[0] && turn = 0);
		// 临界区
		flag[1] = false;
		// 剩余区
	}
	```
* 遵循了空闲让进、忙则等待、有限等待
* 问题：未遵循让权等待，会发生忙等
