有读者和写者两组并发进程，共享一个文件，满足以下要求：
* 多个读者可以同时对文件执行读操作
* 同一时刻只允许一个写者对文件执行写操作
* 任一写者完成写操作前不允许其他读者或写者操作
* 写者执行写操作前，需要其他任何进程退出

实现：
```c
semaphore mutex = 1;
semaphore rw = 1;

int readerCnt = 0;

void Writer() {
	while (1) {
		P(rw);
		// 写操作
		V(rw);
	}
}

void Reader() {
	while (1) {
		P(mutex);
		if (readerCnt == 0)
			P(rw);
		readerCnt++;
		V(mutex);
		// 读操作
		P(mutex);
		readerCnt--;
		if (readerCnt == 0)
			V(rw);
		V(mutex);
	}
}
```
* 潜在的问题：
	* 只要还有读进程在执行，则写进程就要一直等待，可能发生饥饿
	* 即这种算法是读进程优先的
* 读写公平算法改进：
	```c
	semaphore mutex = 1;
	semaphore rw = 1;
	semaphore w = 1;
	
	int readerCnt = 0;
	
	void Writer() {
		while (1) {
			P(w);
			P(rw);
			// 写操作
			V(rw);
			V(w);
		}
	}
	
	void Reader() {
		while (1) {
			P(w);
			P(mutex);
			if (readerCnt == 0)
				P(rw);
			readerCnt++;
			V(mutex);
			V(w);
			// 读操作
			P(mutex);
			readerCnt--;
			if (readerCnt == 0)
				V(rw);
			V(mutex);
		}
	}
	```

解决复杂互斥问题的思路：
* 设置计数器 `count` 记录
* 对 `count` 变量的检查和赋值需要具有原子性，使用互斥信号量
* 注意解决饥饿问题
