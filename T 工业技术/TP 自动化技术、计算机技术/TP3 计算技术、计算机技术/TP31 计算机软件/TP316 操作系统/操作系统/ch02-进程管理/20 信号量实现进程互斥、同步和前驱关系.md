一种信号量代表一种资源的剩余数量

信号量实现进程互斥：
* 分析并发进程的关键活动，划定临界区
* 设置互斥信号量 `mutex`，初值为 1
* 在进入区编写 `P(mutex)`
* 在退出区编写 `V(mutex)`
* 对不同的临界资源需要设置不同的互斥信号量
* P、V 操作必须成对出现
```c
semaphore mutex = 1;

void P1() {
	...
	P(mutex);
	// 临界区
	V(mutex);
	// 剩余区
}

void P2() {
	...
	P(mutex);
	// 临界区
	V(mutex);
	// 剩余区
}
```

信号量实现进程同步：
* 进程同步：使各并发进程按要求有序推进
* 分析什么地方需要实现同步关系，即必须保证一前一后执行的两个操作
* 设置同步信号量，初值为 0
* 在前操作后执行 `V(S)`
* 在后操作前执行 `P(S)`
```c
semephore S = 0;

void P1() {
	// 前操作
	V(S);
	...
}

void P2() {
	...
	V(S);
	// 后操作
}
```

信号量实现前驱关系（本质就是多级同步问题）：
* 为每一对前驱关系设置一个同步信号量
* 在前操作后对相应的同步信号量执行 V 操作
* 在后操作前对相应的同步信号量执行 P 操作
```c
semaphore a, b, c, d, e = 0;

void P1() {
	...
	// S1
	V(a);
	V(b);
	...
}

void P2() {
	...
	P(a);
	// S2
	V(c);
	V(d);
	...
}

void P3() {
	...
	P(b);
	// S3
	V(g);
	...
}

void P4() {
	...
	P(c);
	// S4
	V(e);
	...
}

void P5() {
	...
	P(d);
	// S5
	V(f);
	...
}

void P6() {
	...
	P(e);
	P(f);
	P(g);
	// S6
	...
}
```
