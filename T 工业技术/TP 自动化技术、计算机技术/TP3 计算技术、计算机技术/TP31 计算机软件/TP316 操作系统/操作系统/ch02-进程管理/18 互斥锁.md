 进程在进入临界区时使用 `require` 函数获得锁，在退出临界区时使用 `release` 函数释放锁

每个互斥锁都有一个布尔变量 `available`，表示锁是否可用
* 若锁可用，则可成功调用 `acquire`，且锁不再可用
* 若锁不可用，则进程被阻塞，直到锁被释放

```c
acquire() {
	while (!available);
	available = false;
}

release() {
	available = true;
}
```
* `acquire` 和 `release` 必须是原子操作，通常采用硬件实现

优点：
* 等待期间不用切换进程上下文，若上锁时间短，则等待代价很低

缺点：违反让权等待，多个进程共享同一 CPU 时浪费了 CPU 周期
* 互斥锁常用于多处理机系统，一个进程等待不影响其他进程

自旋锁：需要连续循环等待的互斥锁
* 如 TSL 指令、Swap 指令、单标志法
