1973 年由 Brinch Hansen 在 Pascal 中引入

解决了信号量机制编写困难、易出错的问题

一种特殊的软件模块，由以下部分构成：
* 局部于管程的共享数据结构
* 对该数据结构进行操作的一组过程
* 初始化共享数据结构的语句
* 管程名

基本特征：
* 局部于管程的数据只能通过局部于管程的过程访问
* 一个进程只能通过调用管程中的过程才能进入管程访问共享数据
* 每次仅允许一个进程在管程内执行某个内部过程

用管程解决生产者-消费者问题：
```c
monitor ProducerConsumer
	condition full, empty;
	int count = 0;
	
	void insert(Item item) {
		if (count == N) {
			wait(full);
		}
		count++;
		insertItem(item);
		if (count == 1) {
			signal(empty);
		}
	}
	
	Item remove() {
		if (count == 0) {
			wait(empty);
		}
		count--;
		if (count == N - 1) {
			signal(full);
		}
		return removeItem();
	}
end monitor;

void Producer() {
	while (1) {
		Item item = produce();
		ProducerConsumer.insert(item);
	}
}

void Consumer() {
	while (1) {
		Item item = ProducerConsumer.remove();
		consume(item);
	}
}
```
* 在管程内定义共享数据
* 在管程内定义用于访问共享数据的入口函数
	* 只有通过这些入口才能访问共享数据
	* 每次只能开放一个入口，且只能让一个进程进入，保证同时只能有一个进程访问缓冲区（编译器负责实现）
* 可以在管程中设置条件变量 `condition`（相当于信号量）和 `wait`、`signal` 操作，解决同步问题
	* 可以让进程在条件变量上等待（进程应先释放管程的使用权）
* 本质是封装思想
