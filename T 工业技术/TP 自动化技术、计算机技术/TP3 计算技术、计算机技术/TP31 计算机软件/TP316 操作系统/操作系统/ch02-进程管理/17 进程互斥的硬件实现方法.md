中断屏蔽方法：
* 利用开 / 关中断指令实现
* 优点：简单、高效
* 缺点：
	* 不适用于多处理机
	* 只适用于操作系统内核进程，不适用于用户进程（因为开 / 关中断指令只运行在内核态）

TestAndSet（TestAndSetLock）指令：
* TSL 指令使用硬件实现，执行的过程不允许被中断
	```c
	bool lock = false;
	
	bool TestAndSet(bool *lock) {
		bool old;
		old = *lock;
		*lock = true;
		return old;
	}
	
	void P {
		while (TestAndSet (&lock));
		// 临界区
		lock = false;
		// 剩余区
	}
	```
* TSL 指令将上锁和检查操作用硬件的方式变成了原子性的操作
* 优点：
	* 实现简单，无需检查是否有逻辑漏洞
	* 适用于多处理机环境
* 缺点：
	* 不满足让权等待

Swap（Exchange，XCHG）指令：
* 使用硬件实现，执行过程不允许被中断
	```c
	bool lock = false;
	
	void Swap (bool *a, bool *b) {
		bool tmp;
		tmp = *a;
		*a = *b;
		*b = temp;
	}
	
	void P {
		bool old = true;
		while (old) {
			Swap(&lock, &old);
		}
		// 临界区
		lock = false;
		// 剩余区
	}
	```
* 与 TSL 指令逻辑几乎一致，先记录此时 `lock` 的状态，再将 `lock` 设置为 `true`，最后检查 `old`
* 优点：
	* 实现简单
	* 适用于多处理机
* 缺点：
	* 不满足让权等待
