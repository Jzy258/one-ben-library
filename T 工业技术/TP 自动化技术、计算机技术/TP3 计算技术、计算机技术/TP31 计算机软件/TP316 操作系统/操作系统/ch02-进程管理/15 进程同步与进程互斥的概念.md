进程同步（直接制约关系）：
* 多个进程为完成某种任务，在某些工作次序上产生的制约关系
* 导致这些进程需要进行位置的协调
* 源于进程之间的相互合作

进程互斥（间接制约关系）：
* [[10 进程调度的时机、切换与过程#^c8923c|临界资源]]
* A 进程正在访问临界资源，B 进程想要访问该资源时必须等待
* A 进程访问结束后释放资源，B 进程即可访问
* 在逻辑上的划分：
	```c
	do {
		// 进入区
		// 临界区
		// 退出区
		// 剩余区
	} while (true);
	```
	* 临界区（临界段）：用于访问临界资源的代码逻辑
	* 进入区：负责为临界区上锁
	* 退出区：负责为临界区解锁
	* 剩余区：其余代码
* 遵循原则：
	* 空闲让进：临界资源空闲时，可以允许一个请求进入临界区的进程立即进入临界区
	* 忙则等待：已有进程进入临界区时，其他请求进入临界区的进程必须等待
	* 有限等待：请求访问临界区的进程应能够在有限时间内访问到临界区（保证不会饥饿）
	* 让权等待：进程不能进入临界区时，立即释放处理机，防止进程忙等
