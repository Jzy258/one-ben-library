# 09 文件保护

口令保护：
* 用户访问文件时必须提供口令
* 口令一般存放在文件 FCB 中或索引结点中
* 优点：
	* 空间开销不大
	* 验证的时间开销不大
* 缺点：
	* 正确的口令存放在系统内部，不够安全

加密保护：
* 使用密码对文件加密
* 优点：
	* 不需要在系统中存储密码
* 缺点：
	* 编码 / 译码需要花费时间

访问控制：
* 在 FCB 或索引结点中增加访问控制列表（Access-Control List，ACL），记录各个用户可以对文件执行的操作
* 访问类型：
	* 读
	* 写
	* 执行
	* 添加：将新信息添加到文件末尾
	* 删除
	* 列表清单：列出文件名和属性
* 精简的访问列表：
	* 将用户分组，为不同用户组分配不同权限
	* 操作文件时检查用户所属用户组
	* 系统管理分组信息
