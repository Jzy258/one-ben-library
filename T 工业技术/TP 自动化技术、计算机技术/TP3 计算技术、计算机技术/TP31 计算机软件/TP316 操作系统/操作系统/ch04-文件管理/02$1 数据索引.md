数据索引：
* 数据的目录系统
* 包括：
	* 文件名、大小、创建时间、修改时间、权限（安全 ID）等属性
	* 数据位置指针：文件的物理地址
* 不同文件系统中具体的名字：
	* NTFS：MFT（主文件表，Master File Table）
	* FAT32 / exFAT：FAT（文件分配表）+ 目录项

索引文件：
* 用于实现数据索引
* 本质：定长记录顺序文件
* 各个文件系统的实现：
	* NTFS 使用：`$MFT`（主文件表，Master File Table）
		* 大小通常为 1 kB
		* 包含：
			* 基本属性，如：文件名、创建时间、修改时间、权限（安全 ID）
			* 数据位置指针：文件内容存放的物理地址（以**簇**（Cluster）为单位）
			* 小文件可以直接将内容存在记录中
	* NTFS 还使用：`$INDEX_ROOT`、`$INDEX_ALLOCATION`
		* 目录的索引区
		* 用于目录内部的文件名索引，实现快速查找（采用 B+ 树数据结构）
	* FAT32 使用：FAT 表
		* 本质是链式索引，记录每个簇属于哪个文件、下一个簇的位置
	* exFAT 使用：FAT 表 + 目录项
		* 类似 FAT32，但更先进
* 索引表项（Index File）：
	* 存放在目录的索引区
	* 包括：文件名、文件号（指向 MFT 记录的指针）、排序用的辅助信息
		* 不包含任何文件内容
	* 使用 B+ 树组织，便于按文件名查找
	* [[08 文件共享|硬链接]]实现基础
		* 一个文件可以在多个目录中有多个索引表项
	* 生命周期：
		* 文件被加入到某文件夹时创建
		* 文件被移出某文件夹时销毁
	* 适用于信息处理及时性要求较高的场合

文件记录（File Record）：
* NTFS 中，每个文件和文件夹在 `$MFT` 中有一个对应的文件记录
* 内容包括：
	* 文件号（File Reference Number）：文件的唯一标识
	* 基本属性
	* 数据位置指针
	* 状态标志：是否已删除、是否为目录、是否正在使用等
* 生命周期：
	* 文件创建时创建
	* 文件删除时销毁
* 在 `$MFT` 中可以离散存放
* 创建和销毁时需要联动修改索引表项

文件访问流程（以 `C:\foo.txt` 为例）：
* 在 `C:\` 目录索引中按 `foo.txt` 查找索引表项
* 得到 `foo.txt` 在 `$MFT` 中的文件号
* 在 `$MFT` 中按文件号读取记录
* 得到 `foo.txt` 的物理位置
* 读取 `foo.txt` 的内容
