程序装入内存后才能被 CPU 处理（执行）
* 磁盘的读写速度慢，CPU 的处理速度快
* 作用：缓和 CPU 与硬盘之间读写速度的矛盾

需求：区分多道程序并发执行时的数据
方案：为内存的存储单元编地址
* 从 0 开始，每个地址对应一个存储单元
* 每个存储单元的大小：
	* 按字节编址（主流）：每个存储单元为 1 字节
	* 按字编址：每个存储单元为 1 个字（字长由 CPU 型号决定）

物理地址：数据在内存中实际存放的位置
逻辑地址：
* 相对于进程起始地址的地址
* 程序经过编译、链接后指明的地址

数据装入内存的方式：
* 绝对装入：编译时确定内存位置，编译器直接产生绝对地址的目标代码，装入程序按照可执行文件中的装入模块中的地址，将程序和数据装入内存
	* 只适用于单道程序环境（不会因多个程序同时运行造成地址冲突）
* 静态重定位（可重定位装入）：编译、链接后的装入模块中的地址都从 0 开始（相对于起始地址的逻辑地址），将装入模块装入到内存的适当位置时对地址进行重定位，将逻辑地址转换为物理地址
	* 一个作业装入内存时必须分配其要求的全部内存空间
	* 作业进入内存后不能再移动
	* 适用于早期的多道批处理操作系统
* 动态重定位（动态运行时装入）：编译、链接后的装入模块中的地址都从 0 开始，程序进入内存时所有地址仍为逻辑地址，程序执行时将逻辑地址转换为物理地址
	* 重定位寄存器（基址寄存器）存放装入模块存放的起始地址
	* 由内存管理单元（MMU）负责地址转换
	* 可以将程序分配到不连续的存储区中
	* 程序运行时只需要装入部分代码，可以提供比存储空间大得多的地址空间
	* 允许程序在内存中移动

从写程序到程序运行：
* 程序员编写源代码
* 编译程序将源代码编译为若干目标模块（将高级语言转换成机器语言）
* 链接程序将目标模块和所需库函数链接在一起，形成完整的装入模块
* 装入程序将装入模块装入内存运行

链接的三种方式：
* 静态链接：在程序运行之前将各个目标模块及库函数连接成一个完整的可执行文件（装入模块），不再拆开
* 装入时动态链接：将各目标模块装入内存时链接
* 运行时动态链接：在程序执行中需要该目标模块时进行链接
	* 便于修改和更新
	* 便于实现对目标模块的共享
