分页存储：
* 将物理内存空间分为若干大小相等的分区
* 页框（页帧，内存块，物理块，物理页面）：
	* 内存被划分成的分区
	* 页框号：页框的编号，从 0 开始
	* 大小：一般为 512B ~ 8KB

页（页面）：
* 进程的逻辑地址空间划分成的与页框大小相等的若干部分
* 页号：页的编号，从 0 开始

操作系统以页框为单位为各个进程分配内存空间，进程的每个页被分配到一个页框（一一对应）

各个页不必连续存放

页表：
* 作用：
	* 指示进程的每个页在内存中存放的位置
	* 记录页和内存块之间的映射关系
* 一个进程对应一张页表，页表的始址和长度存放在 PCB 中
* 进程的每个页对应一个页表项
* 每个页表项由页号和块号组成
* 需要一直驻留在物理内存中

每个页表项所占字节：
* 内存块大小 = 页面大小
* 内存块数 = 内存大小 / 内存块大小
* 内存块号大小 = log(内存块数)
* 因为页表项连续存放，页号不占存储空间，则页表项大小 = 内存块号大小

地址转换：
* 重定位寄存器指明进程在内存中的起始位置
* 页号 = 逻辑地址 / 页面长度
* 页内偏移量 = 逻辑地址 % 页面长度
* 页面长度通常为 2 的整数次幂，便于计算页号和页内偏移量
* 物理地址 = 页号对应的起始地址 + 页内偏移量

逻辑地址结构：
* 页内偏移量位数指示一个页面的大小
* 页号位数指示一个进程最多拥有的页面数

页表寄存器：
* 存放页表在内存中的起始地址 F 和页表长度 M
* 进程未执行时页表始址、页表长度存放在 PCB 中，进程被调度时内核将其存放在页表寄存器中

基本地址变换机构：
* 根据逻辑地址计算出页号、页内偏移量
* 页号与页表长度相比较，判断页号是否越界
	* 越界则引发越界中断（内中断）
	* 页号 = 页表长度时也会中断（页号从 0 开始）
* 查询页表，找到页表对应的页表项，确定内存块号
* 根据内存块号和页内偏移量得到物理地址
* 访问目标内存单元

为了让每个页面恰好可以装得下整数个页表项，常常会让一个页表项占更多字节（内存对齐）

共访问 2 次内存：
* 查页表
* 访问目标内存单元
